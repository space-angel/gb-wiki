# ⚠️ 오답 처리 시스템 (미확정)

> **Proposed 상태.** 2026-07-20 논의에서 도출, ADR-12에서 분리 · 안지호 최종 확인 대기.
> 방향은 한 문장으로 요약된다 — **"무제한 재시도 + 이후 어떤 제약도 없음."**

## 1. 재시도 횟수 — 무제한, 카운트 자체를 두지 않음

재시도는 무제한이다. **시도 횟수를 저장 스키마에 기록하지 않는다.**

> **근거 레퍼런스 — The Case of the Golden Idol**: 보드를 몇 번 열어도 이전 시도 기록이 남지 않고, 힌트도 실패 이력과 무관하게 독립 제공된다.

## 2. 오답 시 리셋 범위 — 배치만 리셋, 진행은 불변

오답 선택 시 초기화되는 것은 **재구성 보드 위 조각 배치뿐**이다.

**영구 보존되는 것**:
- 이미 참이 된 1~3단계 플래그
- 이미 확인된 진술 슬롯·회상 내용
- 이미 개방된 사령세계 구역

> **근거 레퍼런스 — Outer Wilds**: 루프가 리셋되어도 지식·단서·열린 문은 영구히 남는다. **"리셋"과 "손실"을 분리**한다.

## 3. 힌트 시스템 (도입 시) — 실패 이력 비참조

힌트를 도입하더라도 **실패 횟수·재시도 이력을 참조해 동적 난이도를 조절하지 않는다.**

## 준수 사항 (확정 시 적용될 것)

1. 재시도 횟수를 **저장 스키마의 어떤 키로도 기록하지 않는다.**
2. 오답 시 리셋 대상은 **해당 시도의 보드 배치로 한정**한다. 플래그·진술·구역 개방 상태는 **절대 초기화하지 않는다.**
3. 힌트 기능은 **실패 이력을 입력값으로 참조하지 않는다.**
4. 오답에 대해 **명시적 실패 텍스트·아이콘·사운드 등 판정성 피드백을 주지 않는다.**

## 효과와 리스크

**효과**
- 오답에 대한 심리적 부담 제거 — "찍어보고 확인" 방식도 자유롭게 허용
- 저장 스키마 단순화 (재시도 카운트·실패 이력·동적 힌트 상태 전부 불필요)
- 3단계까지의 진행이 오답과 **완전히 분리**됨

**리스크**
- 페널티 부재로 4단계 자체의 긴장감·성취감이 약화될 수 있다 → **가설 설계(오답의 그럴듯함)로 보완**해야 한다 ([[가설_3지선다]])
- 무제한 재시도 UI가 매끄럽지 않으면 지루해진다

## 기각된 대안

| 대안 | 기각 사유 |
|---|---|
| 재시도 횟수 제한(예: 3회) 후 페널티 | "무제한+무제약" 방향과 충돌 |
| 오답 시 진술·구역개방 초기화 | Outer Wilds식 원칙 위반 |
| 실패 횟수 기반 동적 힌트 | 실패 이력을 상태로 남기게 되어 §1 위반 |
| 오답 시 "틀렸습니다" 명시 표시 | ADR-12에서 이미 기각된 침묵형 원칙과 재충돌 |

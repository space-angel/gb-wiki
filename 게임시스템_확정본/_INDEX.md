# 게임시스템 확정본 — 인덱스

ADR 14건과 시스템 결정 트래커 17건을 **현재 시점의 시스템 명세**로 재구성한 모음. 2026-08-05 작성.

## 이 폴더가 ADR 원문과 다른 점

ADR은 **결정 기록**이다 — "왜 그렇게 됐나", "무엇을 기각했나"가 시간순으로 쌓인다. 그래서 원문만 읽으면 **이미 폐기된 규칙을 현행으로 오해**할 수 있다.

| 문제 | 예시 |
|---|---|
| supersede가 원문에 반영 안 됨 | ADR-1이 정의한 출력 3종 중 "잡몹 약화"를 ADR-9가 삭제했는데, ADR-1 본문은 그대로 남아 있다 |
| OQ가 다른 ADR에서 해소됨 | ADR-12의 OQ-2(재시도 횟수)는 ADR-14가 답했다 |
| 트래커와 ADR이 중복 | 트래커 17건 중 6건은 ADR과 1:1 대응하는 빈 카드다 |

이 폴더는 그걸 다 적용해서 **"지금 무엇이 참인가"** 만 남긴다. 원문은 `raw/00_컴플라이언스/ADR/`에 그대로 있다.

## 🔴 가장 시급한 것

**[[공간_개방_규칙]](ADR-11)과 스토리 자료가 정면 충돌 중이다.**

- ADR-11: 메인 A로 1구역을 열고 → 메인 B는 **그 1구역 안에서** 획득 (순차 체인)
- 스토리: 메인 3개를 챕터 초반 원룸에서 **동시에 발견**, 각자 독립적으로 구역 개방

명명 차이가 아니라 **레벨디자인 전제가 통째로 갈리는 지점**이다. 거의 같은 시기(07-20 / 07-23)에 서로 확인 없이 결정된 것으로 보인다. 이게 안 풀리면 레벨디자인·아트·[[3계층_분리]] OQ-2가 전부 대기 상태가 된다.

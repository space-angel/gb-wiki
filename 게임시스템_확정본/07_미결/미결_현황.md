## ⬜ 미결 — P1 (지금 막고 있는 것, 4건)

### 1. 1단계(O) 임계값 N 정의
`domain: 이해도-입력`

O 달성에 필요한 유품 개수 N. **구조는 확정, 값이 없다.**

- **확정 전제**: O = 유품 개수 임계 도달 방식 / 아이템 풀 = 챕터당 13~15개(핵심3+보조10~12)
- **미결 지점**: ① N 값 ② 핵심/보조 구분 없이 순수 개수인지, 핵심에 가중치를 둘지 ③ 챕터마다 동일한지
- **제약**: 어떤 수집 순서로도 도달 가능해야 함 (특정 유품 강제 금지)
- **결정 트리거**: **챕터 1 현실세계 맵 초안 + 유품 배치안(재화-아이템매핑)이 나온 뒤**가 안전. 맵 없이 정하면 감으로 찍는 게 된다.
- 현재 [[이해도_판정_트리거]]에서 **N=6으로 변수 유지** 중

### 2. 임계값 (충분/적정/없음 컷오프) 정의
`domain: 이해도-엔딩` · 블록: 재화-후일담

플래그 조합 → 종결 매핑안이 **제안 상태로만 존재**하고 팀 합의·ADR이 없다.

제안된 매핑 (= [[이해도_4플래그_파이프라인]]에 적힌 것):
- 충분 = OAVR 전부 true → 성불
- 적정 = OAV true, R false → 제령
- 없음 = A false (보조 판매 등) → 소멸

- **미결 지점**: ① 매핑안의 팀 합의·ADR 등록 ② **"없음 = A false"의 정의가 모호** — A가 false인 *상태*인지, 유품 판매 같은 *행동*이 트리거인지 ③ **중간 상태 전 구간 미명시** (O만 true, O+A만 true 등에서 어떤 종결이 허용되는가)
- **결정 트리거**: 아래 3번과 **같은 문제의 양면** — 통합 논의 권장

### 3. R 미달 상태 보스전 결과 정의
`domain: 이해도-엔딩`

보스룸 항시 접근이 확정되면서 "R 미달 플레이어도 보스룸에 들어갈 수 있음"이 구조적으로 보장됐는데, **들어가서 무슨 일이 일어나는지 아무도 정의하지 않았다.**

- **확정 전제**: 보스룸 항시 접근(2게이트) / 이해도 출력 = 보스 한정(ADR-9) / 종결 선택지는 이해도가 열쇠
- **미결 지점**: 미도달 상태 보스전이 **"벽"으로 느껴지지 않게** 하는 연출 — 재탐색 동기 부여 방식
- **결정 트리거**: 위 2번과 통합 논의 필수. 보스전 플로우 구현(Unity-전투프로토) 전 잠금 필요

### 4. 핵심 유품 배치 정책 (현실 한정 vs 사령 체인)
`domain: 이해도-입력`

- **A) 현실 한정**: 핵심 3개 전부 현실세계에서만 획득 — 구조 단순, 검증 쉬움 / 사령세계 탐색 보상 약화
- **B) 체인 허용**: 사령 구역 안에 다음 구역 열쇠 배치 — 두 세계 왕복 루프, 메트로배니아다움 강화 / 검증 복잡

논리적으로 강제되는 건 **"열쇠 의존 그래프에 순환이 없을 것"** 하나뿐이다.

> ⚠️ **[[공간_개방_규칙]](ADR-11, Proposed)이 사실상 B안을 채택했다.** ADR-11이 Accepted되면 이 트래커는 종결 가능. 단 ADR-11이 스토리 자료와 충돌 중이라 그쪽이 먼저 정리돼야 한다.

## ⬜ 미결 — P2 (의도적 연기, 4건)

### 5. 재구성 오답 제출 시 리액션 방식
`domain: 재구성보드`

> ✅ **[[오답_처리]](ADR-14)가 대부분 답했다** — "명시적 실패 피드백·페널티 없음, 무제한 재시도". ADR-14 확정 시 종결 가능.
>
> **다만 남은 질문 하나**: "제출됐으나 틀렸다"를 플레이어가 **버그로 오해하지 않게 하는 최소 피드백 라인**. 완전 무반응이 원칙엔 가장 충실하지만 UX상 버그로 오인될 위험이 있다. (참고: Obra Dinn은 3건 동시 정답 시에만 확정, 오답엔 무반응)
>
> 정인-슬롯UI 작업이 영향받으므로 UI 시안 전 잠금 권장.

### 6. 패턴 가시성 시각 표현 방식
`domain: 이해도-출력`

"이해도가 높으면 패턴이 일찍 보인다"를 **어떤 시각 수단으로** 구현할지. 옵션: 히트박스 윤곽 / 이펙트 잔상 / 카메라 줌인 등. 이해도 단계별 차등 표현 여부도 미정.

- **의도적 연기 (M2~M3)**: 기능 방향은 확정, 시각 표현 수단만 남음. 아트 스타일과 문정인 픽셀 작업 역량 확인 후 정하는 게 맞다.
- **결정 트리거**: 문정인 픽셀 작업 진입 + 보스 1종 패턴 프로토타입 완성 시

### 7. 종합 이해도 U 산출 공식
`domain: 이해도-정의`

챕터별 이해도 → 최종 엔딩용 종합 U 산출.

- **의도적 연기 (Phase 1)**: **지금 결정하면 안 되는 항목.** 입력값(챕터 수, 챕터별 종결 구조)이 미정이라 공식을 만들어도 재작업 확정.
- **결정 트리거**: 전체 챕터 수 확정 + 아래 8번과 함께
- 챕터 1 데모(2027-06)에는 불필요 — P2 유지 타당

### 8. 최종 엔딩 분기 처리 방식
`domain: 이해도-엔딩`

챕터별 엔딩 조합 → 최종 엔딩 매핑. "경우의 수 6가지"는 특정 챕터 수를 가정한 계산인데 **전체 챕터 수가 미확정**이라 전제 자체가 유동적이다.

- 위 7번과 **같은 문제의 양면** — 통합 권장. 챕터 1 데모 범위 밖.

## 결정 순서 제안

의존 관계를 따지면 이 순서가 자연스럽다.

1. **메인 유품 정체성 + 공간 개방 구조 확정** (ADR-11 vs 스토리 자료 충돌 해소) — 이게 안 풀리면 4번·OQ-5가 못 움직인다

3. **2번 + 3번 통합 논의** (컷오프 정의와 R 미달 보스전은 한 문제)

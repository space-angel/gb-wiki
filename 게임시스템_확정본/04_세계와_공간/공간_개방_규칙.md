# ⚠️ 사령세계 공간 개방 규칙 (미확정)

> **Proposed 상태.** 2026-07-03 설계 논의에서 도출, 안지호 최종 확인 대기 중.
> **이 문서의 내용은 확정 규칙이 아니다.** 아래를 근거로 다른 결정을 내려도 "위반"이 아니지만, 반대로 이걸 확정으로 알고 레벨디자인을 진행하면 나중에 뒤집힐 수 있다.
>
> ⚠️ 원문 기재: "2026-07-03 설계 논의"에 대응하는 정식 회의록이 회의록 DB에 없음 — 원본 소재 확인 필요.

## 핵심 아이디어 — 두 축을 분리한다

**공간을 여는 축(메인 유품)** 과 **이해를 쌓는 축(추리)** 은 서로 종속되지 않는다.

### 축 1 — 공간 개방 (메인 유품 게이트)

메인 유품 **1개가 사령 구역 1개**를 연다(1:1). **구역 개방은 추리 성공과 무관하다.**

| 열쇠 | 획득 위치 | 여는 것 |
|---|---|---|
| 메인 A | 현실세계 | 사령 1구역 + 보스방 |
| 메인 B | **사령 1구역** | 1구역 내 오브젝트 상호작용 → 2구역 |
| 메인 C | 현실세계 숨겨진 장소 | 3구역 (도달 자체가 열쇠) |

### 축 2 — 이해 축적 (추리)

| 선택 | 결과 |
|---|---|
| 추리를 이어감 | 2·3단계 가설 + 4단계 반전 → 성불/제령 |
| 추리를 하지 않음 | 보조 유품 판매로 생존템 → 소멸 |

## 왕복 구조와 방향 규칙

- 공간 개방은 **양방향 왕복** (사령→현실 힌트 흐름 존재)
- 단, **이해(추리)의 흐름은 현실→사령 단방향**을 유지
- **금지**: 사령 단서가 현실 추리단계(2·3단계 가설)를 여는 트리거가 되는 것

## 소멸의 최소 조건

메인 A만 획득하면 보스방이 열린다. 추리 없이 돌진하면 소멸 엔딩에 도달한다. ([[이해도_4플래그_파이프라인]]의 "보스 도전은 O_reached부터 항상 가능" 유지)

## 배치 제약 (순환 방지)

**N구역을 여는 메인 유품은 N구역보다 앞(현실세계 ~ N-1구역)에만 배치한다.** 뒤에 두면 순환이 발생하므로 금지.

## 준수 사항 (확정 시 적용될 것)

1. 사령 구역은 **메인 유품**으로 연다. **추리 정답을 구역 개방 조건으로 삼지 않는다.**
2. 보스방은 **메인 A 획득 시점부터 상시 개방**한다.
3. 판매용 보조 유품은 **이해 여부와 무관하게 도달 가능한 위치**에 둔다.
4. N구역을 여는 메인 유품은 N구역보다 **앞**에 배치한다.
5. 사령 단서가 현실의 추리 단계를 여는 트리거를 만들지 않는다.

## 이 ADR이 푼 문제 3가지

1. 메인 유품과 사령 구역의 대응 관계 미정의 ([[아이템_위계]] OQ-1에서 미룬 문제)
2. **데드락**: "추리를 맞혀야 구역이 열린다"면 이해 없이는 사령세계 진입 자체가 안 되어 소멸 엔딩이 성립 불가
3. **소멸-판매 루트 데드락**: 판매용 유품이 추리로 열리는 구역 안에 있으면, "이해하지 않으려는 플레이어"가 판매 재료를 못 얻는 순환 발생

## 기각된 대안

| 대안 | 기각 사유 |
|---|---|
| 추리로 구역 개방 | 소멸 엔딩과 충돌 |
| 판매 유품 현실세계만 배치 | "사령에서도 판매 유품 획득" 요구 불일치 |
| 곁길 구역(전투게이트)에 판매유품 | 레벨 복잡도 증가 |
| 메인 유품 여러 개 = 한 구역 | 게이트 조건 복잡화 |

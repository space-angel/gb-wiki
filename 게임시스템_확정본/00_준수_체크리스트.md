# 준수 체크리스트

**Accepted ADR 10건(ADR-1~10)의 Compliance 조항만 뽑은 목록.** 새 설계·문서·구현이 기존 결정을 깨지 않는지 확인할 때 이걸 훑으면 된다.

> 하나라도 위배하는 제안은 **해당 ADR을 명시적으로 Deprecate하거나 Supersede한 후** 진행해야 한다. 조용히 어기면 안 된다.

---

## 이해도 (ADR-1, 2, 9)

- [ ] 이해도가 **플레이어 스탯을 강화**하는 메카닉을 도입하지 않았는가 (데미지·체력·공속)
- [ ] 이해도 수치를 **UI에 직접 노출**하지 않는가 (게이지·진행바·단계 표시·플래그 달성 알림 전부 금지)
- [ ] 챕터 종료 시 챕터별 이해도를 **초기화**하는가
- [ ] 이해도를 **단일 수치·가중 합산**으로 표현하지 않는가 (`U = 0.1·O + …` 형태 금지)
- [ ] O→A→V→R **순서 의존성**을 깨는 트리거가 없는가 (예: O 없이 A 달성)
- [ ] 플래그가 **정확히 4개**인가 (서사 비트를 5번째 플래그로 신설하지 않았는가)
- [ ] 보스 도전 가능 시점을 **이해도 플래그에 종속시키지 않았는가**
- [ ] **잡몹** 패턴·체력·공격력에 이해도 변수를 연동하지 않았는가
- [ ] 이해도 출력의 가시화가 **보스전과 종결 분기**에 집중돼 있는가

## 아이템 (ADR-3)

- [ ] 핵심 아이템이 챕터당 **정확히 3개**이고 **전부 판매 불가**인가
- [ ] 보조 아이템이 챕터당 **10~12개**이고 **전부 관리인 판매 가능**인가
- [ ] O_reached를 **핵심 3개 전부 + 보조 N개 이상의 AND 조건**으로 평가하는가 (핵심 일부만으로 O 판정 금지)
- [ ] 아이템 **등급을 3단계 이상**으로 나누지 않았는가 (핵심/보조 2등급만)
- [ ] 아이템 자체에 **등급 표시**를 두지 않았는가 (슬롯 위치로만 구분)

## 추리 · 재구성 보드 (ADR-4, 5, 6)

- [ ] 재구성 보드가 **4슬롯**(메인유품/보조유품/진술/추리) 구조인가
- [ ] 진행 STEP이 **4단계**인가
- [ ] 핵심 아이템은 **메인 유품 슬롯**, 보조 아이템은 **보조 유품 슬롯**에 배치되는가
- [ ] A 단계 가설이 **정답 1 + 오답 2의 3지선다**인가
- [ ] 두 오답이 **서로 다른 방향**으로 그럴듯한가
- [ ] 한 NPC가 **A 단계 또는 V 단계 중 하나에만** 핵심 진술자로 배치됐는가
- [ ] 케이스당 **A 단계 NPC 2명 이상, V 단계 NPC 2명 이상**인가

## 세계 · 공간 (ADR-7, 10)

- [ ] 사령세계가 **메트로배니아 구조**인가 (선형 진행 챕터 추가 금지)
- [ ] 보스방이 **탐색 영역과 분리된 독립 공간**인가
- [ ] 보스 도전이 **첫 진입부터 가능**한가
- [ ] 현실세계 = **사이드뷰**, 사령세계 = **탑다운뷰**인가
- [ ] 두 세계 전환 시 **카메라 시점 전환 연출**이 있는가
- [ ] 컷신이 **별도 레이어 방식**으로 처리되는가

## 전투 (ADR-8)

- [ ] **패링·가드 메카닉**을 추가하지 않았는가
- [ ] 회피가 **무적 판정**을 가지며 다른 액션을 **캔슬**할 수 있는가
- [ ] 보스 패턴이 **회피 타이밍 변주**로 설계됐는가

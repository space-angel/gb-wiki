# 전투 톤 — 가벼움 + 회피만

## 결정 3줄

1. **전투 톤 = 가벼움 + 회피 위주** — 하데스류 빠른 템포. 한 대가 치명적이지 않다.
2. **방어 시스템 = 회피만** — 패링·가드 **제외**. 회피는 **무적판정 + 캔슬 가능**.
3. **잡몹 = 단순노동형** — "회피로 무적판정 만들고 계속 때리기". **깊이 있는 전투는 보스 한정.**

## 절대 규칙

1. **패링·가드 메카닉을 추가하지 않는다.**
2. 회피는 **무적 판정**을 가지며 다른 액션을 **캔슬**할 수 있다.
3. 보스 패턴은 **회피 타이밍 변주**로 설계한다.

## 왜 가벼운 전투인가

- 4인 인디 캐파에 맞춘 구현 부담 감소
- 메트로배니아 코어 쾌감([[사령세계_구조]])과 정합
- [[이해도_정의와_출력]]의 "보스 패턴 가시성"과 정합 — 가벼운 액션톤에서 "읽는" 플레이가 더 명확해진다

게임의 주정서는 **"이해"이지 "도전"이 아니다.** 소울라이크 팬층 기대 미충족은 **의도된 방향**이다.

## 비용
방어 옵션이 회피 하나뿐이라 보스 패턴 다양성이 제한된다 → 보스 디자인은 **회피 타이밍 변주**에 집중해야 한다.

## 기각된 대안

| 대안 | 기각 사유 |
|---|---|
| 무거운 전투(소울라이크) | 구현난이도↑, 템포 깨짐 |
| 회피 + 패링 | 패링 프레임 처리 복잡 |
| 회피 + 가드 | 가드 방향처리 + 스태미너 추가 필요 |
| 방어 없음 | 단순 DPS 경쟁, 패턴학습 의미 약함 |

## 잡몹과 이해도

잡몹은 **이해도와 완전 무관**하다(→ [[이해도_정의와_출력]]). 동일 패턴·동일 약점의 평타 처리다.
챕터별 잡몹 유형 강화 변형은 **챕터 설계 영역**으로 가능하나, 이해도 변수를 연동해서는 안 된다.

# 이해도 내부 표현 — 4종 이산 플래그 파이프라인

## 자료 구조

이해도는 **4개의 boolean**이다. 단일 수치도, 가중 합산도 아니다.

```
O_reached → A_reached → V_reached → R_reached
 (관찰)       (연결)       (검증)       (재해석)
```

**순서 의존적**: 이전 플래그가 true여야 다음 플래그 달성이 가능하다.

| 플래그 | 이름 | 현실세계 행동 |
|---|---|---|
| O_reached | 관찰 | 탐색, 아이템 획득 |
| A_reached | 연결 | 보드 연결, 가설 선택 |
| V_reached | 검증 | NPC 대화, 교차검증 |
| R_reached | 재해석 | 핵심 아이템 보드 연결 |

각 단계의 구체적 달성 조건은 [[이해도_판정_트리거]](ADR-12, 미확정)에서 다룬다.

## 엔딩 분기 매핑

| 엔딩 | 플래그 조건 |
|---|---|
| **성불** | O + A + V + R 전부 true |
| **제령** | O + A + V true, R false |
| **소멸** | O + A false, 또는 보조 아이템 판매로 A 미달 |

> ⚠️ 이 매핑은 ADR-2에 적혀 있으나, 트래커 "임계값 컷오프 정의"는 아직 **미결** 상태다 — 매핑안 자체는 있는데 팀 합의·ADR 등록이 안 됐고, 중간 상태(O만 true 등) 전 구간이 명시되지 않았다. → [[미결_현황]]

## 보스 도전 가능 시점

**O_reached 시점부터 항상 가능.** 이해도 플래그와 무관하다.
메트로배니아 구조 원칙(첫 진입부터 보스 도전 가능)을 유지한다. 이해도는 **종결 방식**을 바꿀 뿐, 도전 자체를 막지 않는다.

## 절대 규칙

1. **이해도를 단일 수치로 표현하는 메카닉을 도입하지 않는다.** (`U = 0.1·O + 0.2·A + …` 같은 가중 합산 금지)
2. **4종 플래그의 순서 의존성을 깨는 트리거를 만들지 않는다.** (예: O 없이 A 달성)
3. **보스 도전 가능 시점을 이해도 플래그에 종속시키지 않는다.**
4. **5단계 이상으로 늘리지 않는다.** 서사적으로 필요한 중간 비트(예: "기대가 부담이 됨")는 **연출 비트**로 처리하고 플래그로 신설하지 않는다.

## 왜 가중 합산을 버렸나 — 이 결정의 핵심

가중 합산 모델에서는 **R 점수가 0이어도 다른 축 합으로 성불 임계값에 도달**할 수 있다. 즉 "재해석 없이 성불"이 이론상 가능해진다.

4종 플래그 AND 조합은 이걸 **데이터 구조 자체로 차단**한다. R 없이는 성불이 불가능하다. 이게 이 결정의 가장 큰 이득이다.

부수 효과: 가중치 수치 설계 불필요 · 임계값 컷오프 수치 결정 불필요 · 구현이 bool 4개 체크로 끝남 → Phase 0 작업량 감소.

## 알려진 위반 (기록)

> 재화의 서사 문서가 O-A-V-**X**-R 5단계를 사용 중이었다. X는 플래그가 아니라 **연출 비트**로 흡수해야 한다.

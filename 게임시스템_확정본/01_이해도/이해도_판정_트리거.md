# ⚠️ 이해도 판정 규칙 — 4단계 트리거 (미확정)

> **Proposed 상태.** 2026-07-20 논의에서 도출, 48시간 룰 적용 중 · 안지호 최종 확인 대기.
> [[이해도_4플래그_파이프라인]](ADR-2, 확정)이 정의한 O→A→V→R 각 단계의 **구체적 달성 조건**을 채우는 문서다. 구조는 확정, 트리거는 미확정.

## 단계별 판정 조건

| 단계 | 트리거 | 판정 조건 | 관련 슬롯 |
|---|---|---|---|
| **1단계 (O)** | 보조 유품 수집 | 보조 유품 **N개 이상** 확보 (판매분 제외) | 보조 유품 슬롯 |
| **2단계 (A)** | 핵심 유품 제시 (조사+제시 통합) | 대상 NPC에게 제시 완료 | 진술 슬롯 |
| **3단계 (V)** | 회상 공간 진입·기억 확인 | 대응 회상 공간에서 기억 확인 완료 | 추리 슬롯(선택지 개방) |
| **4단계 (R)** | 보드 4슬롯 조합 + 가설 선택 | 4슬롯 전부 충족 상태에서 **3지선다 중 정답 선택** | 전체 슬롯 |

## 4단계 최종 판정 — 통합됨

"단서 3개 조합"은 **별도 로직이 아니다.** 재구성 보드의 핵심 유품 슬롯을 채우는 절차일 뿐이다.
4단계 최종 판정은 **4슬롯 충족 상태에서 3지선다 정답 선택**이라는 **단일 행위**다. (이중 판정 구조 해소)

## 인벤토리 참조 제약

**1단계 이후(2~4단계)는 인벤토리를 전혀 참조하지 않는다.** → [[3계층_분리]]

## 최종 증인(어머니) 증언의 위치

어머니 증언은 **진술 슬롯 게이트가 아니다.** **4단계 정답 선택 이후 재생되는 리워드 컷씬**으로 확정.

## 오답 처리

3지선다 유지, 오답 시 **명시적 표시나 즉각 페널티 없음**. 보드가 닫히고 재시도 가능. **1~3단계 플래그는 오답으로 초기화되지 않는다.** → 상세 [[오답_처리]]

## 보조 유품 배치 및 페어링

보조 유품은 **현실세계·사령 1구역에 집중 배치**(1단계 초반 완료). 핵심 유품과 서사적으로 페어링하되 **시스템적 해금 의존은 만들지 않는다.**

## 보스방 개방 조건

보스방은 1단계 완료가 아니라 **메인 유품 A 획득 즉시** 상시 도전 가능. ([[공간_개방_규칙]] §2.5와 정합)

## 준수 사항 (확정 시 적용될 것)

1. **2단계 이후 판정은 인벤토리를 참조하지 않는다.**
2. 4단계 판정은 **4슬롯이 모두 충족된 상태에서만** 3지선다를 제공한다.
3. 오답 선택 시 **명시적 실패 피드백이나 페널티를 주지 않는다.**
4. 어머니 증언은 **진술 슬롯에 등록하지 않으며**, 4단계 정답 선택 이후에만 재생한다.
5. 보스방은 메인 A 획득 시점부터 상시 개방하며, **1단계 완료 여부를 조건에 넣지 않는다.**

## 미해결 항목 (ADR 원문 OQ)

| OQ | 내용 | 현황 |
|---|---|---|
| OQ-1 | **1단계 임계 개수 N** | 유품 전수 목록 확정 전까지 **6**으로 변수 유지. 트래커 `1단계O_임계값N정의`(미결, P1)와 동일 항목 |
| OQ-2 | 오답 재시도 횟수 제한 여부 | ✅ **ADR-14에서 해소(무제한)** → [[오답_처리]] |
| OQ-3 | 어머니 증언 등록 시점 | ✅ 본 문서 "최종 증인" 항에서 해소 |
| OQ-4 | 메인A 페어링 보조 2개, 메인B/C 각 1개(총 4개) 신규 설계 | ⬜ 미해결 |
| OQ-5 | 파일철·이동장 획득 위치를 ADR-11 체이닝 구조에 맞춰 재화 문서 재작성 | ⬜ 미해결 — 단, ADR-11 자체가 스토리 자료와 충돌 중이라 선행 결정 필요 |

## 기각된 대안

| 대안 | 기각 사유 |
|---|---|
| 4단계를 "단서 3개 조합"만으로 판정 | 이중 판정 구조 발생 |
| 오답 즉시 "오답" 표시 | Obra Dinn식 침묵 설계와 충돌 |
| 조사·제시 별개 단계 | 파이프라인이 5~6단계로 늘어나 ADR-2 위반 |
| 어머니 증언 3단계 배치 | "최종 증인 = 4단계" 전제 충돌 |
| 보스방 O_reached 이후 개방 | ADR-11 §2.5와 충돌 |

## 비용
- 2단계 조사+제시 통합 UI 신규 설계 필요
- 어머니 증언 리워드 컷씬 연출 분량 증가
- "보조 유품 페어링은 배치일 뿐 시스템 의존이 아니다"를 작가와 반복 커뮤니케이션해야 함

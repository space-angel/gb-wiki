# 아이템 위계 — 핵심/보조 2등급

## 위계 = 2등급뿐

S/A/B 3등급 체계는 **기각**됐다. 시스템상 필요한 구분은 하나 — **판매 가능 여부**다.

### 핵심 아이템
고인의 본질에 닿는 물건. 사건의 진실과 직결.

| 속성 | 값 |
|---|---|
| 판매 가능 여부 | **불가** |
| 보드 연결 필수 여부 | 필수 |
| 발견 시 효과 | 사령세계 해당 영역 잠금 해제 |
| 조합 시 효과 | 표층→심층 상태 전환 트리거 (R_reached) |
| **챕터당 수량** | **정확히 3개** |

### 보조 아이템
주변 정황을 구성하는 물건.

| 속성 | 값 |
|---|---|
| 판매 가능 여부 | **가능** (관리인 NPC에게) |
| 보드 연결 | 선택 |
| 발견 시 효과 | 없음 |
| 연결 시 효과 | O→A→V 플래그 진행 재료 |
| 판매 시 효과 | 생존성 아이템 획득 (**소멸-아이템 루트**) |
| **챕터당 수량** | **10~12개** |

→ 챕터당 총 13~15개.

## 시각 구분 = 슬롯 위치로만

핵심/보조의 시각 구분은 **재구성 보드의 슬롯 위치**로 표현한다. **아이템 자체에 등급 표시를 두지 않는다.** (아트 작업량 폭증을 막기 위한 결정)

## O_reached 판정 조건

**AND 조건**이다.

1. 챕터 내 **핵심 아이템 3개 전부** 발견 (보스방 전용 핵심 포함)
2. 챕터 내 **보조 아이템 N개 이상** 발견

N은 케이스별 작가 설계값. 김태현 케이스 기준 6~8 권장. **N의 정식 값은 아직 미결** → [[미결_현황]]

## 절대 규칙

1. 핵심 아이템은 챕터당 **3개**를 두고, **모두 판매 불가**로 설정한다.
2. 보조 아이템은 챕터당 **10~12개**를 두고, **모두 관리인 판매 가능**으로 설정한다.
3. O_reached는 **핵심 3개 전부 + 보조 N개 이상의 AND 조건**으로 평가한다. (핵심 일부만으로 O 판정 금지)

## 기각된 대안 (재논의 방지)

| 대안 | 기각 사유 |
|---|---|
| 3등급 (S/A/B) 유지 | 시스템상 핵심/보조만 구분되면 충분 |
| 챕터당 핵심 2개 | 표층/심층 반전 구조 지탱에 부족 (재화 의견) |
| 보스방 전용 핵심을 O에서 제외 | 케이스마다 별도 설계 필요, 표준 흔들림 |
| 아이템 자체 등급 표시 | 아트 작업량 폭증 |

## 미해결 — OQ-1: 핵심 3개와 "메인 유품"의 관계

ADR-3 시점에는 "핵심 아이템 3개"와 [[공간_개방_규칙]]의 "메인 유품"이 같은 것인지 정리되지 않았다.

| 가능성 | 내용 |
|---|---|
| A | 핵심 3개 모두가 "메인 유품" |
| B | 핵심 3개 중 1개만 "메인 유품"(보스방 해금), 나머지 2개는 일반 핵심 |
| C | "메인 유품"·"핵심"·"보조" 3등급 분류 |

**현황**: ADR-11(Proposed)이 §2.1에서 **A안**(메인 유품 1개 = 사령 구역 1개, 1:1)을 사실상 채택했다. ADR-11이 Accepted로 전환되면 이 OQ는 종결된다.

## 알려진 위반 (기록)

> — 현황: `raw/03_진단문서/세계관자료_확정시스템_어긋남.md` §A에서 "5개 중 3개를 메인, 2개를 보조로 재분류"로 결론. 다만 **최신 스토리 문서의 메인 3종(졸업사진/핸드폰/취준파일)이 ADR-13 리스트와 다른 별도 이슈**가 있다 → `챕터1_스토리_최신본/_INDEX.md` 확인 필요 사항 §1.

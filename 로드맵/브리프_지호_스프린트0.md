# 스프린트 0 브리프 — 지호

> **한 줄**: Linear D트랙 12개 중 지호 담당. 순서 중요 — 아무거나 먼저 잡지 말고 아래 순서대로.

## 왜 이 순서인가

D트랙은 서로 의존 관계가 있다. **번호 정리(D7)를 제일 먼저 안 하면 나머지 작업 중에 또 이슈가
꼬인다** — 지난번에 이미 D1·D2가 각각 두 이슈에 중복 배정돼 있던 걸 발견하고 정리했다(`GBG-160`
취소, `154→D3`, `155→D10`). 그리고 **D2(C-1 갈림)가 최우선인 이유**는, 이게 안 풀리면 사령세계
레벨디자인 자체가 시작을 못 해서 스프린트 0 이후 전체 일정이 밀린다.

## 순서

### 1순위 — `GBG-191` E0-D7. ADR 번호 체계를 통합한다

**배경**: Notion에 ADR DB가 신규/구버전 두 곳에 중복 존재한다(`raw/00_컴플라이언스/노션_위치_지도.md`
§3). Linear D트랙 번호도 이번에 두 번 겹쳤던 전례가 있다(D1·D2 중복 — 이미 정리는 했음).

**할 일**: Notion의 신규 ADR DB(`collection://3b18826f-8563-8078...`)와 구버전 ADR DB
(`collection://3888826f-8563-8061...`)의 14건씩을 대조해서 내용이 동일한지 확인하고, 하나로
합친다(보통 신규 쪽을 정본으로, 구버전은 아카이브 처리).

**완료 기준**: ADR DB가 한 곳만 남는다.

### 2순위 — `GBG-186` E0-D2. 챕터1 진행 게이트 순서를 확정한다 🚨

**배경**: `게임가이드/6_현황/06-03_검토-필요.md` C-1. 재화(동시 노출: 메인 유품 3개 초반 다 노출,
각자 독립적으로 구역 개방)와 지호(ADR-11: 순차 체인, 메인A로 1구역 열고 그 안에서 메인B 획득)가
서로 확인 없이 각자 결정한 상태로 충돌 중.

**막고 있는 것**: 레벨디자인 전제가 통째로 갈리는 지점. 맵 설계가 이거 없이 못 나가고, 맵이 없으면
이해도 N값(`GBG-190`, D6과 별개 트래커)도 못 정하는 연쇄.

**할 일**: 재화와 직접 맞춰서(`#0_결정논의_큐`) 둘 중 하나로, 또는 절충안으로 확정. `ADR-11`을
Accepted로 전환하거나 새로 개정.

**완료 기준**: `06-03` C-1 갈림 해소, `ADR-11` 상태 확정.

**참고**: N값(1단계 O 임계) 관련 `raw/00_컴플라이언스/트래커/1단계O_임계값N정의.md` — `ADR-15`

**완료 기준**: `ADR-12` Accepted 전환, `01-04` 상태를 확정으로 갱신.

### 4순위 — `GBG-187` E0-D3. 핵심 유품 3종을 확정한다

**배경**: `06-03` C-2. 메인유품 명칭이 문서마다 4가지 버전으로 갈려있었는데, **재화가 08-17 공유한
결정로그가 이미 "졸업사진(과거)/핸드폰(현재)/취준파일(미래)"로 확정**해뒀다. 지호 쪽은 `ADR-13`

**완료 기준**: `ADR-13`을 재화안에 맞게 개정하거나, 지호가 반대 의견이면 `#0_결정논의_큐`에서 재논의.

### 6순위 — `GBG-190` E0-D6. 판매 임계 수식을 확정한다

### 7순위 — `GBG-176`/`GBG-177` E0-D11/D12. NPC A/V 배정, 축-플래그 매핑

이번에 새로 만든 이슈(원래 `06-03`의 C-3·C-4 갈림인데 Linear에 대응 이슈가 없었음). 개발 착수를
막는 블로커는 아니라 시간 되면 Sprint 0 안에, 안 되면 Sprint 1 진행 중에 병행해도 무방.

⚠️ **단, D11(NPC A/V 배정)은 재화 쪽 입력이 먼저 필요하다.** 재화 01번 결정로그 §15에 "이유미·어머니
상세 진술 구조, NPC별 해금 조건"이 지금 "추가 정리 필요"로만 남아있어서, 그게 채워지기 전엔 A/V를
배정할 근거 자체가 없다 — 재화한테 먼저 이 부분을 물어보고 시작할 것 (`로드맵/브리프_재화_스프린트0.md`
§3에 같은 내용 전달해뒀음).

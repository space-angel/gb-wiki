# 스프린트 1 — 현실세계를 걷는다

> **한 줄**: 원룸을 실제로 걸어다니는 빌드 하나로 개발·아트가 합쳐지는 게 이 스프린트의 유일한 목표다. 스토리는 이미 확정된 `04-03`(현장 구조) 검토만 하면 된다.

## 왜 이 스프린트인가

이전엔 "호윤은 개발, 재화는 문서, 정인은 아트"가 3개월 내내 따로 도는 구조였다. 그러다 보니 3개월 뒤에도 서로 안 맞물린 산출물만 쌓일 위험이 있었다. 대신 **Linear의 기존 트랙(E1-A~F)을 스프린트 경계로 삼아서**, 매 스프린트마다 "이 기능 하나가 실제로 굴러가는 빌드"를 완료 기준으로 삼는다.

E1-A(현실세계를 걸어다닐 수 있다)가 첫 스프린트인 이유: 이후 모든 스프린트(줍기·인벤토리·관찰·NPC 대화)가 "걸어다니는 원룸" 위에서 동작해야 하므로, 이게 없으면 아무것도 통합 테스트를 못 한다.

## 선행 조건 — 스프린트 0

지금 진행 중인 작업을 스프린트1이 시작 가능한 상태로 마무리하는 게 스프린트 0다. 4개 트랙(호윤·재화·정인·지호)의 완료 기준은 → **`로드맵/스프린트0_기반다지기.md`** 참조.

스프린트 0의 완료 기준이 다 채워지는 시점(대략 2~3주 후)이 스프린트 1의 실제 시작점이다.

## 범위 — Linear 이슈 (이미 존재, 새로 안 만듦)

| 이슈 | 담당 | 내용 |
|---|---|---|
| `E1-A` | — | 현실세계를 걸어다닐 수 있다 (상위 항목, 아래 4개 T가 완료되면 자동 완료) |
| `E1-A-T1` | 호윤 | 사이드뷰 이동 컨트롤러 (좌우 이동 + 충돌) |
| `E1-A-T2` | 호윤 | Cinemachine 카메라 + 방 경계 컨파인 |
| `E1-A-T3` | 정인 | 현실세계 사이드뷰 도면 (레이아웃) |
| `E1-A-T4` | 정인 | 원룸 배경·바닥·벽 타일 |

**스토리 쪽엔 이 스프린트용 신규 작업이 없다.** 현장 구조(`게임가이드/5_예제/04-03_현장-구조.md`)가 이미 확정 상태라, 재화는 T3(도면) 작업 시 정인이 참고할 수 있게 검토만 해주면 된다.

## 진행 순서 제안

1. **T3(도면)이 먼저** — T1(컨트롤러)·T4(타일)가 참고할 기준이 필요함
2. T1과 T4는 병렬 가능 (서로 안 막음)
3. T2(카메라)는 T1 이후 — 캐릭터가 움직여야 카메라 컨파인을 테스트할 수 있음
4. 넷 다 끝나면 **합쳐서 확인**: 원룸 안에서 실제로 걸어다니는 빌드

## 완료 기준 (Definition of Done)

- [ ] `04-03`에 서술된 7~8평 원룸 + 중문 구조가 실제 씬으로 존재한다
- [ ] 좌우 이동 + 벽/오브젝트 충돌이 동작한다
- [ ] 카메라가 방 경계를 벗어나지 않는다
- [ ] 배경·바닥·벽 타일이 러프가 아닌 적용본으로 들어가 있다
- [ ] 4개 담당자(호윤·정인, 재화는 검토만)가 같은 빌드에서 확인 완료

## 이 스프린트가 안 다루는 것

- 유품 줍기·인벤토리 → 스프린트 2
- NPC·대화 → 스프린트 3
- 사령세계·전투 → C-1(사령세계 획득구조) 갈림이 회의로 안 풀리면 3개월 안에 시작 불가 (`게임가이드/6_현황/06-03_검토-필요.md` C-1 참조)

# 맵 디자인 레퍼런스

**본문 텍스트는 한 줄뿐이고 나머지는 전부 이미지다.** 이미지는 마크다운으로 옮길 수 없으므로 Notion 원본에서 직접 확인해야 한다.

## 원문 텍스트 (전부)

> 중문을 기준으로 현관과 방이 나뉜 원룸으로 상세 작성. 현실성을 고려해 약 **7~8평**으로 구성해봄

## 첨부 이미지 구성 (Notion 원본에서 확인)

| 토글 섹션 | 이미지 수 | 비고 |
|---|---|---|
| 톤 앤 무드 | 1장 | |
| 원룸 내부 (탑다운뷰) | 2장 | |
| 원룸 내부 배경 (사이드뷰의 경우) | 1장 | 원문 주석 "화질구림" |
| 원룸 외부 | 2장 | 원문 주석 "화질구림" |

> **참고**: 탑다운뷰와 사이드뷰 레퍼런스가 **둘 다** 준비돼 있다. 시스템 결정(ADR-10)은 현실세계=사이드뷰 / 사령세계=탑다운뷰인데, 이 문서는 현실세계(원룸) 레퍼런스를 양쪽 시점으로 모두 모아둔 상태라 어느 쪽을 채택할지 확정 전인 것으로 보인다.

# 미래 조사축 — 취준 파일

세 축 중 **진도가 가장 빠른 축**. 보조유품 2개 후보가 유일하게 나와 있어, 나머지 두 축 작성의 기준이 될 예정이다([[00_확정메모_및_작업계획]] 작업계획 4번).

| 항목 | 내용 |
|---|---|
| 메인 유품 | **취준 파일** |
| 최초 플레이어 인식 | 취업 실패한 백수 |
| 조사 목적 | 얼마나 버티려고 했는가? |
| 연결 사령세계 | 사령세계 3 |
| 사령세계 감정 | **노력 / 좌절** |
| 획득 보조유품 | ① 면접 일정 가득한 다이어리 ② 반복된 드라이클리닝 영수증과 면접 정장 |
| 현실 탐문 NPC | 상담사 |
| NPC 최초 진술 | "컨설팅 받는거 치곤 방문이 뜸했어요." |
| NPC 재인식 | "끝까지 포기하지 않았어요." |
| 무너지는 오판 | 아무것도 하지 않았다. |
| 최종 재해석 | 실패했지만 계속 살아보려 했던 사람이었다. |
| **이해도 기여** | **V** |

## 작업 메모 (원문)

> 미래축 보조유품 작성중. 보조유품들은 각각 **노력과 좌절**을 보여줘야 한다.
>
> **현재 거의 확정 후보**
> - 면접 일정이 빼곡한 다이어리 (노력)
> - 반복된 드라이클리닝 영수증과 면접 정장 (좌절)
>
> 이를 바탕으로 나올 수 있는 사령세계 3의 연출 — **"끝나지 않는 면접."**
> ← 떠오르는 거 패턴, 맵구조, 이런 거 토론 필요.
>
> 나는 이 다음으로 이 미래 조사축에 맞게 **상담사 NPC 시트를 완성**해보겠음.

## 상태
- ✅ 확정: 메인유품, NPC, 감정, 오판, 재해석
- 🔶 거의 확정: 보조유품 2개 (노력/좌절 대응)
- ⬜ 미정: 환경단서, 정보단서, 사령세계 3 오브젝트·패턴·맵구조, 조사 완료 조건
- 📌 다음 작업: 상담사 NPC 시트 완성

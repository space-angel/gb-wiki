## TL;DR
1. **이해도 = 4종 이산 플래그 파이프라인(O→A→V→R)로 잠금**
가중 합산 스칼라 모델은 기각. R 플래그 없이는 성불 불가 = 구조 레벨 강제
2. **핵심/보조 아이템 수량 표준 확정: 챕터당 핵심 3 + 보조 10~12**
O_reached 판정엔 핵심 전부 발견 필수 (보스방 전용 핵심도 포함)
3. **가설 선택지 = 3지선다(정답 1 + 매력적 오답 2) 고정**
작가 부담(오해 N개 + NPC 3벌 대사 + 컷신 N개) 현실성도 재화가 확인

## 논의 맥락 (Context)

### 1. 5분 전제 공유 — 시스템 절대 원칙 재확인

> **정량(카운트·플래그·수치)은 플레이어에게 일절 비노출.** 진행은 오직 NPC 대사 전환·영역 잠금/해제·연출로만 체감, **대사와 아트 연출이 곧 유일한 UI**

- 이해도 게이지 UI ❌
- 단계 진행 표시 ❌
- 플래그 달성 알림 ❌
- 작가가 쓴 NPC 대사·아트가 만든 환경 변화만이 유일한 피드백 채널

### 2. 핵심/보조 위계 — 케이스 작업의 뼈대 (D1~D4)

### D1: 챕터당 수량 표준
ADR-003 기본값은 핵심 "2~3개"였으나 케이스 1 김태현 가정으로 **핵심 3 / 보조 10~12**로 확정.

**논의 포인트**
- 핵심 2개는 표층/심층 반전 구조를 지탱하기엔 부족
- 스토리 자료 S급(2개: 전역 카톡 / 미전송 문자) + A급(4개) + B급(5개)을 어떻게 핵심 3 / 보조 10~12로 재배치할지는 재화 후속 작업 (A1)

### D3: O_reached 판정 규칙 — "전부 발견"으로 못박은 이유

쟁점:
- (안) 보스방 전용 핵심 아이템은 O 카운트에서 제외
- (안) 핵심 아이템 전부 발견해야 O 성립

> 보스방 전용 핵심을 O에서 빼면 케이스마다 "어떤 핵심이 O 카운트에 들어가나?"를 작가가 별도 설계해야 함. **케이스 작성 표준이 흔들린다.** 그냥 "핵심 전부 = O" 원칙이 표준화에 적합

### D4: 슬롯 방식 — 정인 작업량 줄이기

쟁점:
- (안) 아이템 자체에 등급 표시 (테두리 색, 아이콘 등)
- (안) 슬롯 위치로 구분 (재구성 보드에서 메인 슬롯 vs 보조 슬롯)

정인 의견 (채택):
> 등급 표시면 모든 아이템 스프라이트에 등급 표현이 들어가야 함. **슬롯 방식**이면 아이템 스프라이트는 단일 톤으로 가능 → **아트 작업량 대폭 감소**

재구성 보드 명세 문서의 4슬롯 구조(D7)와도 자연스럽게 정합

### 3. 오해 시스템 — 작가 부담 검증 (D5, D6)

### D5: 3지선다 확정 사유

쟁점:
- (안) 2지선다 (정답/오답)
- (안) 3지선다 (정답 + 오답 2)

**3지로 채택한 사유:**
- 2지선다는 "찍기" 비율 50% → 추리 게임으로서 무가치
- 4지 이상은 작가 오답 설계 부담 폭증
- 3지가 "오답 2개를 서로 다른 방향으로 그럴듯하게" 만들기 적합 = 추리의 깊이 ↑

### D6: 작가 추가 창작 부담 — 재화가 직접 검증

> 표층/심층 감정 반전은 어차피 써야 할 내용. 추가 부담은 "오답 설계 + 중층 1벌"에 가깝다

재화 답변 (스토리 자료 초안 기반):
- NPC 4명의 첫 인상/재해석은 이미 작성 완료 (집주인/이유미/상담사/어머니)
- 표층(첫 인상) → 심층(재해석)의 2벌은 자연 작성됨
- 오해 상태일 때의 대사. 이건 케이스 작성하면서 자연 추출 가능

→ **"케이스당 현실적 부담"으로 확정.** 단, 케이스 2~N 작성 시 재화 페이스 봐서 재조정 여지

### 4. 재구성 보드 메카닉 (D7, D8)

지호 별도로 작성한 재구성 보드 명세를 회의에서 공유.

### D7: 4슬롯 구조 채택

| 슬롯 | 역할 | 입력 | 효과 |
|---|---|---|---|
| 메인 유품 | 사건 진행 핵심 | 현실세계 탐색 | 사령세계 영역 해금 |
| 보조 유품 | 삶/상태 이해 | 현실세계 탐색 | 메인 의미 확장 / 가설 변화 |
| 진술 | 인물 관점 | NPC 대화 | 단계별 심층 진술 해금 |
| 추리 | 가설 생성 | 위 3종 조합 | 해석 → 가설 |

ADR-003의 핵심/보조 위계 + 입력 행위 정의가 이 4슬롯 안에 그대로 매핑됨 → **시스템 ADR과 UX가 자연스럽게 정합**

### D8: A단계 NPC ≠ V단계 NPC

재구성 보드 명세 문서의 "중요 규칙" 그대로 채택

> 같은 인물이 계속 정보를 제공할 경우, 플레이어의 이해 과정이 단순 정보 획득으로 변한다.

김태현 케이스 적용 (잠정):
- A단계 (초기 행동 이유 추론): 집주인 / 이유미 → "왜 이렇게 살았는가?"
- V단계 (최종 감정 검증): 상담사 / 어머니 → "왜 끝까지 말하지 못했는가?"

R_reached NPC 지정 규칙(D7)이 미결로 남은 이유 = 이 NPC 분리 원칙과 R 트리거 NPC가 어떻게 정합되는지 안지호의 추가 1pager 필요 (A6)

### 5. 케이스 1 = 김태현 풀스펙 진행 확정 (D9, D10)

재화의 스토리 자료 초안 공유

**김태현 캐릭터 골격:**
- 30세 자살. 사회적 무너짐류 고독사. (6/1 D3 적용)
- **표층**: "사회가 죽인 청년"
- **심층**: "아무도 그를 버리지 않았지만, 그 역시 아무에게도 진실을 보여주지 못했다"
- "이 사람의 마지막 선택을 내가 대신 내려줘야 하는가?"

**NPC 4명 + 해석 충돌:**
- 집주인 (표층 가설) ↔ 어머니 (최종 진실)
- 이유미 (첫 재해석) ↔ 상담사 (심층 해석)

**플레이어 감정 5단계:**
1. 무기력한 백수 → 2. 노력한 사람 → 3. 오래 버틴 사람 → 4. 끝까지 말 못한 사람 → 5. 이해와 씁쓸함

이 구조가 ADR-002의 O→A→V→R 플래그와 1:1 대응. **시스템과 스토리가 같은 뼈대 위에 올라가 있음.**

### D10: 케이스 작성 표준 워크플로

```
① 고인 표층/중층/심층 감정 3단 + 반전 한 줄 정의
② 핵심 3 / 보조 10~12로 아이템 위계 배분
③ 단계별 보드 연결 조합 → 가설(정답1+오답2) 설계
④ 오해 1개 지정 + NPC 3벌 대사 (표층/중층/심층)
⑤ 엔딩 체크리스트로 4루트(성불/제령/소멸-피지컬/소멸-아이템) 막힘 검증
```

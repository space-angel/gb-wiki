**Aseprite 무료로 설치하기 (Mac)**

> Aseprite는 원래 유료 프로그램이지만, 소스 코드가 공개되어 있어서 직접 빌드하면 무료로 쓸 수 있음! 어렵게 들릴 수 있는데 → 실제로 해보면 별거 없으니께 쫄지말고 천천히 해봅시다

---

## 0. 시작 전에 준비할 것 `3가지 다운로드`

**1. Aseprite 소스 코드**
https://github.com/aseprite/aseprite/releases
페이지 들어가서 가장 위에 있는 버전 찾기 → **`Aseprite-v1.x.x.x-Source.zip`** 클릭해서 다운로드
(이미지 — Notion 원본 S3 서명 URL, 만료됨. 원본 페이지에서 확인: https://app.notion.com/3488826f8563800ead52d4d19a165a19)
> 숫자(버전)는 달라도 괜찮음 → 가장 최신 걸 받기

**2. Skia 패키지**
https://github.com/aseprite/skia/releases
여기서는 **내 Mac 종류에 맞는 파일**을 받기. 애플실리콘이면 **`Skia-macOS-Release-arm64.zip`** ← 요고 다운받으셈
(이미지 — 만료됨)

**3. Homebrew**
> Homebrew는 Mac에서 개발 도구들을 쉽게 설치할 수 있게 해주는 프로그램. 나중에도 유용하게 쓰임
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
**복사해서 터미널에 붙여넣으면 설치**

> **터미널**은 Mac에 기본으로 설치된 앱 → Spotlight(돋보기 아이콘 또는 `⌘ + 스페이스`)에서 "터미널" 검색하면 나옴

## 1. **다운로드한 파일 압축 풀기**

다운로드 폴더에 있는 두 파일을 더블클릭해서 압축 풀어.
- `Aseprite-v1.x.x.x-Source.zip` → 더블클릭
- `skia-xxx.zip` → **더블클릭**

압축이 풀리면 폴더 두 개가 생겨. 그냥 다운로드 폴더에 놔두면 돼

---

## 2. **설치 시작 (터미널에서)**

> **터미널**은 Mac에 기본으로 설치된 앱 → Spotlight(돋보기 아이콘 또는 `⌘ + 스페이스`)에서 "터미널" 검색하면 나옴

#### 2.1. 컴파일러 설치

터미널을 열고 아래를 **그대로 복사해서 붙여넣기** 하고 엔터

`xcode-select --install`

팝업창이 뜨면 **설치** 클릭. 1GB 정도라 금방 끝남 - 완료될 때까지 기다리기

#### 2.2. cmake랑 ninja 설치

컴파일러 설치 완료되면, 이어서 아래도 복사해서 붙여넣기 하고 엔터

`brew install cmake ninja`

설치되는 동안 뭔가 주르륵 나와도 괜찮으니까 끝날 때까지 기다려

#### 2.3. **Aseprite 폴더로 이동**

터미널에 `cd ` 를 입력해. (cd 뒤에 **스페이스 한 칸** 있어야 함)
그 상태에서 — 더 입력하지 말고 — **압축 푼 Aseprite 폴더를 터미널 창으로 드래그**해서 놓기
폴더 경로가 자동으로 입력돼 → `엔터`

#### 2.4. 빌드 스크립트 실행

```bash
./build.sh
```
복사해서 붙여넣고 `엔터`

#### 2.5. 질문에 답하기

스크립트가 실행되면서 질문이 두 개 나와

**첫 번째 질문 — User인지 Developer인지**
```bash
[U/D]?
```
→ `U` 입력하고 엔터 (우리는 그냥 쓰는 사람이니까)

**두 번째 질문 — Skia 폴더 위치**
```bash
Select Skia directory to create [...]:
```
→ 이번에도 직접 입력하지 말고, **압축 푼 Skia 폴더를 터미널 창으로 드래그**해서 놓고 엔터

#### 2.6. 빌드 기다리고 실행하기

자동으로 빌드가 시작 → 몇 분 걸려 // 터미널에 뭔가 계속 올라오는 게 정상이니까 끝날 때까지 그냥 놔두기
완료되면 Aseprite 앱 파일이 생겨 있을 거임 ㅇㅇ

`~/Applications/aseprite/build/bin` 위치에 aseprite을 누르면 실행가능 하니까 finder 들어가서 실행 ㄱㄱ

## 3.오늘 회의에서 다룰 안건

페이즈 0 본격 진입을 막는 **결정 블로커 4건**을 우선 처리하고, v2 정합성과 작업 분배로 마무리

#### 안건 A — Tier 1 핵심 결정

`A-1. 전투 코어 메커닉`
**왜 지금** — 갭분석 #2. v2에서도 손 안 댄 영역. Unity 작업 시작의 근본 블로커
**결정해야 할 것**
- 무기 시스템 — 근접 단일 / 근접·원거리 혼합 / 무기 없음·맨손
- 핵심 무브 — 회피·방어·패리·반격 중 코어 1~2개
- 자원 관리 — HP 단일 / HP+스태미나 / HP+이해도 / 자원 없음·즉사형
- 공격 표현 — 단발 무거운 / 콤보 / 리듬 기반
**검증 기준**
- 사령 패턴 = 끝내지 못한 마지막 순간 (Pillar 3) 정합
- 약점 매핑 보스 디자인 회피 (Anti-Pillar 4)
- "사령 공격 패턴 한가운데 들어가는" 종결 조건 지원 가능

`A-2. "패턴이 읽힌다"의 가시화`
**다음회의로 이월** — 즉석 토론보다 각자 숙성 시간이 필요한 주제. A-1 결정 후 후보 카드가 자연스럽게 좁혀지므로 순서상으로도 다음 회의가 적절

`A-3. 현실세계 탐문 메카닉`
**왜 지금** — v2 4단계 루프(탐문)가 메카닉으로 정의되어야 이재화의 NPC 대본 작업·문정인의 UI 작업이 시작될 수 있음
**결정해야 하는것**
- 대화 시스템 형태 — 선택지형 / 키워드 / 증거 제시형 / 자유 텍스트
- 사령세계 정보 필요 NPC 개방 트리거 — 인벤토리 토큰 / 자동 해금 / 단서 보드 연결
- 진술 교차 검증 위치 — 단서 보드 위 / 대화 중 즉시 / 별도 UI
- 고인의 방 탐색 — 1인칭 자유 / 포인트앤클릭 / 3인칭 트리거
**검증 기준**
- "정보 외우기 게임" 회피 (Anti-Pillar 3)
- 단서 보드 자동 연결 금지 (Pillar 6)

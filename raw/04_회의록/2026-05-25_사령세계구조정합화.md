## 논의 맥락 (Context)

### 1. 사령세계 구조 — 가장 큰 쟁점

**문제 제기:** 네 명 모두 머릿속에 서로 다른 "사령세계 모습"을 가지고 있었음

| 사람 | 초기 멘탈 모델 |
|---|---|
| 이재화 | 진입 시점에 보스가 곧장 등장 (RPG 쯔꾸르 스타일). 단일 맵 안에서 보스 모습이 점차 변함 |
| 안지호 | 계층형 구조. 잡몹 → 보스로 단계적으로 진행. 유품이 계층 해금 |
| 송호윤 | 메트로배니아. 수평적 맵, 어디든 재진입 가능 |
| 문정인 | 보스방은 별개 공간. 이스터에그 형식 가능성도 제안 |

**합의 도출 과정:**
- 처음엔 "보스가 시작점에 있어야 하는가"로 논쟁. 이재화는 *피지컬 플레이 존중*을 위해 보스 직접 도전이 가능해야 한다고 주장.
- 송호윤이 "메트로배니아에서 보스방은 어디든 포탈/통로로 연결 가능"임을 설명하며 합의점 발견.
- 첫 진입은 보스전으로 시작 → 이후엔 탐색 영역으로 분기되는 구조로 정착.

**남은 의문 (다음 회의):**
- 보스방 재도전 시 진입 UX (현실 → 사령 단말기 다시 켜기? 단축 동선?)
- 피지컬 루트가 채택될 경우 별도 스토리 필요 여부 → 이재화 검토

### 2. 이해도 시스템 — 다음 회의의 가장 큰 의제

송호윤이 정리한 시스템 계층:
```
[코어] 이해도
   ├─ [입력] 탐문 시스템 (NPC 대화, 유품 수집)
   ├─ [입력] 재구성 시스템 (단서 보드 조합)
   └─ [입력] 사령세계 탐험
       │
       └─ [출력] 보스/잡몹 패턴 변화
       └─ [출력] 보스전 스킵(공명) 가능 여부
       └─ [출력] 엔딩 루트 분기 (성불/제령/소멸)
```

**합의:** 이해도는 단일 코어 변수. 하위 시스템들은 각자 다른 가중치로 이해도에 기여

**미합의:**
- 가중치 구체 수치 (재구성 시스템이 핵심이라는 데에는 안지호가 강하게 주장, 다른 멤버 동의)
- 측정 단위: 점수제 vs 이벤트 트리거 vs 척도형 → A1에서 결정

### 3. 유품-맵 해금 구조

안지호 제안 → 채택:
- **보조유품 1** 획득 → 사령세계 영역 1 해금 (예: 오르골 → 놀이동산 풍 회로, 장난감 병정 잡몹)
- **보조유품 2** 획득 → 영역 2 해금
- **메인유품** 트리거 충족 → 보스방 해금
- **유품을 팔아도(소멸 루트)** 해금은 진행되나, 같이 작동해야 할 기억 앵커가 비활성화되어 이해도는 상승하지 않음

→ 이렇게 하면 4가지 루트(성불/제령/소멸/피지컬) 모두 동일한 진행 구조로 커버 가능.

### 4. 협업 운영 이슈

- 문정인이 노션 알림을 못 받아서 정보 격차 발생 (메트로배니아 합의 과정에서 본인만 모르고 있었던 사례 발생)
- Notion은 멘션이 없으면 알림 미발생 → 작성/수정 시 Discord 알림 + 멘션 약속
- Linear 사용 시: 상태 변경(In Progress → Done) 활용으로 자연스러운 알림 흐름 권장 (송호윤)

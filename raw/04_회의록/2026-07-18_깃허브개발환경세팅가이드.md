### 0. 먼저 알아둘 3가지 (안 읽으면 헷갈림)
- **GitHub**: 코드·파일을 저장하고 팀이 공유하는 온라인 창고. (구글 드라이브의 개발자 버전이라고 생각하세요)
- **clone(클론)**: GitHub 창고에 있는 프로젝트를 내 컴퓨터로 통째로 복사해오는 것
- **Unity**: 이 게임을 만드는 프로그램. 프로젝트를 "여는" 도구

우리는 **GitHub Desktop**이라는 앱을 씁니다. 원래 개발자는 검은 터미널 창에 명령어를 치지만, 우리는 이 앱으로 버튼만 눌러도 됩니다

---

### 1. GitHub 계정 만들기
1. https://github.com 접속 → **Sign up** → 이메일·비밀번호·아이디 입력해서 가입
2. 가입한 이메일로 인증 메일이 오면 확인
3. 가입한 **GitHub 아이디(또는 이메일)를 팀 담당자(banjax)에게 알려주세요.** 그래야 프로젝트에 초대해 줍니다
4. 초대가 오면 이메일 또는 GitHub 알림에서 **"Accept invitation"**을 누릅니다

✅ github.com에 로그인한 상태에서 프로젝트 repo 주소가 열리면 성공. (주소는 담당자가 알려줍니다)

---

### 2. GitHub Desktop 설치
이 앱 하나에 Git과 Git LFS(큰 파일 관리 기능)가 **이미 포함**되어 있어서 따로 설치할 게 없습니다

1. https://desktop.github.com 접속 → 본인 OS용 **Download** 클릭
   - **Mac**: 다운로드된 파일을 열고 GitHub Desktop 아이콘을 Applications 폴더로 드래그
   - **Windows**: 다운로드된 설치 파일을 실행하면 자동 설치
2. 앱을 켜고 **1번에서 만든 GitHub 계정으로 로그인**(Sign in)

✅ 로그인 후 본인 GitHub 이름이 앱에 보이면 성공

---

### 3. Unity Hub + Unity 에디터 설치

**Unity Hub**는 여러 Unity 버전을 관리하는 런처이고, 그 안에서 **에디터 본체**를 깔아야 합니다

#### 3-1. Unity Hub 설치
1. https://unity.com/download 접속 → **Download Unity Hub** → 본인 OS용 설치
2. Unity Hub를 켜고 무료 **Unity 계정**을 만들어 로그인(가입 화면이 나오면 안내대로)
3. 라이선스: 개인용 무료 라이선스(Personal/Free)를 선택하면 됩니다

#### 3-2. 정확한 에디터 버전 설치 ⚠️ 중요
***버전이 다르면 프로젝트가 안 열리거나 깨집니다.*** 반드시 아래 버전으로 설치하세요

> **필요한 버전: `6000.3.11f1`** (Unity 6)

1. Unity Hub 왼쪽 **Installs** 탭 → **Install Editor**.
2. 목록에 `6000.3.11f1`이 없으면, 아래 **"Archive"(아카이브)** 또는 **"download archive"** 링크를 눌러 브라우저에서 정확한 버전을 찾아 설치합니다
   - 또는 이 링크 형식으로 바로: `unityhub://6000.3.11f1` (Unity Hub가 설치된 상태에서 브라우저에 입력하면 Hub가 열립니다)
3. 설치 중 **모듈 선택** 화면이 나오면:
   - **Mac**: 본인 칩에 맞는 것 — 최신 맥은 대부분 **Apple silicon**, 오래된 맥은 Intel
   - **Windows**: 기본값 그대로 두면 됩니다
   - "Build Support"는 지금은 필수 아님. 나중에 필요하면 추가 가능
4. 설치는 몇 GB라 시간이 걸립니다

✅ installs 탭에 `6000.3.11f1`이 보이면 성공

---

### 4. 프로젝트 내려받기 (clone)
GitHub Desktop으로 돌아옵니다

1. 상단 메뉴 **File → Clone repository**.
2. 목록에서 우리 프로젝트 repo를 선택 (안 보이면 **URL 탭**에 담당자가 준 repo 주소를 붙여넣기)
3. **Local path**: 내 컴퓨터에 저장할 위치. 경로에 **한글·공백이 없는 곳**을 권장합니다
   - 예) Mac: `/Users/내이름/Dev/` · Windows: `C:\Dev\`
4. **Clone** 클릭 → 다운로드 시작
5. 이미지·오디오 같은 큰 파일(LFS)도 자동으로 같이 받아집니다

✅ 다운로드가 끝나고 GitHub Desktop에 "No local changes" 같은 상태가 보이면 성공

---

### 5. Unity로 열고 정상 확인
1. **Unity Hub → Projects 탭 → Add(또는 Open) → 4번에서 clone한 폴더 선택**
2. 프로젝트가 목록에 뜨면 클릭해서 엽니다
   - 버전 경고가 뜨면, `6000.3.11f1`로 여는 게 맞는지 확인 (다른 버전으로 열면 안 됩니다)
3. **첫 실행은 몇 분 걸립니다.** Unity가 내부 파일(Library)을 새로 만드느라 그런 것이니 정상입니다

#### 5-1. 열린 뒤 확인할 것
- 화면 아래 **Console 창에 빨간 에러가 없는지** (노란 경고는 무시해도 됨)
- 프로젝트 창에서 `Assets/Scenes` 안의 씬을 더블클릭해 열어보기
- 위쪽 **▶(Play) 버튼**을 눌러 실행되는지

✅ 여기까지 되면 세팅 완료! 이제 유니티로 다른사람과 개발 시작할 준비가 됐습니다

### 자주 나는 문제 (Troubleshooting)

⛔ **Unity가 프로젝트를 못 열거나 스크립트 에러가 잔뜩 떠요**
십중팔구 **에디터 버전이 달라서**입니다. Unity Hub에서 `6000.3.11f1`이 설치돼 있는지, 그 버전으로 열었는지 확인하세요

⛔ **이미지가 다 깨지거나 회색으로 나와요**
LFS 파일이 덜 받아진 경우. GitHub Desktop에서 repo를 다시 clone하거나, 담당자에게 "LFS pull 필요"라고 알려주세요

⛔ **Clone이 중간에 멈추거나 실패해요**
인터넷 문제일 수 있습니다. 다시 시도하거나, 저장 경로에 한글·공백이 없는지 확인하세요

⛔ **Unity 버전 목록에 6000.3.11f1이 없어요**
install Editor 화면의 **Archive / download archive** 링크에서 정확한 버전을 찾아야 합니다 (최신 목록에는 특정 세부 버전이 안 보일 수 있어요)

⛔ **Console에 빨간 에러가 있어요**
에러 메시지를 **그대로 캡처해서** 담당자에게 보내세요. 대부분 버전 문제이거나 파일 일부가 덜 받아진 경우입니다

### 용어 사전

| 용어 | 쉬운 뜻 |
|---|---|
| Repository(repo) | GitHub의 프로젝트 저장 창고 |
| Clone | 창고를 내 컴퓨터로 복사해오기 |
| Commit | 변경사항을 "저장 슬롯"으로 기록하기 |
| Push / Pull | 내 변경을 올리기(push) / 남의 변경을 받기(pull) |
| LFS | 이미지·오디오 같은 큰 파일을 따로 관리하는 기능 |
| Unity Hub | Unity 버전들을 관리하는 런처 |
| Editor | 실제로 게임을 만드는 Unity 본체 |
| Console | Unity에서 에러·로그가 뜨는 창 |

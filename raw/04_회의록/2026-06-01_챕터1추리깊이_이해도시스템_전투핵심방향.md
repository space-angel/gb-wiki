#### TL;DR
1. **챕터1 사인은 흐리지 않는다. 고독사로 명확하게 선 제시**
대신 "왜 그럴 수밖에 없었는가"를 표층/심층 감정의 반전 구조로 풀어낸다.
2. **이해도 시스템 v0 4명 합의 완료**
인식 변화량 기반 + 4종 세분화(관찰/연결/검증/재해석) + 챕터별 초기화 + 종합 이해도 별도 산출. 단, 4종 세분화 데이터 구조와 가중치 수치는 banjax+안지호가 M1까지 별도 작업
3. **전투 시스템 핵심 4가지 결정**
회피만(패링/가드 X) / 근접 기본 + 원거리 가젯(퍼즐용) / 보스만 이해도 적용(잡몹 X) / 이해도 출력 = 패턴 가시성 변화 위주

## 4. 논의 맥락 (내용 이해 안될시 확인)

#### 1. 챕터1 추리 깊이 (Part A 0~35분)

**문제 제기 (안지호):**
"고독사로 사인을 처음부터 명확히 제시하면 추리할 게 없다. 유저가 첫 진술에서 이미 결론 다 알아버려서 이후 진행이 노가다가 된다."

**대안 1 (안지호 초안):** 사인 자체를 흐리기 — 자살/타살/사고 가능성을 비주얼/진술 양쪽에서 모호하게.
**대안 2 (안지호 보조):** 챕터2부터 고독사 한정 풀고 다양한 죽음으로 확장.

**반박 1 (재화):** "맥거핀에 피 묻은 칼 같은 너무 강렬한 비주얼은 몰입을 깬다. '이 새끼 정신병이네' 같은 반응 나옴. 우리는 '한 사람의 무너짐' 톤이지 그로테스크 톤이 아니다."

**반박 2 (호윤, 결정적):**
1. 사인 흐리면 **장르가 미스터리 스릴러로 미끄러진다**. "닿지 못했음"이라는 정서적 주제가 범인 찾기에 잡아먹힘.
2. 사인별로 NPC가 다른 가설 뱉고 모순 해소하려면 **케이스1 설계 비용이 폭발한다**.
3. 대안: 사인은 명확히 두되 **"왜 이렇게 됐는지를 표층/심층으로 한 번 더 뒤집기"**. (역전재판 비유 — "범인은 처음부터 알고 시작하지만, 왜 그랬는지가 핵심")

**투표:** 사인 흐리기 = 3명 반대로 폐기. D1 확정

**최종 합의:** 표층 감정(엄마한테 버림받음)과 심층 감정(알고 보니 아들이 먼저 떠남)을 뒤집는 구조. 호윤이 재화와 페어로 챕터1 NPC 서사 작업 진행.

#### 2. 챕터1 고인의 실제 사인 (Part A 35~45분)

재화가 처음 인지: "고독사가 사회적 무너짐류 자살이라고 항상 생각하고 있었다."
- 정인/호윤은 영양실조·병사도 고독사로 알고 있어서 인식 차이 노출
- 정의상 고독사 = (1) 병사 (2) 자살 (3) 알코올/약물 사망 셋 다 포함이지만, **챕터1 = 자살로 픽스 (D3)**
- 고양이 떡밥 유지 — "다른 거 다 망가졌어도 얘만큼은 챙긴" 흔적
- 자해 톤은 "잼 묻은 칼" 정도. "흥건한 피"는 금지

#### 3. 이해도 시스템 v0 공유 (Part A 43~75분)

구조 합의 (안지호 문서 기반, 호윤이 진행):
```
입력 (인식 변화량 기반):
- 단순 수집량만으로 X (소멸 루트 성립 안 됨)
- 수집 + 재가공(단서 보드 등) → 인식 변화량

내부 표현:
- 4종으로 세분화: 관찰도 / 연결도 / 검증도 / 재해석도
  - 관찰도: 유품 발견·기억 앵커 등 단서 획득
  - 연결도: 단서 연결·유품 제시·신규 질문 해금
  - 검증도: 재탐문·숨겨진 진술·사령세계 교차검증·기존 가설 수정
  - 재해석도: 핵심 감정 반전·관계의 진실 반응
- 단일값 vs 4종 최종 결정은 안지호 별도 작업 (A1)

출력 (3종 모두 활용):
A. 보스 패턴 가시성 변화
B. 잡몹 약화 (가시성/형태 등)
C. 종결 선택지 해금

플레이어 스탯 직접 강화 = ❌ 명시적 금지

종결 매핑:
- 성불 (히든): 이해도 충분 → 전투 무효화, 보스와 대화로 스킵
- 제령: 이해도 적정 → 보스 약화 상태 전투
- 소멸: 이해도 없음/불충분 → 약화 없는 보스 격파
  - 소멸-피지컬: 아이템 없이 순수 컨트롤
  - 소멸-아이템: 유품을 관리인에게 팔아 생존성 아이템 획득

종합 이해도 U:
- 챕터별 이해도는 챕터마다 초기화 (챕터2 몬스터에 챕터1 진행도 영향 ❌)
- 최종 엔딩 분기용 U는 챕터별 수치 합산 + 가중치 + 정규화로 별도 산출
```

**아이템 효과 논쟁 (Part A 49~56분, 가장 격렬):**
- 안지호 초안: 아이템도 보스 패턴 가시화/약화 (이해도와 같은 결)
- 호윤 반대: **이해도와 아이템 효과가 똑같으면 둘이 왜 다른지 체감 못함**. 둘 다 올려야 하는 당위성도 흐려짐
- 호윤 대안 (채택): **아이템 = 생존성** (부활·무적기·데스카드). 패턴은 어렵지만 살아남는 방식 차이
- 재화 우려: "생존성도 결국 전투력 아닌가" → 정인 동의 ("어쨌든 베네핏은 있어야지")
- 결과: 호윤 안 채택 (D11). 단 "생존성 = 전투력"인지 여부는 향후 재검토 여지

**소멸 엔딩 통합 논의 (Part A 60~67분):**
- 재화 초안: 피지컬형/아이템형 = 다른 엔딩 (히든처럼 분리)
- 호윤: "둘 다 추리 흐름 무시한 사람들. 하나의 섹션 안에서 분리할 필요 없다"
- 재화 최종 양보: **하나의 엔딩으로 통합 + 관리인 독백 텍스트 한두 줄 차별화** (D10)
- 호윤: "그건 아이템 내부 `소비 분기` 프로퍼티로 구현 가능"

**재화의 결정적 질문 (Part A 57~60분):**
"인식 변화량이라는 게 개발적으로 가능한가? 모든 텍스트가 이해도별로 변하는 거면 우리가 짤 게 폭발하지 않나?"
→ 호윤 답: **조건 조합(AND) 방식.** 모든 텍스트가 변하는 게 아니라 메인 유품/핵심 NPC/특정 리마인드 시점에서만 트리거 발생. 1차 프로토타입은 성불 루트 기준으로 짜고 분기 스크립트는 그 위에 얹음 (D13, D14).

#### 4. 챕터별 이해도 초기화 (Part A 69~75분)

재화 질문: "챕터2 가면 관찰/연결/검증/재해석 4종 게이지가 초기화되나?"

논의 후 합의:
- 챕터별로 초기화. 챕터2의 새 고인 진행도가 챕터1 영향 받으면 안 됨
- 단, **최종 엔딩 분기용 종합 이해도 U는 챕터별 수치를 가중치·정규화로 합산**
- 안지호가 U 산출 공식 작성 예정 (A3)

#### 5. 전투 시스템 핵심 4가지 (Part B 전체)

호윤이 사전 조사 후 안건 4개로 가져옴.
**전제:** "이해도 없이 보스를 잡는 소멸 루트가 얼마나 어려운 게임이 될까"가 모든 결정의 기준점.

### Part B-1. 무거운가 가벼운가 (회의 0~8분)

| 후보 | 대표 게임 | 채택? |
|---|---|---|
| 무거움 (소울라이크) | 세키로, 다크소울 | ❌ |
| 가벼움 (액션 RPG) | 하데스, 하이퍼라이트드리프터 | ⭕ |

호윤 초안: 무거운 게임 → 회의 후 가벼운 쪽으로 선회
정인: "치고 빠지는 느낌"
재화: "구현 가능성 높은 쪽이면 다 OK"
**결정: 가벼움 + 회피 위주 (D15, D16)**

부수 결정: 패링/가드 X. 회피만. "회피 무적 판정 + 계속 때리는 단순노동형" — 정인 표현 그대로.

### Part B-2. 근접/원거리 (회의 8~18분)

- 정인 초기: "근접만 + 회피 빠른 숟가락 살인마"
- 호윤 선회: 원거리를 **퍼즐 트리거**로 쓰면 탐험 깊이가 늘어남
- 재화 동의: "보스 특정 패턴 끝에 결여물 던지기" 같은 활용도 있음
- **결정: 근접 기본 + 원거리 가젯 (제한 횟수/쿨타임)** (D17)

미결: 무기 종류 (한 손 검 vs 대걸레 vs 양손 둔기). 대걸레는 정인 강력 추천 ("유품 정리사 컨셉이랑 맞음"), 호윤은 비주얼 우려. → A5

### Part B-3. 이해도 적용 범위 (회의 18~26분)

- 호윤: 잡몹까지 이해도 적용?
- 재화: "잡몹은 고인 개별 오브젝트가 아니라 사령세계 일반 적대 존재. 이해도 영향 ❌"
- 정인: "잡몹은 그냥 지능 없이 달려드는 거. 이해도 무관"
- **결정: 보스만 이해도 영향. 잡몹은 그냥 평타** (D18)

미결: 안지호가 "챕터별 메인 감정 잡몹 유형 강화" 식 설계안 제시했으나 호윤이 "뭔 소리인지 이해 못함" → 다음 회의 (U6)

### Part B-4. 이해도 출력 방식 (회의 19~22분)

4가지 후보:
1. 정보 가시성 (패턴 잘 보임/안 보임, 히트박스 흐려짐)
2. 적 능력치 (체력/공격력 감소)
3. 패턴 자체 변화 (패턴 단순화/제거)
4. 플레이어 행동 선택지 증가 (스킬 해금) — **호윤 지양 명시**

재화: "고무 차력 덩어리 → 불쌍한 우리 새끼로 변하는 느낌. **패턴 자체가 변해야** 한다."
정인: "고인과 관련된 패턴이 안 나오는 식."
**결정: 패턴 가시성 변화 + 핵심 패턴 노출/은닉 (D19)**. 능력치 변화는 보조.

# 2. 챕터2 - 붕괴 (기초안) 디벨롭x

## 2-1. 챕터 개요

| 항목 | 내용 |
| --- | --- |
| 챕터명 | 붕괴 |
| 핵심 감정 | 자기투영 |
| 사회 이슈 | 투자 실패 / 비교 사회 / 경제 불안 |
| 핵심 메시지 | "남의 일이 아니다" |
| 주요 공간 | 도시 외곽 오피스텔 |

## 2-2. 핵심 구조
피해자는:
주인공의 과거 지인 혹은 이전 직장 동료.

플레이어는:
"나도 저렇게 될 수 있었다"
를 강하게 체감한다.

## 2-3. 주요 사회 요소
- 코인 투자 실패
- SNS 과시
- 부채 압박
- 인간 관계 붕괴
- 자기 가치 하락

## 2-4. 사령세계 컨셉
"끝없이 추락하는 인간의 불안"

### 공간 특징
- 무너지는 계단
- 끝없는 엘리베이터
- 숫자가 뒤틀리는 UI
- 붕괴되는 시세 그래프

## 2-5. 주인공 변화

### 성불 성향
타인을 보며:
"사람은 무너질 수 있다"
를 받아들이기 시작.

### 제령 성향
죽음의 패턴을 구조로 보기 시작.

### 소멸 성향
감정보다 효율이 편해지기 시작.
관리인과의 대화 증가.

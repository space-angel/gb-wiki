# 챕터1 미니루프

# 미니 루프 예시 — 「고립」 (김태현)

## 챕터 목표
플레이어는 고인의 생활 공간을 조사하고, 유품과 주변인의 진술을 통해 "사회와 단절된 사람"이라는 표면적 인식을 넘어, 고인이 실제로 느꼈던 감정에 도달한다.

# 전체 루프

```
현실 조사
↓
메인 유품 확보
↓
사령세계 영역 해금
↓
보조 유품 수집
↓
재구성 보드 1차 해석
↓
NPC 진술 해금
↓
추리 슬롯 가설 생성
↓
사령세계 심화 탐색
↓
최종 유품 확보
↓
재구성 보드 최종 해석
↓
보스 해소
```

# STEP 1. 현실 조사

## 장소
김태현의 원룸
상태:
- 생활 흔적은 남아있음
- 시간은 멈춘 듯한 상태
- 외부와 단절된 분위기

## 조사

### 메인 유품 슬롯 획득

### [부재중 전화 기록]
발견 위치: 침대 옆 휴대폰
정보:
```
어머니 → 14통
마지막 전화: 사망 전날
```

재구성 보드 등록:
```
메인 유품
[부재중 전화]
"누군가는 연락을 시도했다"
```

## 결과
사령세계 1구역 해금

# STEP 2. 사령세계 탐색

## 지역
기억 공간 1구역
특징:
- 반복되는 휴대폰 화면
- 끊임없이 울리는 전화음
- 움직이지 않는 그림자

## 감정 잔재 몬스터

### 불안형 잔향
패턴:
- 플레이어 주변 배회
- 가까워질수록 속도 증가
- 공격 후 다시 거리 유지

상징: "연락하고 싶지만 두려운 마음"

## 기억 앵커
발견: 고인이 휴대폰을 들고 망설이는 장면
획득: 보조 유품 힌트

# STEP 3. 보조 유품 수집
현실 복귀 후 조사

## 보조 유품 1
### [SNS 비공개 캡처]
위치: 휴대폰 갤러리
정보:
```
과거 게시물 대부분 숨김 처리
```

## 보조 유품 2
### [미개봉 생일 택배]
위치: 현관
정보:
```
발송자: 어머니
수령하지 않음
```

# STEP 4. 재구성 보드 — 1차

## 슬롯 배치
### 메인 유품
부재중 전화

### 보조 유품
SNS 비공개
미개봉 택배

### 추리 슬롯
연결:
```
SNS 비공개
+
미개봉 택배
```

## 해석 생성
```
"사람을 피했다"
```
↓
추가 해석 선택
A. 원래 타인을 싫어했다
B. 자신의 상태를 보여주기 싫었다
C. 가족과 사이가 좋지 않았다

플레이어 선택: B

# STEP 5. 진술 슬롯 해금

## NPC
옆집 주민 이유미

초기 진술:
```
"조용한 사람이었어요.
거의 마주친 적도 없고요."
```

심층 진술:
(추리 해석 이후)
```
"한 번은 문 앞에 서있는 걸 봤어요.
누군가 들어오길 기다리는 것 같았어요."
```

등록: 진술 슬롯
```
고립
→
기다림
```

# STEP 6. 사령세계 2구역

해금 조건:
```
O단계 완료
+
A단계 해석 완료
```

환경 변화:
처음: 닫힌 공간
변경: 출구 방향 생성

감정 잔재 변화:
불안형
↓
기대와 두려움이 섞인 형태

획득: 최종 메인 유품
[마지막 녹음 파일]

# STEP 7. 재구성 보드 — 최종

## 슬롯 연결
메인: 부재중 전화 - 마지막 녹음 - 어머니 진술

## 최종 해석
기존:
```
"연락하지 않았다"
```
변경:
```
"연락하고 싶었지만,
상대에게 부담이 될까 두려워했다"
```

# STEP 8. 보스 해소

## 보스
감정 복합체: 「고립」
구성 감정:
- 외로움
- 수치심
- 기대
- 체념

전투 목적: 처치 X, 패턴 해석 O

패턴 변화:
초반: 벽을 만들며 접근 차단
↓
중반: 자신을 숨김
↓
최종: 플레이어를 향해 다가옴

## 해소 조건
재구성 완료
↓
대화 선택지 발생

선택: "기다리고 있었다는 걸 알아"

결과: 감정 정리, 사령세계 안정화

# 이 미니 루프에서 검증되는 시스템

| 시스템 | 역할 |
| --- | --- |
| 메인 유품 | 사건 진행 |
| 보조 유품 | 해석 변화 |
| 진술 | 관점 확장 |
| 추리 슬롯 | 플레이어 판단 |
| 사령세계 | 감정 시각화 |
| 보스 | 미해결 감정의 형태 |
| 해소 | 이해의 완료 |

## 감사 결과 (자동, 2026-08-03)
- 상태: 확인필요
- 근거: 옆집 주민 이유미가 초기 진술("조용한 사람이었어요...")과 심층 진술("한 번은 문 앞에 서있는 걸 봤어요...", 추리 해석 이후 해금)을 모두 제공함. ADR-6은 "한 NPC는 A 단계 또는 V 단계 중 하나에만 핵심 진술자로 배치"하도록 규정하는데, 이 문서의 초기/심층 진술 구분이 동일 A단계 내 심도 차이인지 A/V 두 단계에 걸친 배치인지 불명확하여 사람 확인 필요. (3지선다 가설 A/B/C는 ADR-4와 부합.)

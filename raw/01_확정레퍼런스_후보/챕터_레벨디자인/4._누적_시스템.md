# 4. 누적 시스템

## 4-1. 존재 희석

| 단계 | 변화 |
| --- | --- |
| 초기 | 기억 흐림 |
| 중반 | NPC 인식 저하 |
| 후반 | 자기 존재 붕괴 |

## 4-2. 이해도 시스템

### 현실 조사
- 유품 조사
- NPC 탐문
- 생활 흔적 분석

### 영향
- 성불 조건 개방
- 패턴 약화
- 숨겨진 기억 개방

## 4-3. 유품 시스템

| 타입 | 역할 |
| --- | --- |
| 메인 유품 | 심층부 개방 |
| 사이드 유품 | 인간 관계 이해 |
| 종결 유품 | 루트 분기 |

## 4-4. 관리인 상점

### 판매 물품
- 강제소멸부적
- 오염 억제 장치
- 탐문 보조 아이템

### 관리인 철학
"이해한다고 달라지는 건 없다"

## 4-5. 루트 누적 변화

### 성불
- 화면 노이즈 증가
- 존재 희석 연출 강화

### 제령
- 기록 로그 증가
- 정보량 증가

### 소멸
- UI 감정 연출 감소
- 사령 음성이 점점 노이즈처럼 들리기 시작
- NPC와의 거리감 증가
- 탐문 선택지가 효율 중심으로 변화
- 유품 판매를 통한 재화 획득 가능
- 관리인 상호작용 증가
- 감정보다 생존과 처리 속도를 우선하게 됨

## 감사 결과 (자동, 2026-08-03)
- 상태: 확인필요
- 근거: "4-3. 유품 시스템"이 메인 유품/사이드 유품/종결 유품 3종으로 구분되는데, ADR-3(핵심/보조 2등급)·ADR-5(4슬롯: 메인유품/보조유품/진술/추리)에 명시된 위계·슬롯 구조에 "종결 유품"이라는 제3의 범주가 어떻게 대응하는지 명시되지 않음. 사람 확인 필요.

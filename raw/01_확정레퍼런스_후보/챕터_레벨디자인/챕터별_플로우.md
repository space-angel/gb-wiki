# 챕터별 플로우

## 전제
> 메인 유품은 문이고, 서브 유품들이 그 문이 무엇인지 알려준다.

- 메인 유품 = 사령세계 진입 트리거 + 챕터 엔딩 열쇠
- 서브 유품 = 감정/이해도 축적 장치
- 이해도 = 플레이어에게 수치로 표시되지 않음. 세계의 반응으로만 체감.

## 전체 흐름
현실 공간 진입
↓
청소 및 공간 조사
↓
메인 유품 조우 → 사령세계 진입 해금
↓
서브 유품 루프 (서브 유품 수만큼 반복)
↓
메인 유품 의미 파악
↓
보스방 진입
↓
챕터 엔딩

## STEP 1 — 현실 공간 진입

### 행동
- 고인의 공간(현장)에 처음 발을 디딤
- 청소 업무 시작

### 메커니즘
- 방 안 모든 오브젝트 조사 가능
- 처음엔 모든 오브젝트가 동등하게 보임 (강조 없음)
- 오브젝트 조사 시 주인공 독백 출력 + 내부 태그 기록
- 태그 조합 완성 시 생활 패턴 로그 자동 생성

### 플레이어 경험
> "이 공간에서 뭔가 읽힌다. 하지만 뭘 봐야 할지 모르겠다."

## STEP 2 — 메인 유품 조우

### 행동
- 청소 중 메인 유품 발견
- 아직 의미는 알 수 없음

### 메커니즘
- 메인 유품 접촉 시 일반 오브젝트와 다른 연출 발생
  - 화면 연출 변화 / 사운드 변화
  - 주인공 독백: 의미를 모른 채 반응
- 공간 변화 시작 (색온도 하강 / 반복음 발생)
- 사령세계 진입은 자동 아님 → **플레이어 능동 선택**

### 분기
메인 유품 조우
↓
사령세계 진입 선택 가능 상태
↓
진입 → STEP 3으로
보류 → 현실 청소 계속 (언제든 재진입 가능)

### 플레이어 경험
> "이게 뭔지 모르겠지만 뭔가 다르다. 들어갈지 말지는 내가 결정한다."

## STEP 3 — 사령세계 1차 진입

### 행동
- 메인 유품을 통해 사령세계 최초 진입
- 이 시점엔 서브 유품 정보 없음
- 기본 구역만 개방된 상태

### 메커니즘
- 현실 이해도 낮음 → 진입 가능 구역 제한
- 기억 앵커 일부 배치 (발동 시 단편 기억 재생)
- 기본 몬스터 등장 (고인의 표면 감정 형상화)
- 사령세계 NPC 첫 등장 (무반응 or 최소 반응 상태)
- 드롭 아이템 or 보물상자 일부 획득 가능

### 획득 가능 아이템
- 서브 유품 조각 (미완성)
- 기억 파편 (맥락 없는 단편)

### 플레이어 경험
> "여기서 뭔가 가져올 수 있다. 하지만 아직 전체 그림이 안 보인다."

## STEP 4 — 현실 복귀 + NPC 1차 탐문

### 행동
- 사령세계에서 현실로 복귀
- 획득 아이템 반입
- NPC 탐문 시작

### 메커니즘

**아이템 반입 처리**
인벤토리 내 현실 연동 아이템 감지
↓
관련 NPC 선택지 추가
↓
관련 오브젝트 재조사 반응 변화

**NPC 대화 구조**
- 각 NPC는 공개 진술층 / 잠긴 진술층 2단계 구성
- 선택지는 감정 방향 선택 (정답 고르기 아님)
- 잘못된 질문도 정보가 됨 (NPC 회피·침묵도 단서)
- 아이템 제시 / 로그 기반 선택지 / 기억 앵커 정보로 잠긴 진술 해금

**NPC 감정 거리 상태**
폐쇄 → 형식적 → 회상 → 죄책감 → 직면
질문 방향과 탐문 진척도에 따라 단계적 변화

### 플레이어 경험
> "사령세계에서 가져온 게 여기서 쓰인다."

## STEP 5 — 서브 유품 발견

### 행동
- 현실 청소 계속 진행
- 서브 유품 발견

### 메커니즘
- 서브 유품은 청소 중 자연스럽게 등장
- 강조 마커 없음 → 플레이어가 직접 발견
- 발견 즉시 관련 NPC 선택지 추가 or 잠긴 진술 해금 조건 충족
- 서브 유품마다 독립된 감정/기억 태그 보유

**서브 유품 역할**
서브 유품 발견
↓
관련 NPC 진술 해금
↓
사령세계 관련 구역 추가 개방
↓
이해도 축적

### 플레이어 경험
> "이게 그 사람이랑 연결된 건가? 더 들여다봐야겠다."

## STEP 6 — 서브 유품 관련 사령세계 재진입

### 행동
- 서브 유품을 통해 사령세계 재진입
- 서브 유품별 독립된 감정/기억 구역 탐험

### 메커니즘
- 서브 유품마다 대응하는 사령세계 구역 존재
- 현실 탐문 이해도에 따라 구역 내 접근 가능 범위 변화
- 기억 앵커 추가 발동 → 현실 탐문 신규 질문 해금
- 사령세계 NPC 반응 변화 (이해도 상승에 따라)

**이해도에 따른 구역 변화**
이해도 낮음 → 기본 구역만 접근 가능
이해도 중간 → 추가 구역 개방
이해도 높음 → 심층 구역 + 사령세계 NPC 반응 변화

**드롭 아이템 / 보물상자**
- 서브 유품 조각 추가 수집
- 음성 메모 / 편지 조각 등 현실 연동 아이템

### 플레이어 경험
> "올 때마다 보이는 게 달라진다."

## STEP 7 — 현실 복귀 + NPC 달라진 진술

### 행동
- 사령세계에서 현실로 복귀
- 아이템 반입
- NPC 재탐문

### 메커니즘

**NPC 재탐문 처리**
NPC 재접근 (NPC가 먼저 말 걸지 않음)
↓
보유 아이템 자동 감지
↓
연동 태그 일치 항목 확인
↓
달라진 반응 or 새 선택지 출력

**달라진 진술 유형**

| 유형 | 트리거 | 예시 |
| --- | --- | --- |
| 새 정보 개방 | 드롭 아이템 반입 | "그 명찰 어디서 났어요?" |
| 감정 태도 변화 | 이해도 상승 | 형식적 → 회상 상태 전환 |
| 방관 고백 | 로그 + 이해도 조합 | "사실 알고 있었어요." |
| 유품 제시 반응 | 유품 직접 제시 | 어머니 NPC 감정 붕괴 |

**이해도 누적 처리 (비표시)**
탐문 행동 발생
↓
내부 이해도 변수 업데이트
↓
플레이어에게 수치 미표시
↓
세계의 반응으로만 체감
- NPC 감정 거리 변화
- 공간 생활감 증가
- 사령세계 NPC 반응 변화
- 새 구역 개방

### 플레이어 경험
> "다시 왔더니 뭔가 달라졌다. 내가 뭔가 하고 있다는 느낌."

## STEP 8 — 서브 유품 루프 반복

### 행동
- STEP 5 → STEP 7 반복
- 서브 유품 수만큼 반복

### 메커니즘
- 루프를 돌 때마다 메인 유품의 맥락이 조금씩 쌓임
- NPC 초기 반응이 이전보다 미세하게 달라짐
- 사령세계 접근 가능 구역 점진적 확장
- 생활 패턴 로그 항목 추가 완성

**다음 서브 유품 유도 방식**
직접 마커 없음. 간접 유도 3가지로 처리.
1. NPC 진술 속 힌트
"그 사람 책상 서랍을 한 번도 안 열었더라고요."
2. 사령세계 기억 앵커 정보
특정 공간/오브젝트 관련 기억 재생 → 현실 해당 오브젝트 조사 시 반응 변화
3. 생활 패턴 로그의 빈칸
로그에 "미확인" 항목 존재 → 플레이어가 스스로 채우려는 동기 형성

### 플레이어 경험
> "조각들이 모일수록 그 사람이 보이기 시작한다."

## STEP 9 — 메인 유품 의미 파악

### 행동
- 서브 유품 루프 완료
- 메인 유품의 맥락이 완성됨

### 메커니즘
- 플레이어에게 직접 알려주지 않음
- 서브 유품들이 다 모였을 때 플레이어가 스스로 연결
- 메인 유품 재조사 시 첫 조우 때와 다른 독백 출력
- 보스방 진입 조건 충족

서브 유품 루프 완료
↓
메인 유품 이해도 임계 도달
↓
메인 유품 재조사 시 연출 변화
↓
보스방 진입 가능 상태

### 플레이어 경험
> "아, 이게 그거였구나."

## STEP 10 — 보스방 진입 + 보스전

### 행동
- 사령세계 심층 진입
- 메인 보스와 조우

### 메커니즘

**보스 설계 원칙**
> 보스는 악이 아니라 반복되는 감정이다.
> 전투의 핵심은 처치가 아니라 해석이다.

**이해도에 따른 전투 분기**

| 이해도 구간 | 전투 경험 |
| --- | --- |
| 높음 | 메인 유품 아이템 사용 가능. 보스 약점 노출. 공명 페이즈 진입. |
| 중간 | 패턴 회피 중심. 일부 페이즈 스킵 불가. 클리어 가능. |
| 낮음 | 패턴 예측 불가. 공명 페이즈 미발동. 소멸 엔딩 확정 구간. |

**공명 페이즈**
이해도 높음 조건 충족
↓
보스전 중 공명 페이즈 발동
↓
전투 일시 중단
↓
공격 대신 공명 선택 가능
↓
성불 엔딩 조건 확정

**보스 패턴 = 메인 유품의 감정 구조**
서브 유품으로 쌓은 이해도 = 패턴 해석 능력

### 플레이어 경험
> "이 패턴이 그 사람의 감정이었구나."

## STEP 11 — 챕터 엔딩 분기

### 엔딩 분기 기준

| 엔딩 | 핵심 조건 |
| --- | --- |
| **성불** | 공명 페이즈 발동 + 공명 선택 + 주요 NPC 잠긴 진술 대부분 해금 |
| **제령** | 주요 탐문 일부 완료. 공명 미선택 or 이해도 중간 구간. |
| **소멸** | 탐문 최소화. 공명 페이즈 미발동. |

### 엔딩 연출

**성불**
사령이 반복을 멈춤
유품들이 제자리를 찾아감
공간이 서서히 밝아짐

**제령**
이상현상 종료
고인의 방은 여전히 텅 빈 채로 남음
주인공 독백: "충분하지 않았다"

**소멸**
사령세계 강제 붕괴
유품들이 의미 없는 물건으로 남음
주인공 독백 없음 — 침묵

## 전체 메커니즘 요약

| 단계 | 핵심 메커니즘 | 플레이어 경험 |
| --- | --- | --- |
| 현실 진입 | 공간 조사 + 태그 기록 | "이 공간에서 뭔가 읽힌다" |
| 메인 유품 조우 | 공명 트리거 + 진입 선택 | "들여다볼지 내가 결정한다" |
| 사령세계 1차 진입 | 기본 구역 탐험 | "아직 전체 그림이 안 보인다" |
| 현실 복귀 + 1차 탐문 | 아이템 반입 + NPC 선택지 생성 | "가져온 게 여기서 쓰인다" |
| 서브 유품 발견 | 독립 감정 태그 + 구역 개방 | "더 들여다봐야겠다" |
| 사령세계 재진입 | 이해도 기반 구역 확장 | "올 때마다 보이는 게 달라진다" |
| 현실 복귀 + 재탐문 | 달라진 NPC 진술 | "내가 뭔가 하고 있다는 느낌" |
| 루프 반복 | 맥락 누적 + 로그 완성 | "조각들이 모일수록 보인다" |
| 메인 유품 의미 파악 | 이해도 임계 + 연출 변화 | "아, 이게 그거였구나" |
| 보스전 | 이해도 기반 패턴 해석 | "이게 그 사람의 감정이었구나" |
| 챕터 엔딩 | 태도의 총합 → 자동 분기 | "나는 이 사람을 어떻게 바라봤는가" |

## 감사 결과 (자동, 2026-08-03)
- 상태: 위반발견
- 근거: STEP3("현실 이해도 낮음 → 진입 가능 구역 제한")과 STEP6("이해도에 따른 구역 변화: 낮음/중간/높음")에서 사령세계 구역 접근을 이해도 수준에 직접 연동함(ADR-11 §2.1과 충돌 가능, 다만 ADR-11은 Proposed). 더 중요하게, STEP9~10에서 "서브 유품 루프 완료 → 메인 유품 이해도 임계 도달 → 보스방 진입 가능 상태"로 서술하여 보스 도전 자체를 이해도 조건에 종속시킴. 이는 ADR-2(§2.3 "보스 도전은 이해도 플래그와 무관하게 O_reached 시점부터 항상 가능")와 ADR-7(§2.3 "보스 도전은 첫 진입부터 가능. 이해도 플래그에 종속시키지 않는다")에 명백히 위반됨(둘 다 Accepted).

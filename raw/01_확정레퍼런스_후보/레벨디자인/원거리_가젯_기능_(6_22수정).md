그럼 원거리 공격은??? → 사실 후레쉬 기능을 생각함 → 빛을 비추면 잠시 스턴 이런식으로 → 사령세계 체류시간에따라 방전해서 현실세꼐로 복귀하는 방안

# 잔향 스캔

## 작동
플레이어 주변에 원형 스캔 영역 생성

```
        ✦
    ┌────────┐
    │        │
    │   ○    │
    │        │
    └────────┘

        ↑
     플레이어
```

범위 안에 들어온 것 중:
- 유품
- 기억 잔재
- 감정 흔적
- 숨겨진 상호작용

이 표시됨.

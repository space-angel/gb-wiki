# 재구성시스템(추리보드)

# 재구성 보드 (Reconstruction Board)

## 1. 시스템 개요
재구성 보드는 유품정리사가 디바이스를 통해 수집한 정보를 기반으로, 고인의 삶과 죽음에 대한 사건을 재구성하는 추리 시스템이다.
플레이어는 현실과 사령세계를 오가며 유품, 주변 인물의 진술, 기억의 흔적을 수집한다.
수집한 정보는 재구성 보드에 배치되고, 서로 연결함으로써 새로운 해석과 가설을 생성한다.

재구성 보드의 목적은 "정답을 찾는 것"이 아니라,
> 고인의 행동과 감정을 플레이어가 단계적으로 이해하도록 만드는 것

이다.

# 2. 기본 구조
재구성 보드는 4개의 이해 단계로 진행된다.

```
1. 사실 확인
        ↓
2. 관계 파악
        ↓
3. 사건 해석
        ↓
4. 진실 도달
```

플레이어는 각 단계에서 새로운 정보를 연결하며, 기존의 해석을 수정한다.

# 3. 재구성 보드 슬롯 구성
재구성 보드는 총 4종류의 정보 슬롯으로 구성된다.

## ① 메인 유품 슬롯 (Main Evidence)

### 역할
사건 진행의 핵심이 되는 정보를 제공하는 슬롯.
고인의 죽음과 직접적으로 연결된 물품이며,
사령세계 영역 해금 및 주요 진행 조건에 사용된다.

### 특징
- 필수 조사 대상
- 특정 단계 진행 조건
- 주요 사건의 방향성 제공

### 예시
```
메인 유품
[부재중 전화 기록]
발견: 침대 옆 휴대폰
제공 정보: 고인이 마지막 순간 누군가와 연결하려 했음
```

## ② 보조 유품 슬롯 (Sub Evidence)

### 역할
사건 자체보다 고인의 삶과 상태를 이해하기 위한 정보 슬롯.
메인 유품의 의미를 확장하거나,
새로운 해석을 가능하게 만드는 재료가 된다.

### 특징
- 필수는 아니지만 추리 방향 변화
- 잘못된 해석 수정
- 감정 이해에 영향

### 예시
```
보조 유품
[미개봉 생일 택배]
발견: 현관 앞
초기 해석: 누군가와 단절된 상태
재구성 후: 연결을 기다리고 있었음
```

## ③ 진술 슬롯 (Statement)

### 역할
주변 인물의 기억과 관점을 제공하는 슬롯.
유품이 "사실"을 제공한다면,
진술은 "사람이 바라본 사건"을 제공한다.

### 특징
- NPC 대화 결과 저장
- 단계별 심층 진술 해금
- 플레이어의 해석 방향 변화

### 중요 규칙
A단계와 V단계의 핵심 진술자는 분리한다.
이유:
같은 인물이 계속 정보를 제공할 경우,
플레이어의 이해 과정이 단순 정보 획득으로 변하기 때문.

```
A단계 NPC
→ 초기 행동의 이유 추론

V단계 NPC
→ 최종 감정 검증
```

## ④ 추리 슬롯 (Inference)

### 역할
수집한 정보들을 연결하여 플레이어가 사건에 대한 가설을 만드는 공간.
추리 슬롯은 정답을 저장하는 공간이 아니라,
현재 플레이어가 가진 이해를 기록하는 공간이다.

# 4. 추리 슬롯 구조
추리 슬롯은 두 단계로 구성된다.

```
[해석]
↓
[가설]
```

## 해석 (Interpretation)
수집한 정보에서 생성되는 중간 결론.

예:
```
SNS 비공개 캡처
+
미개봉 택배
↓
해석 생성:
"자신의 모습을 숨기고 있었다"
```

해석은 플레이어의 이해 방향을 변경한다.

## 가설 (Hypothesis)
해석을 기반으로 플레이어가 선택하는 사건의 설명.

예:
질문: "왜 사람들과 거리를 뒀을까?"
선택:
A. 원래 사람을 싫어했다
B. 보여주고 싶지 않은 것이 있었다
C. 가족과 사이가 나빴다

선택 결과에 따라:
- NPC 진술 변화
- 새로운 조사 가능
- 진행 플래그 변화

발생.

# 5. 재구성 진행 단계

## STEP 1. 사실 확인
목표: "무슨 일이 있었는가?"
사용 슬롯: 메인 유품, 보조 유품
결과: 사령세계 접근 및 기본 사건 구조 확보

## STEP 2. 관계 파악
목표: "고인은 누구와 어떤 관계였는가?"
사용 슬롯: 진술 슬롯, 보조 유품
결과: NPC 심층 대화 및 새로운 정보 해금

## STEP 3. 사건 해석
목표: "왜 그런 행동을 했는가?"
사용 슬롯: 유품, 진술, 추리 슬롯
결과: 표면적인 사건 설명에서 벗어나 심층 원인 접근

## STEP 4. 진실 도달
목표: "고인이 마지막에 느낀 것은 무엇인가?"
사용 슬롯: 핵심 유품, 최종 진술, 추리 슬롯
결과: 보스의 진짜 형태 확인 및 해소 루트 개방

# 6. 핵심 설계 원칙

## 재구성은 수집 시스템이 아니다.
단순히 아이템 개수를 채우는 것이 아니라,

```
정보 획득
↓
해석 변화
↓
새로운 질문 발생
↓
추가 정보 접근
↓
기존 해석 수정
```

의 반복 구조이다.

## 플레이어의 목표
사건 해결: X
망자의 삶을 이해: O

최종적으로 플레이어는
"무슨 일이 일어났는가"가 아니라
"왜 그 사람이 그렇게 될 수밖에 없었는가"
에 도달해야 한다.

## 감사 결과 (자동, 2026-08-03)
- 상태: 통과(자동감사)
- 근거: 4단계 진행(사실확인/관계파악/사건해석/진실도달), 4종 슬롯(메인유품/보조유품/진술/추리), "A단계와 V단계의 핵심 진술자는 분리한다" 원칙, 3지선다 가설 구조가 각각 ADR-5·ADR-6·ADR-4와 거의 문구 단위로 일치함. 충돌 없음.

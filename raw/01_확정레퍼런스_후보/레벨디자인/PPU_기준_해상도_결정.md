# 🖥️ PPU 기준 / 해상도 결정

# 1. PPU 결정사항 표

PPU = pixel per unit
"게임월드의 1유닛을 몇 픽셀로 볼 것인가"

| 항목 | 값 | 의미 | 계산/ 기준/ 관련사항 |
| --- | --- | --- | --- |
| 타일크기 | 32x32 | 맵을 구성하는 기본 1칸 | 바닥, 벽 오브젝트 배치 기준 |
| PPU | 32 | unity월드 1유닛에 들어가는 픽셀 수 | |
| 월드기준 | 1타일 = 1 unit | 맵배치 단순 | |
| 캐릭터 기본 크기 | 32x48 | 1타일 x 1.5타일 | main |
| npc 및 오브젝트 크기 | 32x32 | 1타일 x 1타일 | npc, 언저리 |
| 기준 해상도 | 640x360 | 게임 내부에서 그려지는 원본화면 | 모니터해상도 아님. 화면 타일수 20x11칸 |
| 출력 해상도 | 1920x1080 | 기준해상도를 확대해서 보여주는 화면 | 기준 해상도 x 3 |
| 확대 방식 | 정수배율 | | |

# 2. 픽셀 비율별 캐릭터 이미지

> 참고: 원문에는 32x48 픽셀 캐릭터 이미지와 32x32 픽셀 캐릭터 이미지가 2단 컬럼으로 나란히 첨부되어 있었다. 이미지는 Notion S3의 임시 서명 URL(만료됨)이라 이 raw 아카이브에는 그대로 옮기지 못했다. 원본은 Notion 페이지(https://app.notion.com/p/3738826f856380b8b9a4f7790b2558ea)에서 직접 확인 필요.

# NPC 정보 및 설계

## 공통 원칙

NPC는 사건의 진실을 알려주는 존재가 아니다. NPC는 **현실에서 자신이 경험한 것만 말하는 사람**이다.
진실은 유품 · 환경 · 사령세계를 통해 플레이어가 직접 재구성한다.

1. **NPC는 거짓말하지 않는다. 하지만 틀릴 수 있다.** 예) "취업 준비도 안 하던데." — 실제로는 엄청 많이 했다.
2. **NPC는 추측한다.** 예) "우울증이었겠죠." "힘든 줄은 몰랐어요." "원래 조용한 사람이었어요."
3. **NPC는 피해자를 정의하지 않는다.** 절대 "착한 사람" / "나쁜 사람"이라고 말하지 않는다.
4. **NPC는 자신의 시점만 안다.** 모든 NPC 정보는 자신의 위치에서만 얻는다.

## 관리인 (허브 NPC)

| 항목 | 내용 |
|---|---|
| 존재 목적 | 현실과 플레이어를 연결하는 허브 / 상점 / 사건 배정 / 현실 절차 담당 |
| 등장 장소 | 프롤로그, 건물 외부, 특수청소 차량, 챕터 종료 후 거점 |
| 담당 공간 | 현실 전체 |
| 연결 오브젝트 | 없음 |
| 연결 유품 | 직접 연결 없음 (모든 위임 유품 처리 담당) |
| 판매/보관/구매 | 유품 판매 ○ · 유품 보관 ○ · 장비 구매 ○ |
| 플레이어 선택 | 유품 판매 → 재화 획득 → 소멸 부적 구매 |
| 알고 있는 것 | 경찰 철수, 의뢰 내용, 청소 범위, 유족 인계 물품 |
| 모르는 것 | 사령, 기억, 미완, 플레이어가 보는 것 |
| 만드는 오판 | 없음 |
| OVAR 영향 | 없음 |
| 절대 말하지 않는 것 | "사령" "기억" "성불" |
| 금지 | 사령 설명 · 세계관 설명 · 죽음 해석 |

**챕터1 대사 톤**
> "집주인한테 연락 왔다." / "네 손이 필요할지도 몰라." / "이번 건…" / "네가 직접 한번 보는 게 좋겠다."

## 집주인

| 항목 | 내용 |
|---|---|
| 존재 목적 | 사건 발생의 시작 |
| 등장 장소 | 건물 입구 |
| 담당 공간 | 현관, 복도 |
| 연결 오브젝트 | 마지막 문자 / 월세 고지서 / 계좌 입금 내역 |
| 핵심 유품 | 없음 |
| 보조 유품 | 월세 고지서 |
| 해금 | 게임 시작 |
| 알고 있는 것 | 연체 / 문자 / 발견 |
| 만드는 오판 | "생활고 때문에 죽었다." |
| 제공 정보 | 사건 진행 |
| **OVAR** | **O** |
| 다음 조사 유도 | 거실, 중문 밖 |

## 이유미

| 항목 | 내용 |
|---|---|
| 존재 목적 | '마지막까지 남아 있던 책임'을 보여주는 NPC |
| 등장 장소 | 복도 (플레이어가 중문 밖을 충분히 조사한 뒤) |
| 담당 공간 | **중문 밖** — 이 NPC의 핵심 |
| 연결 오브젝트 | 고양이 이동장 / 사료 / 물그릇 / 화장실 |
| 핵심 유품 | 없음 |
| 보조 유품 | 고양이 용품 일체 |
| 해금 조건 | 사료·물그릇·화장실 중 **2개 이상 조사** → 이유미 등장 |
| 알고 있는 것 | 고양이를 정말 아꼈다 / 마지막까지 챙겼다 / 항상 웃으며 인사했다 |
| 만드는 오판 | "참 착한 사람이었어요." → 플레이어는 '착한 사람' 이미지를 갖게 됨 |
| 제공 정보 | 고양이 이야기 / 마지막 일상 / 책임감 |
| **OVAR** | **A** → '끝까지 책임을 놓지 않았다.' |
| 다음 조사 | 중문 개방 |

## 어머니

| 항목 | 내용 |
|---|---|
| 존재 목적 | '기대의 시작'을 보여주는 NPC |
| 등장 장소 | 전화 (챕터 후반) |
| 담당 공간 | 침대, 책장 |
| 연결 오브젝트 | 졸업사진 / 가족사진 / 상장 |
| 핵심 유품 | ✔ 졸업사진 (조사 후 자동으로 유족 인계) |
| 보조 유품 | 상장 / 가족사진 |
| 해금 조건 | 졸업사진 조사 → 어머니 통화 |
| 알고 있는 것 | 어릴 적 태현 / 성실했던 모습 / 가족 이야기 |
| 만드는 오판 | "힘들면 엄마한테 말했을 거야." → 플레이어는 '도움을 요청하지 않은 사람'이라 생각 |
| 제공 정보 | 가족 관계 / 성장 과정 / 부모의 기대보다 더 큰 자기 기대 |
| **OVAR** | **Transition** → "남이 기대한 삶이 아니라, 스스로 기대를 짊어진 삶이었다." |
| 다음 조사 | 최종 사령세계 |

## 상담사

| 항목 | 내용 |
|---|---|
| 존재 목적 | '노력하지 않았다'는 오판을 깨는 NPC |
| 등장 장소 | 전화 (혹은 취업센터) |
| 담당 공간 | 책상 |
| 연결 오브젝트 | 취업 준비 파일 / 상담 기록 / 일정표 / 모의면접 메모 |
| 핵심 유품 | ✔ 취업 준비 파일 |
| 보조 유품 | 상담 기록 / 일정표 / 면접 메모 |
| 해금 조건 | 취업 준비 파일 조사 → 상담사 통화 가능 |
| 알고 있는 것 | 계속 도전했다 / 꾸준히 상담받았다 |
| 만드는 오판 | "이제 좋아지고 있는 줄 알았습니다." → 플레이어 역시 '회복 중'이라 믿게 됨 |
| 제공 정보 | 반복된 노력 / 계속된 실패 / 포기하지 않았던 모습 |
| **OVAR** | **V** → "생각보다 훨씬 많이 버텼다." |
| 다음 조사 | 러닝화 |

## NPC-장소-유품 매핑

| 장소 | 오브젝트 | 유품 | NPC | 플레이어의 첫 오판 |
|---|---|---|---|---|
| 건물 입구 | 문자·월세 | 월세 고지서 | 집주인 | 생활고 때문에 죽었다 |
| 중문 밖 | 사료·물그릇·이동장 | 고양이 용품 | 이유미 | 착하고 평범한 청년이었다 |
| 책상 | 취업 파일·상담 기록 | **취업 준비 파일(핵심)** | 상담사 | 이제는 회복하고 있었다 |
| 침대/책장 | 졸업사진·가족사진 | **졸업사진(핵심)** | 어머니 | 힘들면 가족에게 말했을 것이다 |

## NPC 오판 구조

| NPC | 플레이어가 처음 믿게 되는 것 | 나중에 수정되는 진실 |
|---|---|---|
| 집주인 | 생활고 때문에 죽었다 | 돈보다 '기대를 저버렸다는 감정'이 더 컸다. |
| 이유미 | 착하고 조용한 사람이었다 | 조용했던 것이 아니라 힘든 모습을 감췄다. |
| 상담사 | 회복되고 있었다 | 끝까지 버텼지만 결국 도움을 요청하지 못했다. |
| 어머니 | 힘들면 말했을 것이다 | 말하지 못한 것이 아니라, 말할 수 없었다. |
| 관리인 | 오판을 만들지 않는다 | 현실과 비현실을 이어주는 안내자 역할만 한다. |

> **원본 첨부**: 캐릭터 이미지 예시 1장 (코멘트: "관리인과 집주인은 생김새 비슷할거같은데 이미지 미생성").

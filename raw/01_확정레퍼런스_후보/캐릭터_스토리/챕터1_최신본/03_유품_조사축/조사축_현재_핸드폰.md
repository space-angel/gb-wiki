# 현재 조사축 — 핸드폰

| 항목 | 내용 |
|---|---|
| 메인 유품 | **핸드폰** |
| 최초 플레이어 인식 | SNS를 많이 보던 사람 |
| 조사 목적 | 비교는 어디서 시작됐는가? |
| 연결 사령세계 | 사령세계 2 |
| 사령세계 감정 | **비교 / 자기비하** |
| 획득 보조유품 | 미정 ×2 |
| 현실 탐문 NPC | 이유미 |
| NPC 최초 진술 | "원래 밝은 사람이었어요." |
| NPC 재인식 | "자기 자신을 계속 깎아내렸어요." |
| 무너지는 오판 | SNS, 유튜브로 시간을 낭비했다. |
| 최종 재해석 | 비교와 자기비하가 문제였다. |
| **이해도 기여** | **A + V** |

## 상태
- ✅ 확정: 메인유품, NPC, 감정, 오판, 재해석
- ⬜ 미정: 보조유품 2개, 환경단서, 정보단서, 사령세계 오브젝트, 조사 완료 조건

## ⚠️ 확인 필요
- **핸드폰은 시스템 문서(ADR-13 Proposed)의 메인 유품 리스트에 없다.** ADR-13은 졸업사진 액자 / 취업 준비 파일철 / **고양이 이동장**을 메인 3종으로 잡고 있다. 자세한 건 [[_INDEX]]의 "확인 필요 사항" §1.
- **이유미가 A와 V를 동시에 담당**한다. [[NPC_정보_및_설계]]에서 이유미의 OVAR는 A로만 표기돼 있어 두 문서 간에도 차이가 있고, A/V 진술자 분리 원칙(ADR-6)과도 충돌 소지가 있다. [[_INDEX]] "확인 필요 사항" §3.

## ⚠️ 확인 필요 사항

이 문서군을 다른 파트(시스템·레벨디자인·아트)로 넘기기 전에 짚어야 할 것들. 전부 **스토리 문서 내부 문제가 아니라 시스템 결정(ADR)과의 어긋남**이다.

### 1. 메인 유품 이름이 두 곳에서 다르다

| | 이 문서군 (07-23 확정 ~ 08-04) | 시스템 문서 ADR-13 (Proposed, 07-20) |
|---|---|---|
| 메인 A | 졸업사진 | 졸업사진 액자 |
| 메인 B | **핸드폰** | 취업 준비 파일철 |
| 메인 C | 취준 파일 | **고양이 이동장** |

겹치는 건 졸업사진 하나뿐. 핸드폰은 ADR-13에 없고, 고양이 이동장은 이 문서군의 메인에 없다.

주목할 점: **같은 작성자의 [[챕터1_사건_상세]](07-20)는 오히려 ADR-13과 거의 일치**한다("졸업사진 액자 / 취업 준비 파일철 / 인턴 출입증 / 낡은 러닝화"). 즉 07-20 → 07-23 사이에 본인이 방향을 바꿨는데 그 변경이 ADR-13에도, 이전 문서에도 반영되지 않은 상태다. → **어느 쪽을 정본으로 삼을지 결정 필요.**

### 2. 판매 금지 유품 목록이 또 다른 버전이다

[[메인유품_진행순서]] 코멘트의 "판매 불가 확정" 목록은 **졸업사진 · 고양이 · 자살 메모**다. 위 두 버전 어느 쪽과도 일치하지 않고, "자살 메모"는 여기서 처음 등장한다. (다만 이건 확정이 아니라 답변 대기 중인 제안이다.)

### 3. 유품 획득 구조가 시스템 결정과 근본적으로 다르다 — **가장 시급**

- **이 문서군**: 메인 유품 3개를 챕터 초반 원룸에서 **동시에 발견**, 하나를 골라 시작. 각 유품이 사령세계 1·2·3을 **독립적으로** 여는 열쇠.
- **ADR-11 (Proposed)**: 메인 A로 1구역을 열고 → **메인 B는 그 1구역 안에서** 획득 → 2구역 개방. "N구역을 여는 유품은 N구역보다 앞에 배치"라는 순환 방지 규칙까지 있는 **순차 체인** 구조.

이건 명명 차이가 아니라 레벨디자인 전제가 통째로 갈리는 지점이다. 두 모델은 거의 같은 시기(ADR-11 07-20 / 이 문서군 07-23)에 서로 확인 없이 각자 결정된 것으로 보인다. → **레벨디자인 담당자와 먼저 맞출 것.**

### 4. 이유미가 A·V 두 단계를 겸한다

[[조사축_현재_핸드폰]]은 이유미의 이해도 기여를 **A + V**로 적었는데, ADR-6은 "A단계와 V단계의 핵심 진술자 NPC는 분리(각 최소 2명)"를 규정한다. 게다가 [[NPC_정보_및_설계]]에서는 이유미가 **A로만** 표기돼 있어 두 문서 사이에도 차이가 있다.

### 5. 축별 "이해도 기여" 매핑이 4플래그 파이프라인과 어떻게 맞물리는지 불명확

3축의 기여가 각각 R / A+V / V이고, **O가 어느 축에도 명시되지 않았다.** 축마다 독립된 O→A→V→R 세트가 있는 건지, 세 축이 하나의 공유 플래그 세트를 나눠 채우는 건지 문서상 확정되지 않는다(후자라면 축 간 순서의존성이 문제가 된다). 3축 구조 자체가 ADR-2 이후에 나온 아이디어라 아직 다뤄진 적 없는 설계 공백으로 보인다.

# 재화 개인이 생각하는 GDD

## (현재까지 확정된 세계관 / 스토리 / 플레이 구조 / 감정 구조 정리)

# 1. 프로젝트 핵심 방향성

## 장르
탑다운뷰 내러티브 액션 RPG
(Narrative-driven Topdown Action RPG)

# 핵심 경험
> **"무력감 속에서 타인을 이해하는 경험"**

플레이어는:
- 단순히 괴물을 죽이는 것이 아니라,
- 죽은 자가 끝내지 못한 마지막 순간을 마주한다.

# 게임 핵심 메시지
> **"문제는 아무도 몰랐다는 게 아니다. 알고도 아무도 문을 열지 않았다는 것이다."**

# 전체 감정 흐름
초반: 이상하다
↓
중반: 불편하다
↓
후반: 이해된다
↓
결말: 나는 이 죽음을 어떤 방식으로 끝낼 것인가?

# 2. 세계관 개요

## 시대 배경
2026~2030년대 대한민국.
사람의 감정과 기억이 데이터처럼 물질화될 수 있다는 사실이 밝혀진 시대.
강한 감정을 품고 죽은 인간은:
- 기억
- 감정
- 후회
- 공포

를 현실에 남긴다.

이 잔류 감정 데이터는:
- 악취
- 냉기
- 변색
- 반복 현상
- 환청

등의 이상현상을 일으킨다.
사람들은 이를 정확히 이해하지 못하지만,
일부 현장은 "설명할 수 없는 사고 현장"으로 취급된다.

# 사령 (死靈)

## 정의
> 망자의 "끝나지 못한 감정"이 현실에 고착된 존재.

사령은 단순 괴물이 아니다.
그들은:
- 죽음의 순간
- 유예된 선택
- 끝내 하지 못한 행동

을 계속 반복하는 존재다.

즉:
> 사령은 "미완"을 반복하는 존재.

# 기록관

## 정의
사령을 이해하고 접근할 수 있는 존재.
기록관은:
- 훈련으로 되는 게 아니다.
- 자신의 기억이 비어버린 인간만 가능하다.

즉:
- 거대한 상실
- 선택하지 못한 과거
- 자기 자신의 미완

을 가진 존재들만,
타인의 미완에 공명 가능하다.

# 기록관의 특징
- 유품과 공명 가능
- 사령세계 진입 가능
- 사령의 감정 해석 가능

BUT:
> 타인을 이해할수록 자신의 존재가 희석된다.

# 존재 희석

## 정의
사령을 깊게 이해할수록:
- 주인공의 존재감이 약해진다.
- 사람들의 인식에서 흐려진다.
- 기억에서 희미해진다.

이것이:
기록관의 대가.

# 관리인

## 정의
기록관이 아니다.
사령을 볼 수도 없다.

BUT:
오랫동안 이상현상을 처리해온 인간.

## 역할
- 유품 거래
- 현실고정 부적 판매
- 봉인구 제공
- 소멸 루트 유도

## 핵심 철학
> "모든 걸 이해하려 들면 결국 네가 먼저 망가진다."

# 3. 주인공 설정

## 현재 상태
- 30세 남성
- 기억 없음
- 자신이 누구였는지 모름
- 유품정리사로 살아감

# 왜 유품정리를 하는가?
주인공은:
유품에 닿을 때마다,
희미한 기억 파편을 본다.

즉:
- 타인의 삶
- 죽음 직전 감정
- 마지막 선택

을 볼 수 있다.

그리고:
그 조각 속에서 자기 자신의 흔적도 느낀다.

# 주인공의 진짜 정체
> "선택을 끝내지 못한 상태로 남아있는 존재"

즉:
주인공 역시 "미완"이다.

# 중요한 점
주인공은:
사령과 완전히 다른 존재가 아니다.
차이는:

| 사령 | 주인공 |
| --- | --- |
| 미완에 갇힘 | 미완을 움직이며 떠돎 |
| 반복 | 탐색 |
| 감정에 잠식 | 타인의 감정 해석 |

# 4. 미완 / 선택하지 않음 / 사령 차이
(팀 공유용 중요)

# 미완

## 정의
> 하고 싶었지만 끝내지 못한 상태.

예:
- 도움 요청 못 함
- 사과 못 함
- 문 못 엶

# 선택하지 않음

## 정의
> 행동할 순간이 있었지만 유예한 상태.

예:
- 신고할까 고민함
- 전화할까 고민함
- 모른 척함

# 사령

## 정의
> 미완된 감정이 죽음 이후에도 반복되는 존재.

즉:
> "끝내지 못한 상태가 고착된 존재."

# 핵심 포인트

## 주인공
선택하지 못한 자.

## 사령
미완이 반복되는 자.

# 5. 현실세계 / 사령세계 구조

# 현실세계

## 역할
> "그 사람이 어떻게 살아왔는가를 읽는 공간"

# 플레이 핵심
- 탐문
- 유품 조사
- 생활 패턴 추론
- 인간관계 조사

# 핵심 철학
오브젝트는:
수집품이 아니라 "삶의 흔적".

# 예시 오브젝트

| 오브젝트 | 의미 |
| --- | --- |
| 미개봉 우편 | 사회적 단절 |
| 빈 냉장고 | 식사 패턴 붕괴 |
| 멈춘 시계 | 시간 감각 상실 |
| 반복 재생 TV | 고립된 일상 |
| 약 봉투 | 정신/신체 붕괴 |

# 사령세계

## 역할
> "끝나지 못한 감정이 규칙이 된 공간"

# 핵심 구조
현실 공간이:
감정적으로 왜곡된다.

# 예시

| 현실 | 사령세계 |
| --- | --- |
| 복도 | 끝없는 회랑 |
| 우편함 | 편지 장애물 필드 |
| TV | 노이즈 시야 방해 |
| 냉장고 | 냉기 구역 |
| 문 | 반복되는 닫힌 문 |

# 핵심 철학
사령세계는:
"던전"이 아니라,
> 고인의 마지막 감정이 플레이 규칙이 된 공간.

# 6. 앵커 단말기

- 감정 공명

- 기억 파편 저장

# 중요

= 감정 좌표

# 9. 루트 구조

# 🌿 성불

## 감정
숭고함

## 철학
> "끝까지 이해하겠다."

## 결과
- 사령 해방
- 주인공 존재 희석 증가

# ⚖️ 제령

## 감정
사명감

## 철학
> "감당 가능한 만큼만 짊어진다."

## 결과
- 이상현상 종료
- 존재 유지
- 다음 사건으로 이동 가능

# ❄️ 소멸

## 감정
냉혹함

## 철학
> "해결보다 중요한 건 제거다."

## 결과
- 빠른 해결
- 인간성 마모
- 유품 거래 중심 플레이

# 10. 관리인과 소멸 루트

## 중요 수정 사항
관리인은:
초자연 능력자가 아니다.

# 소멸부적 정체
사령을 죽이는 게 아니라:
> 현실과의 연결을 강제로 끊는 장치.

즉:

| 성불 | 감정 해소 |
| --- | --- |
| 제령 | 반복 차단 |
| 소멸 | 연결 격리 |

# 관리인의 역할
> "이상현상이 더 번지지 않게 막는 인간"

# 11. 플레이어가 느껴야 하는 최종 감정

# 성불 루트

# 제령 루트
> "계속 남아 다음 죽음을 마주해야 한다."

# 소멸 루트
> "오래 버티려면 결국 감정을 버려야 한다."

# 12. 현재까지 가장 중요하게 정리된 결론

## 이 게임은:
"괴물을 죽이는 게임"이 아니다.

## 플레이어는:
> 죽은 사람을 구하는 것이 아니라,
> 끝나지 못한 순간을 끝내는 존재다.

# 마지막 핵심 문장
> **"나는 죽은 사람을 구하는 게 아니다. 끝나지 못한 순간을 끝내는 것이다."**

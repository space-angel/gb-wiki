# 🎮 게임 시스템 세분화

### 현실세계 (탐문)
- NPC 감정 거리 시스템 (폐쇄→직면 5단계 변화)
- NPC 진술 2단계 시스템 (공개층 / 잠긴층)
- 질문 선택지 생성 시스템 (기본 / 조사기반 / 로그기반 / 아이템기반)
- 공간 조사 시스템 (오브젝트 태그 기록)
- 생활 패턴 로그 시스템 (태그 조합 → 자동 생성 → "추정" 표시)
- 유품 위계 시스템 (핵심 유품 / 보조 유품 분리)
- 공간 변화 시스템 (탐문 깊이에 따라 공간 인상 변화)
- 관리인 / 유품 판매 시스템 (보조 유품 판매 → 탐험 깊이 차단 → 소멸 수렴)

### 사령세계 (탐험)
- 메트로배니아 필드 시스템 (탐험 범위 점진적 확장)
- 감정 패턴 몬스터 시스템 (고인 감정 → 전투 패턴 변환)
- 전투 시스템 (패링 카운터 / 회피 스킬 / CC 제거 청소 도구)
- 자원 시스템 (체력 / 패링 게이지 / 스킬 게이지)
- 보스 페이즈 시스템 (1페이즈 감정표출 / 2페이즈 감정폭주 / 3페이즈 감정붕괴)
- 보스 이해도 연동 시스템 (이해도 높을수록 패턴 해석 가능 / 3페이즈 진입 조건)
- 사령세계 NPC 소멸 시스템 (이해도 누적 → 타인 시선 NPC 순차 소멸)
- 기억 앵커 시스템 (특정 이해도 초과 시 발동 → 고인 기억 재생 → 현실 탐문 경로 해금)
- 드롭 아이템 시스템 (몬스터 처치 → 보조 유품 조각 / 기억 파편 드롭)
- 보물상자 시스템 (필드 탐험 → 이해도 증가 아이템 / NPC 진술 해금 아이템 획득)
- 현실-사령세계 공간 대응 시스템 (현실 공간 구조 → 사령세계 지형 / 기믹으로 변환)
- 현실 단서 → 전투 패턴 변환 시스템 (탐문 결과 → 보스 패턴 / 약점 구조 결정)

### 둘을 종합하여 재구성 (앵커 단말기)
- 앵커 단말기 진입 시스템 (초반 출입증 → 루프마다 기능 확장)
- 키워드 조합 시스템 (진술 키워드 + 유품 키워드 → 고인 상태 추리)
- 이해도 측정 시스템 (관찰 / 연결 / 검증 / 재해석 4단계 가중 측정)
- 이해도 세계 반영 시스템 (수치 비표시 → NPC 반응 / 공간 변화 / 단말기 기능으로만 체감)
- 엔딩 분기 시스템 (이해도 총합 → 성불 / 제령 / 소멸 자동 판정)
- 존재 희석 시스템 (챕터 누적 → 주인공 독백 / 인식 점진적 소멸)

## 감사 결과 (자동, 2026-08-03)
- 상태: 위반발견
- 근거: (1) 전투 시스템에 "패링 카운터"와 "패링 게이지"를 명시하여 ADR-8("패링·가드 메카닉을 추가하지 않는다")에 위반됨. (2) 이해도 측정 시스템을 "관찰×1/연결×3/검증×5/재해석×10" 가중치로, 엔딩 분기를 "재해석 70% 이상/검증 이상 50% 이상/관찰·연결에만 머무름" 퍼센트 임계값으로 서술하여, ADR-2가 명시적으로 기각한 가중 합산 스칼라 모델(§4.3 대안 검토 기각 항목)을 그대로 사용함. (3) 시스템 흐름도상 보스전은 "챕터 종료 조건 충족" 이후에만 도달하도록 되어 있어, 보스 도전이 첫 진입부터 항상 가능해야 한다는 ADR-2(§2.3)·ADR-7(§2.3)과도 충돌함.

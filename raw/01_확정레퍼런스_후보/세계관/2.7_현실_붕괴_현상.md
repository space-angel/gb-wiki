# 2.7 현실 붕괴 현상

**핵심 문장:**
현실 붕괴는 강한 감정과 미완이 특정 공간에 과도하게 응집되며,
현실과 사령세계의 경계가 무너지는 현상이다.

### 1. 붕괴 징후
- 반복 현상
- 존재 인식 저하
- 시간 왜곡
- 기억 누락

### 2. 붕괴 규모

| 단계 | 설명 |
| --- | --- |
| 미약 | 개인 공간 오염 |
| 중간 | 주변인 영향 |
| 심각 | 지역 단위 왜곡 |

### 3. 기록관과의 관계
- 붕괴를 인식 가능
- 일부 봉합 가능
- 완전 제거는 불가능

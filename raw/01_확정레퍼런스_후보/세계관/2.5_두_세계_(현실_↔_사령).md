# 2.5 두 세계 (현실 ↔ 사령)

게임은 현실세계와 사령세계라는 두 개의 층으로 구성된다.
하지만 이 둘은 완전히 분리된 공간이 아니다.

사령세계는 현실과 단절된 이세계가 아니라:
> 현실에 남은 감정과 미완이 침식되어 형성된 감정 구조 공간

이다.
따라서 두 세계는 항상 서로 영향을 주고받는다.

## 1. 두 세계의 관계

> 현실은 사령세계를 해석하고, 사령세계는 현실의 감정을 반복한다.

플레이어는:
- 현실에서 단서를 수집하고
- 사령세계에서 그 감정 구조를 체험하며
- 다시 현실로 돌아와 사건의 의미를 재해석한다.

즉:
- 현실은 원인을 보여주고
- 사령세계는 결과를 반복한다.

### 중요한 점
한쪽만 플레이해서는 케이스를 종결할 수 없다.
- 현실만 보면 감정 구조를 이해할 수 없고
- 사령세계만 보면 인간의 맥락을 이해할 수 없다.

이 상호 의존성이 게임의 핵심 루프를 만든다.

## 2. 현실세계 (토글: = 사회 속 고인을 이해하는 공간 — 타인의 기억 / 관계 / 사회적 이미지 / 생활 흔적 / 현실의 잔여감)

```
사회 속에서 고인을 이해하는 공간
```

현실세계는 단순 조사 파트가 아니다.
이곳은:
- 고인의 흔적
- 인간관계
- 사회적 위치
- 생활 습관
- 무너져가는 과정

을 체감하는 공간이다.

### 2.1. 정의
> 사건 현장이자, 고인의 삶을 재구성하는 공간

주인공은 현실에서:
- 특수청소업자
- 유품정리사

로 현장에 들어간다.

플레이어는:
- 방 구조
- 생활 흔적
- 유품
- 냄새
- 정리되지 않은 물건
- NPC 증언

등을 조사하며,
고인의 마지막 순간을 재구성한다.

### 중요한 점
현실세계의 핵심은 "추리"가 아니다.
핵심은:
> 왜 이 사람이 이런 상태에 도달했는가

를 이해하는 것이다.

### 2.2. 현실세계에서 하는 일
플레이어는 현실세계에서 다음을 파악한다.
- 고인은 어떤 사람이었는가
- 사회 속에서 어떤 위치였는가
- 무엇을 두려워했는가
- 무엇을 숨기고 있었는가
- 어떤 감정이 반복되고 있었는가
- 마지막에 무엇을 하지 못했는가

### 현실세계의 특징
현실세계는:
극적인 사건보다 "생활의 무너짐"을 보여줘야 한다.

예시:
- 개봉되지 않은 우편물
- 계속 미뤄진 설거지
- SNS 비교 흔적
- 취업 사이트 기록
- 편의점 영수증
- 약 봉투
- 읽지 못한 문자

이런 사소한 흔적들이:
고인의 심리와 사회적 붕괴를 설명한다.

### 2.3. 현실세계의 톤

| 차원 | 현실세계 |
| --- | --- |
| 속도 | 느리고 정적임 |
| 행위 | 듣고 관찰하기 |
| 감정 | 거리감 / 응시 |
| 시각 | 따뜻하지만 공허함 |
| 사운드 | 생활 소음 중심 |
| 인터랙션 | 탐문·관찰·정리 |
| 플레이 감각 | 숨 막히는 현실감 |

## 3. 사령세계 (토글: = 고인의 내면 구조를 탐험하는 공간 — 선택하지 못한 감정 / 왜곡된 기억 / 내면의 반복 / 감정의 구조화 / RPG적 탐험)

```
고인의 감정과 반복 행동이 공간화된 세계
```

사령세계는 단순한 이세계가 아니다.
그곳은:
- 고착된 감정
- 반복되는 행동
- 왜곡된 기억
- 끝나지 못한 순간

이 현실 공간을 침식하며 만들어낸 구조다.

### 3.1. 정의
> 고인의 마지막 감정과 반복 구조가 시각화된 공간

사령세계는 현실을 기반으로 생성된다.
즉:
현실 공간 자체가,
고인의 감정 논리에 따라 뒤틀린다.

예시:
- 원룸 복도가 끝없이 반복된다
- 알림 소리가 공간 전체를 채운다
- 계단이 계속 위로만 이어진다
- 문이 열리지 않는다
- 시간이 특정 시각에 멈춘다

### 중요한 점
사령세계는 랜덤 판타지 공간이 아니다.
모든 구조는:
> "왜 저 사람이 끝나지 못했는가"

를 기반으로 설계되어야 한다.

### 3.2. 사령세계에서 하는 일
사령세계에서는 현실에서 수집한 정보가:
- 전투 패턴
- 공간 기믹
- 환경 변화
- 보스 구조

로 변환된다.

| 현실 단서 (Input) | 사령세계 패턴 (Output) |
| --- | --- |
| 받지 못한 전화 | 반복되는 전화벨 패턴 |
| 닫힌 문 | 계속 닫히는 공간 구조 |
| 도움 요청 실패 | 플레이어를 밀어내는 충격파 |
| 방치된 유품 | 보스 약점 및 성불 조건 |
| SNS 비교 강박 | 플레이어 복제 그림자 생성 |
| 취업 실패 불안 | 끝없이 올라가는 계단 구조 |
| 읽지 못한 문자 | UI 오류 및 오입력 발생 |

### 중요한 점
사령세계의 전투는:
"괴물을 때려잡는 것"이 아니다.
플레이어는:
> 반복되는 감정 구조를 읽고 대응하는 것

에 가깝게 느껴야 한다.

### 3.3. 사령세계의 톤

| 차원 | 사령세계 |
| --- | --- |
| 속도 | 빠르고 압박감 있음 |
| 행위 | 읽고 반응하기 |
| 감정 | 몰입 / 충돌 |
| 시각 | 차갑고 선명함 |
| 사운드 | 노이즈·반복음·왜곡 |
| 인터랙션 | 전투·회피·퍼즐 |
| 플레이 감각 | 감정 속에 휘말리는 느낌 |

## 4. 두 세계의 톤 대비

이 대비는 게임 전체의 감정 리듬을 만든다.
한쪽의 톤이 다른 쪽을 침범하면,
두 세계 모두 흐려진다.

| 차원 | 현실세계 | 사령세계 |
| --- | --- | --- |
| 속도 | 느리고 정적 | 빠르고 압박적 |
| 행위 | 관찰·탐문 | 반응·생존 |
| 감정 | 거리감·응시 | 몰입·충돌 |
| 시각 | 따뜻하지만 공허함 | 차갑고 선명함 |
| 사운드 | 생활 소음 | 노이즈·왜곡 |
| 인터랙션 | 조사·정리 | 액션 RPG |
| 플레이 감각 | 현실 체감 | 감정 침식 |

## 5. 두 세계의 핵심 명제

> 현실세계는 왜 무너졌는가를 보여주고, 사령세계는 그 무너짐을 끝없이 반복시킨다.

### 현실 → 사령세계
현실의:
- 유품
- NPC 진술
- 생활 흔적
- 사회적 맥락 등이

사령세계의:
- 패턴
- 구조
- 기믹
- 감정 반복으로 변환된다.

### 사령세계 → 현실
사령세계에서:
- 기억 앵커 발동
- 미니보스 처치
- 감정 구조 해석
- 심층 기억 접근

등을 통해 얻은 정보가,
현실 탐문의 새로운 방향을 만든다.

## 6. 두 세계와 루트 구조

### 성불
현실과 사령세계를 모두 깊게 이해하려 한다.
플레이어는:
고인의 감정 구조 전체에 공명하게 된다.

### 제령
현실과 사령세계를 기록과 구조로 분석한다.
감정에 잠식되지는 않지만,
흔적 역시 지우지 않는다.

### 소멸
사령세계를 감정과 기억의 공간이 아니라,
현실에 남은 오염 현상으로 보기 시작한다.

현실 탐문 역시:
고인을 이해하기 위한 과정이 아니라,
효율적으로 사건을 정리하기 위한 방향으로 변해간다.

유품은 더 이상 감정의 흔적이 아니다.
소멸 성향의 플레이어는 유품을:
- 재화
- 생존 수단
- 거래 가능한 자원

으로 보기 시작한다.

플레이어는 유품을 판매해 재화를 얻고,
관리인을 통해:
- 강제소멸부적
- 오염 억제 장치
- 탐문 보조 아이템

등을 구매할 수 있다.

소멸은 감정을 이해하지 못하는 루트가 아니다.
현실적 선택과 효율을 위해,
더 이해할 가능성을 스스로 포기하기 시작하는 루트다.

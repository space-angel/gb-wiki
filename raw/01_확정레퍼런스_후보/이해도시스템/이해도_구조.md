# 이해도 구조

## 플래그는 bool로 두고, "전부/N개" 같은 정량 표현은 ADR 차원에서 "지정 목록"으로 명시화.
## 숫자는 계산 내부에만 살고, 결과는 항상 4개의 true/false로 떨어진다.

```
O_reached = COUNT(발견한 핵심 아이템 ∩ O단계 지정 목록) == LEN(O단계 지정 목록)
AND COUNT(발견한 보조 아이템) >= N

A_reached = 보드 연결(보조 아이템 ≥2) → 가설 정답 선택

V_reached = A_reached 해금 NPC 전원과 대화 완료
AND (보드 연결 → 가설 정답) [OQ-10 확정 필요]

R_reached = 보드 연결(R단계 지정 핵심 아이템 목록) → 트리거 장면 완료
```

### 전체 구조

```
플레이어 행동 (정량 카운트)
↓
계산식 적용
↓
플래그 판정 (bool)
↓
O_reached → A_reached → V_reached → R_reached
(관찰)      (연결)       (검증)       (재해석)
```

### O_reached — 관찰 (Observation)
> 정의: 챕터 내 지정된 핵심 아이템 일부 + 보조 아이템 일정 수 이상 발견

#### 케이스 1 지정 목록
```
O단계 핵심 아이템 목록 = [핵심-1(부재중 전화), 핵심-2(탈락 메일)]
  ※ 핵심-3(녹음 파일)은 보스방에서만 발견되므로 O단계 목록 제외

O단계 보조 아이템 최소 수량 (N) = 2
```

#### 내부 계산식
```
관찰_핵심_카운트 = COUNT(발견한 아이템 ∩ O단계 핵심 아이템 목록)
관찰_보조_카운트 = COUNT(발견한 아이템 ∩ 전체 보조 아이템 목록)

O_reached = (관찰_핵심_카운트 == 2) AND (관찰_보조_카운트 >= 2)
```

#### 플레이 예시

| 행동 | 관찰_핵심_카운트 | 관찰_보조_카운트 | O_reached |
| --- | --- | --- | --- |
| 침대 옆 휴대폰만 조사 (핵심-1 발견) | 1 | 0 | false |
| + 부엌 사료 봉투 발견 (보조-1) | 1 | 1 | false |
| + 책상 출력물 발견 (핵심-2) + 컴퓨터 화면 조사 (보조-4) | 2 | 2 | **true** |

→ 핵심 아이템 2개(부재중 전화, 탈락 메일) + 보조 아이템 2개(고양이 사료, 취업 사이트)를 발견한 시점에 관찰 완료.

### A_reached — 연결 (Association)
> 정의: 재구성 보드에서 보조 아이템 연결 후 가설 제출 정답

#### 케이스 1 지정 조합
```
A단계 보드 연결 재료 = [보조-2(SNS 비공개), 보조-5(미개봉 택배)]
A단계 가설 정답 = (B) "보여주고 싶지 않은 게 있었다"
```

#### 내부 계산식
```
연결_재료_확보 = (보조-2 보유) AND (보조-5 보유)
연결_완료 = 보드에서 보조-2 + 보조-5 연결 시도 발생

가설_결과 ∈ {정답, 오답, 미제출}

A_reached = 연결_재료_확보 AND 연결_완료 AND (가설_결과 == 정답)
```

#### 플레이 예시 — 분기별 bool

| 시나리오 | 연결_재료_확보 | 연결_완료 | 가설_결과 | A_reached | 결과 상태 |
| --- | --- | --- | --- | --- | --- |
| ① 보조-2 판매함, 보조-5만 보유 | false | - | - | **false** | 연결 자체 불가 → 소멸 수렴 |
| ② 재료 보유, 보드 연결 후 (A) 선택 | true | true | 오답 | **false** | 오해 1 활성 |
| ③ 재료 보유, 보드 연결 후 (C) 선택 | true | true | 오답 | **false** | 오해 1 활성 |
| ④ 재료 보유, 보드 연결 후 (B) 선택 | true | true | 정답 | **true** | 이유미 해금 |

**오해 1 활성 상태 (시나리오 ②③)**
```
오해1_플래그 = (A_reached == false) AND (가설_제출_시도 >= 1)

오해1_플래그 == true 인 동안:
  - 이유미 NPC 대화 잠김
  - 집주인 대사 = "원래 그런 사람" 고착
  - 보조-5 보드 표시 중요도 낮음
```

**재시도 경로**
```
오해1_해소 = (오해1_플래그 == true) AND (보조-2+보조-5 재연결) AND ((B) 재선택)

오해1_해소 == true → A_reached = true (시나리오 ④로 전환)
```

### V_reached — 검증 (Verification)
> 정의: A_reached로 해금된 NPC와 재탐문 대화 완료 + 보드 연결 후 가설 제출 정답

#### 케이스 1 지정 조합
```
V단계 필수 대화 = [이유미]  (A_reached 해금 NPC)
V단계 보드 연결 재료 = [핵심-2(탈락 메일), "끊어진 연결" 키워드]
  ※ "끊어진 연결" 키워드 = 핵심-1 + 이유미 증언 연결로 생성
V단계 가설 정답 = (C) "걱정 끼치고 싶지 않아서"
```

#### 내부 계산식
```
대화_완료 = (이유미와의 대화 완료 == true)
키워드_생성 = (핵심-1 보유) AND (이유미 대화 완료)
연결_완료 = 키워드_생성 AND (핵심-2 보드 연결 시도 발생)

가설_결과 ∈ {정답, 오답, 미제출}

V_reached = (A_reached == true)
            AND 대화_완료
            AND 연결_완료
            AND (가설_결과 == 정답)
```

#### 플레이 예시 — 분기별 bool

| 시나리오 | A_reached | 대화_완료 | 연결_완료 | 가설_결과 | V_reached |
| --- | --- | --- | --- | --- | --- |
| ⑤ A_reached=false 상태 | false | - | - | - | **false** (시도 자체 불가) |
| ⑥ 이유미 대화 미완료 | true | false | - | - | **false** |
| ⑦ 대화 완료, 보드 연결 후 (A) 선택 | true | true | true | 오답 | **false** |
| ⑧ 대화 완료, 보드 연결 후 (B) 선택 | true | true | true | 오답 | **false** |
| ⑨ 대화 완료, 보드 연결 후 (C) 선택 | true | true | true | 정답 | **true** |

**구조적 순서 의존성 확인 (시나리오 ⑤)**
```
A_reached == false 인 경우:
  → 이유미 NPC 대화 자체가 잠겨있음
  → 대화_완료 = false 고정
  → "끊어진 연결" 키워드 생성 불가
  → V단계 가설 제출 시도 자체가 불가능

∴ V_reached는 A_reached 없이는 "달성 실패"가 아니라 "달성 시도 자체가 성립 불가"
```

**오해 2 활성 상태 (시나리오 ⑦⑧)**
```
오해2_플래그 = (V_reached == false) AND (A_reached == true) AND (V단계_가설_제출_시도 >= 1)

오해2_플래그 == true 인 동안:
  - 어머니 NPC 대화 잠김
  - 핵심-3(녹음 파일) 재생 잠김
  - 이유미 대사 = "가족도 안 찾는 사람" 고착
```

**재시도 경로**
```
오해2_해소 = (오해2_플래그 == true) AND (핵심-1+핵심-2 재조합) AND ((C) 재선택)

오해2_해소 == true → V_reached = true (시나리오 ⑨로 전환)
```

### R_reached — 재해석 (Reinterpretation)
> 정의: R단계 지정 핵심 아이템 조합 + 검증으로 해금된 증언 결합 → 반전 트리거 완료

#### 케이스 1 지정 조합
```
R단계 보드 연결 재료 = [핵심-3(녹음 파일), 핵심-1(부재중 전화), 어머니 증언]
  ※ 핵심-2는 V단계에서 이미 소모, R단계 조합에는 미포함
```

#### 내부 계산식
```
어머니_증언_확보 = (V_reached == true)  AND (어머니 대화 완료 == true)
핵심3_확보 = (보스방 진입 == true) AND (핵심-3 발견 == true)

조합_완료 = 핵심3_확보 AND (핵심-1 보유) AND 어머니_증언_확보
트리거_재생 = (조합_완료 == true) AND (반전 장면 재생 완료 == true)

R_reached = 트리거_재생
```

#### 플레이 예시 — 분기별 bool

| 시나리오 | V_reached | 어머니_증언_확보 | 핵심3_확보 | 조합_완료 | R_reached |
| --- | --- | --- | --- | --- | --- |
| ⑩ V_reached=false 상태로 보스방 진입 | false | false | true | **false** (어머니 증언 슬롯 비어있음) | **false** |
| ⑪ V_reached=true, 어머니 대화 미완료 | true | false | true | false | **false** |
| ⑫ V_reached=true, 어머니 대화 완료, 보스방에서 핵심-3 미발견 | true | true | false | false | **false** |
| ⑬ 전부 충족, 보드 조합 → 반전 장면 재생 완료 | true | true | true | true | **true** |

**구조적 순서 의존성 확인 (시나리오 ⑩)**
```
V_reached == false 인 경우:
  → 어머니 NPC 대화 자체가 잠겨있음
  → 어머니_증언_확보 = false 고정
  → R단계 조합 재료 중 "어머니 증언" 슬롯이 항상 비어있음
  → 조합_완료 = false 고정 (영구)

∴ 보스방 진입(O_reached만으로 가능)은 되지만,
  V_reached가 false인 상태로는 R_reached에 영원히 도달 불가
```

### 최종 플래그 조합 → 엔딩 분기

#### 종합 계산식
```
이해도_상태 = (O_reached, A_reached, V_reached, R_reached)
```

#### 엔딩 분기표 — 전체 16개 조합 중 도달 가능한 경로

| O | A | V | R | 도달 가능 여부 | 엔딩 |
| --- | --- | --- | --- | --- | --- |
| false | - | - | - | 도달 가능 (보스 미도전) | 진행 불가 (챕터 미완료) |
| true | false | false | false | 도달 가능 | **소멸** (보스 도전, 미약화) |
| true | true | false | false | 도달 가능 (오해1 해소 후 오해2 미해소) | **소멸** 또는 **제령 미달** |
| true | true | true | false | 도달 가능 | **제령** |
| true | true | true | true | 도달 가능 | **성불** |
| true | false | true | * | **도달 불가** (V는 A 없이 성립 불가) | - |
| true | * | false | true | **도달 불가** (R은 V 없이 성립 불가) | - |

> `*` = false 또는 true 무관, 단 구조상 해당 행 자체가 발생하지 않음

#### 도달 불가 조합이 증명하는 것
```
(O,A,V,R) = (true, false, true, *) 인 상태는 게임 내에서 절대 발생하지 않는다.
이유: V_reached 계산식에 (A_reached == true)가 AND 조건으로 포함되어 있음.

(O,A,V,R) = (true, *, false, true) 인 상태도 절대 발생하지 않는다.
이유: R_reached 계산식의 "어머니_증언_확보"가 V_reached에 종속됨.
```

→ ADR-002가 의도한 "R=0이어도 성불 불가" + "축 간 점수 교환 불가"가 **계산식 레벨에서 물리적으로 발생 자체가 차단**되어 있음을 확인.

### 정량-정성 분리 요약

| 층위 | 내용 | 노출 |
| --- | --- | --- |
| 정량 (카운트/조합) | 관찰_핵심_카운트, 연결_재료_확보, 어머니_증언_확보 등 | 플레이어에게 절대 비노출 |
| 정성 (플래그) | O_reached, A_reached, V_reached, R_reached (4개 bool) | 내부 시스템에서만 참조 |
| 체감 (연출) | NPC 대사 전환, 영역 잠금/해제, 단말기 기능 확장, 보스 페이즈 변화 | 플레이어가 체감하는 유일한 형태 |

## 감사 결과 (자동, 2026-08-03)
- 상태: 위반발견
- 근거: "O_reached — 관찰" 절이 "O단계 핵심 아이템 목록 = [핵심-1, 핵심-2]"로 정의하며 "핵심-3(녹음 파일)은 보스방에서만 발견되므로 O단계 목록 제외"라고 명시한다. 이는 ADR-3 §2.3/Compliance "O_reached는 핵심 3개 전부 발견(보스방 전용 핵심 포함) + 보조 N개 이상의 AND 조건으로 평가한다"와 정면으로 충돌한다(3개 중 2개만 요구). 4종 플래그의 순서 의존 구조 자체(ADR-2)는 잘 구현되어 있으나, O_reached 판정 조건이 ADR-3을 위반함.

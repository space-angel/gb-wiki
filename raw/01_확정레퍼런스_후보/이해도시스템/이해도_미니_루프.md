# 이해도 미니 루프

## [현실 진입]
방에 들어선다. 좁은 원룸. 멈춰있는 시간.
→ 침대 옆 휴대폰 조사
핵심-1(부재중 전화 - 어머니 14건) 발견
→ 사령세계 2구역 잠금 해제

→ 부엌 구석 조사
보조-1(고양이 사료) 발견

→ 휴대폰 갤러리 조사
보조-2(SNS 비공개 캡처) 발견

→ 현관 앞 조사
보조-5(미개봉 생일 택배) 발견

※ O_reached 판정: 핵심-1 보유 + 보조 3개 보유 → true
※ 이 시점부터 보스 도전 가능 (플레이어는 인지 못함)

## [재구성 보드 — A단계]
보조-2(SNS 비공개) + 보조-5(미개봉 택배) → 보드 연결
"스스로 가린 것" 키워드 생성

가설 제시: "김태현은 왜 사람들과 거리를 뒀을까?"
(A) 원래 사람을 안 좋아하는 성격이었다
(B) 보여주고 싶지 않은 게 있었다
(C) 가족과 사이가 안 좋았다

→ 플레이어 선택: (B)
※ A_reached: true
→ 옆집 주민 이유미 NPC 대화 해금
→ 집주인 대사 중층 전환

## [현실 탐문 — 이유미]
이유미 대화 (심층 진술 해금됨)
"한 번은 복도에서 마주쳤는데, 표정이 좀 평소랑 달랐어요.
그날 밤엔 문 앞에 서있는 소리도 들렸고요."

→ 책상 위 조사
핵심-2(마지막 면접 탈락 메일) 발견
→ 사령세계 3구역 잠금 해제

## [사령세계 — 2구역 + 3구역 탐험]
(원문에 인라인 discussion 스레드 마커가 있었음: discussion://3808826f-8563-8059-b3b1-e1380996de03/ac185bda-e233-42ff-baa3-d51431c265cf/3808826f-8563-80ae-b305-001c160c49bd)

2구역 진입
→ 그림자가 복제되며 따라옴. 윤곽이 사람 형태로 보였다 흩어짐
→ 기억 앵커 접촉: "취업 사이트를 끝없이 새로고침하는" 장면 재생
→ 드롭 아이템: 보조-3(졸업앨범) 조각 획득

3구역 진입
→ 좁아지는 공간. 자기혐오형 체력 감소 기믹
→ 감정 패턴 몬스터 처치 → 보조-4(취업 사이트 즐겨찾기) 획득

## [현실 복귀]
획득한 보조 아이템 반입 → 추가 정보는 없음 (이미 핵심 경로 진행 중)

## [재구성 보드 — V단계]
핵심-2(탈락 메일) + "끊어진 연결" 키워드
(핵심-1 + 이유미 증언으로 생성된 키워드) → 보드 연결

가설 제시: "왜 가족에게도 연락하지 않았을까?"
(A) 가족과 원래 소원했다
(B) 취업 실패를 들키기 싫었다
(C) 더 이상 기대를 주고 싶지 않았다

→ 플레이어 선택: (C)
※ V_reached: true
→ 어머니 NPC 대화 해금
→ 핵심-3(녹음 파일) 재생 잠금 해제

## [현실 탐문 — 어머니]
어머니 대화 (해금됨)
"택배 보낸 거... 사실 걱정은 됐어요.
근데 또 전화하면 부담 줄까 봐. 그래서 그냥... 기다렸어요."

→ 침대 밑 조사
핵심-3(최근 일기장 / 녹음 파일) 발견

## [재구성 보드 — R단계]
핵심-3(녹음 파일) + 핵심-1(부재중 전화) + 어머니 증언 → 보드 연결

반전 트리거 장면 재생:
6초의 정적, 숨소리, 통화 버튼을 누르려다 끊는 소리
"...오늘은 진짜 해야겠다"

※ R_reached: true
→ 성불 루트 해금 (보스전 대화 선택지 등장)

## [사령세계 — 보스방]
진입 시 보스 형체 처음으로 완전히 드러남
좁은 방 안에 웅크려 앉은 청년 실루엣

전투 시작 직전, 보스가 멈춤. 웅크리고 앉음.
대화 선택지 등장 (전투 스킵)

→ 플레이어 선택: 공명 / 대화

보스(고인) 반응:
사령세계의 반복이 멈춤
청년 형상이 천천히 일어섬

## [엔딩 — 성불]
방으로 복귀. 처음 들어왔을 때와 다른 조용함.
주인공: 타인을 이해할수록 자신이 조금씩 희미해지고 있음을 느낀다.

(O,A,V,R) = (true, true, true, true)

## 감사 결과 (자동, 2026-08-03)
- 상태: 위반발견
- 근거: "※ O_reached 판정: 핵심-1 보유 + 보조 3개 보유 → true"라고 명시하는데, 핵심 아이템 3개 중 1개(핵심-1)만으로 O_reached를 true로 판정한다. ADR-3 Compliance "O_reached는 핵심 3개 전부 발견 + 보조 N개 이상 발견의 AND 조건으로 평가한다"를 위반. O/A/V/R 4종 플래그 자체(5번째 플래그 없음)는 ADR-2와 정합함.

# 🤮 이해도 시스템 초안

## 이해도 시스템 (Understanding System)
(원문에 인라인 discussion 스레드 마커가 있었음: discussion://3708826f-8563-8052-80e0-c0c09d0e54a4/efd18c68-692c-46a0-8a5a-c697a98aa933/3708826f-8563-80d3-9b04-001ce0051f4f)

### 개요
유품정리사의 이해도 시스템은 플레이어가 얼마나 많은 정보를 수집했는지를 측정하는 시스템이 아니다.
이해도는 플레이어가 고인에 대해 가진 인식을 얼마나 수정하고 확장했는지를 측정하는 시스템이다.

따라서 이해도는 단일 점수로만 관리되지 않는다.
시스템은 크게 두 개의 계층으로 구성된다.

#### 1. 디자이너 데이터 (Designer Data)
플레이어의 행동량을 정량적으로 측정하기 위한 데이터.
밸런싱, QA, 콘텐츠 검증, 엔딩 판정 등에 사용된다.

#### 2. 진행 데이터 (Progress Data)
게임 내 콘텐츠 개방 여부를 관리하는 데이터.
NPC 진술 변화, 신규 질문 생성, 지역 개방, 보스 페이즈 개방 등에 사용된다.

## 핵심 설계 원칙
이해도는 플레이어의 머릿속을 측정하지 않는다.
대신 플레이어가 이해했다고 판단할 수 있는 행동들을 기록하고 분석한다.

즉, 수집 → 연결 → 검증 → 재해석
이라는 학습 과정을 데이터화한다.

## 이해도 게이지 구조

유품정리사는 총 4개의 독립된 이해도 게이지를 사용한다.

### 1. 관찰도 (Observation)
정보를 발견하는 능력.

#### 측정 예시
- 유품 발견
- NPC 최초 진술 획득
- 기억 앵커 발견
- 사령세계 단서 획득

#### 의미
"고인을 보기 시작했다"

### 2. 연결도 (Association)
획득한 정보를 서로 연결하는 능력.

#### 측정 예시
- 단서 연결
- 유품 제시
- 신규 질문 해금
- 단서 간 관계 발견

#### 의미
"고인의 삶을 구조적으로 이해하기 시작했다"

### 3. 검증도 (Verification)
가설을 확인하고 수정하는 능력.

#### 측정 예시
- 재탐문 수행
- 숨겨진 진술 발견
- 사령세계 정보 반영
- 기존 가설 수정

#### 의미
"고인에 대한 오해를 바로잡기 시작했다"

### 4. 재해석도 (Reinterpretation)
사건과 인물을 다시 이해하는 능력.

#### 측정 예시
- 핵심 감정 발견
- 방관의 순간 발견
- 관계의 진실 발견
- 마지막 선택의 의미 이해

#### 의미
"고인을 이해했다"

## 게이지 활용

### 관찰도
사용처
- 조사 가능 오브젝트 개방
- 추가 유품 발견
- 기억 앵커 노출

### 연결도
사용처
- 신규 질문 생성
- NPC 추가 대화
- 숨겨진 지역 개방

### 검증도
사용처
- 재탐문 루트 생성
- 고급 진술 해금
- 사령세계 추가 경로 개방

### 재해석도
사용처
- 보스 특수 페이즈개방
- 고인과의 최종 대화
- 성불 루트 해금

## 데이터 구조

### 디자이너 데이터
플레이어 행동을 점수로 저장한다.

```
O = Observation Score
A = Association Score
V = Verification Score
R = Reinterpretation Score
```

예시
```
O = 12
A = 8
V = 5
R = 2
```

## 정규화
챕터마다 콘텐츠 양이 다르므로 점수는 반드시 정규화한다.

### 공식
(원문에 인라인 discussion 스레드 마커가 있었음: discussion://3708826f-8563-8052-80e0-c0c09d0e54a4/ba29511c-6f16-48dd-8978-be8a4ec99317/3718826f-8563-8066-a827-001c51780238)

```
ON = O / Omax
AN = A / Amax
VN = V / Vmax
RN = R / Rmax
```

### 예시
```
관찰 12 / 15 = 0.80
연결 8 / 10 = 0.80
검증 5 / 8 = 0.625
재해석 2 / 4 = 0.50
```

## 종합 이해도 계산
정규화된 값을 가중치와 결합하여 최종 이해도(U)를 계산한다.

### 권장 가중치
관찰보다 재해석이 중요하다.

```
관찰 10%
연결 20%
검증 30%
재해석 40%
```

### 공식
```
U = 0.1*ON + 0.2*AN + 0.3*VN + 0.4*RN
```

### 계산 예시
```
ON = 0.80
AN = 0.80
VN = 0.625
RN = 0.50

U = 0.1(0.80) + 0.2(0.80) + 0.3(0.625) + 0.4(0.50)
  = 0.08 + 0.16 + 0.1875 + 0.20
  = 0.6275

최종 이해도 62.75%
```

## 콘텐츠 해금 구조
중요한 점은 대부분의 시스템이 종합 이해도(U)를 직접 사용하지 않는다는 것이다.
실제 게임은 개별 게이지를 참조한다.

### 예시

#### NPC 진술 변화
```
RN ≥ 50%
```
↓
최종 진술 해금

#### 신규 질문 생성
```
VN ≥ 40%
```
↓
새 질문 생성

#### 숨겨진 지역 개방
```
AN ≥ 60%
```
↓
비밀 통로 개방

#### 보스 3페이즈
```
RN ≥ 50%
```
↓
감정 붕괴 페이즈 진입

#### 고인과의 최종 대화
```
RN ≥ 75%
```
↓
심층부 진입 가능

## 엔딩 판정
(원문에 인라인 discussion 스레드 마커가 있었음: discussion://3708826f-8563-8052-80e0-c0c09d0e54a4/7518882f-d010-47ac-a49a-0f0480bf023b/3718826f-8563-802a-bbe6-001c5bbec43e)
엔딩은 단순 점수 합산이 아닌 플래그 조건을 함께 사용한다.

### 성불
- 재해석도 조건 충족
- 보스 특수페이즈 진입
- 고인 최종 대화 완료

### 제령
- 검증도 조건 충족
- 보스 격파
- 최종 대화 미달성

### 소멸
- 핵심 재해석 실패
- 보스 존재 모른채로 끝

## 최종 정의
유품정리사의 이해도 시스템은
플레이어의 행동 데이터를 기반으로
관찰 → 연결 → 검증 → 재해석
의 학습 과정을 측정하는 연속 학습 기반 진행도 시스템이다.

(원문에 인라인 discussion 스레드 마커가 있었음: discussion://3708826f-8563-8052-80e0-c0c09d0e54a4/2464e1b7-3903-4198-8446-788b025bbbff/3718826f-8563-80a5-b90d-001c4a47d58a)
종합 이해도(U)는 플레이어의 전체 이해 수준을 나타내며,
개별 게이지(O/A/V/R)는 게임 내 콘텐츠 개방과 전투 경험 변화를 담당한다.

## 감사 결과 (자동, 2026-08-03)
- 상태: 위반발견
- 근거: "종합 이해도 계산" 절이 `U = 0.1*ON + 0.2*AN + 0.3*VN + 0.4*RN` 가중 합산 스칼라 모델을 사용하고, RN≥50%·AN≥60% 등 연속 퍼센트 임계값으로 콘텐츠를 해금한다. 이는 ADR-2가 Context와 대안 검토에서 명시적으로 기각한 "가중 합산 스칼라" 모델("R=0이어도 성불 임계값 도달 가능, ADR-1 원칙 위반")과 정확히 일치하며, ADR-2 Compliance "이해도를 단일 수치로 표현하는 새 메카닉을 도입하지 않는다"를 위반한다.

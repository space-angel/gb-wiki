# 노션 구축 현황 대조 — 설계 문서 vs 실측 (2026-08-05)

목적: `gb_wiki/raw` 전체와 Notion 워크스페이스 정합성을 확인하기 전에, 자료가 지금 어디에 있는지부터 지도화한다. [[Notion_페이지_구조_설계]] (이하 "설계 문서")가 이미 목표 구조를 정의해뒀으므로, 이 문서는 그 목표 대비 **실제로 뭐가 만들어졌는지**를 `ntn` CLI로 직접 조회해 대조한 것이다.

범위: Obsidian은 `gb_wiki/raw` 5개 폴더 148파일 전체. Notion은 워크스페이스 전체(1,943페이지, 91DB)를 훑었고, 그중 게임 프로젝트와 무관한 것(다른 회사 백로그·채용공고·리뷰 파이프라인 등, ADR/이해도/사령 키워드로 안 걸리는 것)은 제외했다.

---

## 1. 결론 먼저

설계 문서의 build 순서(§6) 기준으로 각 단계가 실제로 어디까지 됐는지:

| 단계 | 설계 목표 | 실측 결과 |
|---|---|---|
| ADR DB | 14행 | ✅ 존재 — 단, **두 곳에 중복** (§3 참고) |
| 트래커 DB | 17행, 담당자 배정 | ⚠️ **새 위치는 0행(빈 DB)**, 옛 위치에 17행이 남아있음 — 이관 안 됨 |
| 확정 레퍼런스 DB | 92행, relation·rollup 포함 | ❌ **아직 생성 안 됨** — 워크스페이스 어디에도 없음 |
| 회의록 DB | 17행 | ✅ 존재 (17행, 옛 위치) — 새 위키 허브의 "회의록·프로세스" 칸은 빈 스텁 |
| 위키 허브(🏢 프로젝트 홈 등 4개 팀스페이스) | §1 트리 구조 | 🔶 **최근(8/2~8/3) 착수됨** — `ATK_DEF_위키` DB에 컴플라이언스/확정 레퍼런스/회의록·프로세스/샌드박스 4개 칸 생성. 그중 **컴플라이언스만 실제로 연결**됐고 나머지 3칸은 내용 없는 빈 페이지 |

한 줄 요약: **설계는 끝났고 ADR·트래커·회의록 원본 데이터는 이미 있지만, 그걸 설계 문서가 정한 새 구조로 옮기는 작업은 컴플라이언스 팀스페이스 착수 단계에서 멈춰 있다.** 확정 레퍼런스 DB(64+28=92파일이 갈 곳)는 아직 시작도 안 됐다.

## 3. Notion 쪽 실측 — 확인된 위치

### 3-1. 새 위키 허브 (`ATK_DEF_위키` DB, 8/2~8/3 생성, 소유자 spaceAngel)

허브 자체는 데이터베이스이고, 그 안의 행(페이지) 4개가 설계 문서 §1의 팀스페이스 4개에 대응하는 것으로 보인다:

|---|---|---|
| 컴플라이언스 | ✅ 채워짐 | 컴플라이언스 기준서(페이지) + ADR DB(14행) + 트래커 DB(**0행**) |
| 확정 레퍼런스 | ❌ 빈 스텁 | 하위 페이지 없음 |
| 회의록 · 프로세스 | ❌ 빈 스텁 | 하위 페이지 없음 |
| 샌드박스 | ❌ 빈 스텁 | 하위 페이지 없음 |

### 3-3. 확정 레퍼런스 DB — 미발견

`ntn api v1/search`로 "확정 레퍼런스"를 데이터소스로 검색해도 결과 없음. `01_확정레퍼런스_후보`(64) + `02_참고자료_후보`(28) = 92파일이 갈 곳으로 설계 문서가 지정한 DB가 아직 워크스페이스에 없다. **가장 큰 미착수 구간.**

## 5. 다음 단계 (실제 정합성 확인, 2단계)

이 문서는 "어디에 뭐가 있는지"까지만 다룬다. 내용 대조는 아직 안 했다. 다음에 할 것 제안:

1. **ADR 중복 해소** — 새(3b18826f-8563-8078...) vs 옛(3888826f-8563-8061...) 14행씩, 내용이 동일한지 diff. 동일하면 옛 것 정리, 다르면 어느 쪽이 최신인지 판단 필요.
2. **트래커 이관** — 옛 17행을 새 트래커 DB(현재 0행)로 옮기는 게 먼저 되어야, `gb_wiki/raw/00_컴플라이언스/트래커`(16파일)와의 내용 대조가 의미 있어진다.
3. **확정 레퍼런스 DB 92파일 대조는 DB 생성 이후로 미룰지, 아니면 DB 없이도 흩어진 개별 페이지 기준으로 먼저 대조할지** 결정 필요.
4. `3.4_세계_전환`, `3.5_공통_시스템` — Notion에 대응 DB가 안 보이는데, 아예 없는 건지 다른 이름으로 있는 건지 확인.
5. `이해도 루프 초안`(5행, 단서설계) ↔ `01_확정레퍼런스_후보/이해도시스템`(7파일) 실제 내용 매칭 확인.

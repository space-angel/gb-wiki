# 1단계(O) 임계값 N 정의

상태: 미결 · 영역: 이해도-입력 · 우선순위: P1

O(1단계) 달성에 필요한 유품 개수 N(핵심/보조 무관, 개수만 판정). 제약: 어떤 수집 순서로도 도달 가능해야 함(특정 유품 강제 금지).

### 왜 미결인가
구조(임계 기반 O 판정)는 확정인데 값이 없음. N은 레벨 디자인(유품 배치 밀도·동선)과 커플링돼 있어 맵 초안 없이 정하면 감으로 찍는 것이 됨.

### 확정된 전제
- [x] O(1단계) = 유품 개수 임계 도달 방식
- [x] 아이템 풀: 챕터당 핵심 3+보조 10~12 = 총 13~15개

### 실제 미결 지점
1. N 값 (총 13~15개 중 몇 개?)
2. 핵심/보조 구분 없이 순수 개수인지, 핵심 유품에 가중치를 둘지
3. 챕터마다 N이 동일한지, 챕터별 상이 허용인지

### 제약 (결정 시 준수)
- 어떤 수집 순서로도 도달 가능해야 함

### 결정 트리거
- 챕터 1 현실세계 맵 초안 + 유품 배치안(재화-아이템매핑) 나온 뒤 결정이 안전

# 핵심 유품 배치 정책 (현실 한정 vs 사령 체인)

상태: 미결 · 영역: 이해도-입력 · 우선순위: P1

> ⚠️ 참고: ADR-11(사령세계 공간 개방 규칙)이 이후 이 문제를 다뤘고, §2.1에서 메인B/C를 사령구역·현실 숨은장소에 배치하는 "체인 허용(B안)"을 채택한 것으로 보인다. 감사 시 본 트래커 항목을 ADR-11로 대체/종결 처리할지 확인 필요.

논리 필수 요건은 '열쇠 의존 그래프 비순환'뿐. A) 현실 한정: 구조 단순·검증 쉬움, 사령세계 탐색 보상 약함 / B) 체인 허용(사령 구역 내 다음 열쇠): 두 세계 왕복 루프·탐색 보상 강화, 검증 복잡. 사령세계 탐색 영역 보상 설계(ADR-7)와 함께 결정 권장.

### 왜 미결인가
양쪽 다 성립 가능한 순수 설계 선택지라 팀 결정이 필요함. 논리적으로 강제되는 건 "열쇠 의존 그래프에 순환이 없을 것" 하나뿐.

### 확정된 전제
- [x] 아이템 위계: 챕터당 핵심 3 / 보조 10~12, 핵심 유품 = 사령 구역 개방 (3:3 대응)
- [x] 2게이트: 조사 구역 순차 개방 + 보스룸 항시 접근
- [x] 사령세계 = 메트로배니아 ARPG, 보스방+탐색 영역 분리 (ADR-7)

### 실제 미결 지점
- **A) 현실 한정**: 핵심 유품 3개 전부 현실세계에서만 획득 — 구조 단순, 검증 쉬움. 단점: 사령세계 탐색 보상 약화 우려
- **B) 체인 허용**: 사령 구역 안에 다음 구역 열쇠 배치 — 두 세계 왕복 루프, 메트로배니아다움 강화. 단점: 검증 복잡

### 결정 트리거
- 사령세계 탐색 영역의 보상 설계 논의와 함께 결정
- 챕터 1 유품 배치(재화-아이템매핑) 작업 전 잠금 필요

# 재구성 오답 제출 시 리액션 방식

상태: 미결 · 영역: 재구성보드 · 우선순위: P2

오답 제출 시 게임 반응: 완전 무반응/분위기 연출/페널티. 단, all-or-nothing 원칙(부분 정답 힌트 금지)을 훼손하지 않는 선에서 결정.

> ⚠️ 참고: ADR-14(오답 처리 시스템)가 이후 "명시적 실패 피드백/페널티 없음"으로 확정했다. 이 트래커 항목이 ADR-14로 흡수·종결됐는지 감사 시 확인 필요.

### 왜 미결인가
원칙(all-or-nothing)은 확정인데, 오답 제출 순간의 플레이어 경험이 미정의. 완전 무반응은 원칙에 가장 충실하지만 UX상 버그로 오인될 위험.

### 확정된 전제
- [x] 재구성 보드 = 4슬롯, all-or-nothing 검증 — 부분 정답 힌트 절대 금지
- [x] 오답 시 맞은 슬롯도 확정되지 않음

### 실제 미결 지점
1. 오답 제출 시 반응: 완전 무반응/분위기 연출/페널티
2. 재시도 횟수 제한 여부
3. "제출됐으나 틀렸다"를 버그로 오해하지 않게 하는 최소 피드백 라인

### 결정 트리거 / 연관
- 정인-슬롯UI 작업이 이 결정에 영향받음 — UI 시안 전 잠금 권장
- 참고: Obra Dinn은 3건 동시 정답 시에만 확정, 오답엔 무반응

# 임계값 (충분/적정/없음 컷오프) 정의

상태: 미결 · 영역: 이해도-엔딩 · 우선순위: P1 · 블록 작업: 재화-후일담

04_엔딩 문서의 미결 항목. 4종 플래그 잠금됐으니 수치 가중치 불필요. 플래그 조합으로 정의 가능.
- 충분 = OAVR 전부 true → 성불
- 적정 = OAV true, R false → 제령
- 없음 = A false (보조 판매 등) → 소멸

### 왜 미결인가
플래그 조합 → 종결 매핑안이 **제안 상태로만 존재**하고 팀 합의·ADR이 없음.

### 확정된 전제 (재논의 불필요)
- [x] 이해도 = 4종 이산 플래그 파이프라인 (ADR-2 잠금) → 수치 가중치 방식 불필요 확정
- [x] 3종결 구조: 성불/제령/소멸
- [x] 컷오프는 플래그 조합으로 정의한다는 방향

### 실제 미결 지점
1. 매핑안의 팀 합의 및 ADR 등록
2. "없음 = A false(보조 판매 등)"의 정의가 모호 — A가 false인 **상태**인지, 유품 판매 같은 **행동**이 트리거인지 구분 필요
3. 중간 상태 처리: O만 true, O+A만 true 등 각 상태에서 어떤 종결이 허용되는지 전 구간 명시 필요

### 결정 트리거 / 연관
- "R 미달 상태 보스전 결과 정의" 항목과 같은 문제의 양면 — 통합 논의 권장
- 재화-후일담 작업이 이 결정에 블록

# 패턴 가시성 시각 표현 방식

상태: 미결 · 영역: 이해도-출력 · 우선순위: P2

"이해도가 높으면 패턴이 일찍 보인다" = 어떻게 시각적으로? 옵션: 히트박스 윤곽/이펙트 잔상/카메라 줌인 등. 정인 픽셀 작업 진입 시점에 결정.

### 왜 미결인가
의도적 연기(M2~M3). 기능 방향은 확정됐고, 시각 표현 수단만 남음 — 아트 스타일과 문정인 픽셀 작업 역량 확인 후 정하는 게 맞음.

### 확정된 전제
- 이해도 출력 = 보스 한정, 잡몹 완전 분리 (ADR-9)
- "이해도가 높으면 보스 패턴이 일찍 보인다"는 출력 방향 자체
- 전투 톤 = 회피 중심 가벼운 액션 (ADR-8) → 패턴 가시성은 회피 타이밍 인지와 직결

### 실제 미결 지점
- 시각 표현 수단 택1: 히트박스 윤곽/이펙트 잔상/카메라 줌인/기타
- 이해도 단계별 차등 표현 여부

### 결정 트리거
- 문정인 픽셀 작업 진입 시점 + 보스 1종 패턴 프로토타입 완성 시

# 재구성 보드 — 4슬롯 구조 (메인 유품·보조 유품·진술·추리)

## 1. Context
재구성 보드는 이해도 시스템의 핵심 UX다. ADR-002의 O→A→V→R 파이프라인이 작동하는 무대이고, ADR-003의 핵심/보조 아이템이 배치되는 공간이며, ADR-004의 가설 제출이 일어나는 인터페이스다.

결정 포인트: 슬롯 종류 수 / 진행 STEP 수 / 슬롯과 ADR-003 위계의 매핑

## 2. Decision

### 2.1. 슬롯 = 4종
| 슬롯 | 역할 | 입력 | 효과 |
|---|---|---|---|
| 메인 유품 | 사건 진행 핵심 | 현실세계 탐색 | 사령세계 영역 해금 |
| 보조 유품 | 삶/상태 이해 | 현실세계 탐색 | 메인 의미 확장/가설 변화 |
| 진술 | 인물 관점 | NPC 대화 | 단계별 심층 진술 해금 |
| 추리 | 가설 생성 | 위 3종 조합 | 해석 → 가설 |

ADR-003의 핵심 아이템은 메인 유품 슬롯에, 보조 아이템은 보조 유품 슬롯에 배치된다.

### 2.2. 진행 = 4 STEP
```
STEP 1. 사실 확인 — 메인+보조 유품 → 사령세계 접근 + 기본 사건 구조 확보
STEP 2. 관계 파악 — 진술+보조 유품 → NPC 심층 대화 + 신규 정보 해금
STEP 3. 사건 해석 — 유품+진술+추리 → 표면 사건에서 심층 원인 접근
STEP 4. 진실 도달 — 메인 유품+최종 진술+추리 → 보스의 진짜 형태 확인 + 해소 루트 개방
```

## 3. Status
Accepted. 2026-06-15 회의 D7에서 합의. 노션 재구성 보드 명세 문서에 verified 상태로 잠금됨.

## 4. Consequences

#### 4.1. 긍정적 결과
ADR-003 위계가 보드 UI에 자연스럽게 매핑된다. 진술 슬롯이 별도 존재해 ADR-006의 기반이 마련된다. 추리 슬롯에서 ADR-004의 3지선다 가설이 발동한다.

#### 4.2. 부정적 결과 / 제약
4슬롯 UI는 화면 영역을 많이 차지한다(PC 전용이라 실질 제약은 적음). 진행 STEP과 플래그 매핑이 1:1이 아니라 혼란 가능 — 케이스 작성 표준 절차에서 명확히 문서화 필요.

#### 4.3. 대안 검토 (기각)
| 대안 | 기각 사유 |
|---|---|
| 2슬롯 (메인/보조만) | 진술·추리 위치 모호 |
| 3슬롯 (메인/보조/진술) | 추리 단계가 보드 외부에서 일어남 |
| STEP 없는 자유 보드 | 진행 가이드 부재로 진입 장벽 |

## 5. Compliance
본 ADR을 따르는 모든 후속 설계는 다음을 준수한다.
- 재구성 보드는 항상 4슬롯 구조를 유지한다.
- 진행 STEP은 4단계로 표현된다.
- 핵심 아이템은 메인 유품 슬롯에, 보조 아이템은 보조 유품 슬롯에 배치한다.

# 가설 선택지 — 3지선다 고정 (정답 1 + 오답 2)

## 1. Context
A_reached 달성 조건은 "재구성 보드에서 보조 아이템 연결 + 가설 제출 정답"이다(ADR-002). 여기서 "가설 제출"의 선택지 수와 오답 설계 기준이 미정이었다.

옵션: 2지선다(단순, 부담 최소) / 3지선다(정답+오답2, 중간) / 4지선다 이상(추리 깊이↑, 부담↑)

## 2. Decision
가설 선택지를 **3지선다 고정 (정답 1 + 매력적 오답 2)**으로 한다. 오답 설계 기준은 두 오답이 서로 다른 방향으로 그럴듯해야 한다 (표층 감정 해석 vs 일반화된 사회적 해석).

## 3. Status
Accepted. 2026-06-15 회의 D5에서 합의. 노션 ADR-003 문서에 포함됨

## 4. Consequences

#### 4.1. 긍정적 결과
3지선다는 찍기 확률 33%로 추리 게임 의미가 있다. 오답 2개를 다른 방향으로 설계하는 룰이 게임 주제와 정합된다.

#### 4.2. 부정적 결과 / 제약
작가는 케이스마다 정답 1개 외 매력적 오답 2개를 설계해야 한다. 선택지 수 변경 시 시스템 전반 재설계 필요 (변경 비용이 큰 잠금).

#### 4.3. 대안 검토 (기각)
| 대안 | 기각 사유 |
|---|---|
| 2지선다 | 찍기 확률 50%, 추리 게임 의미 약함 |
| 4지선다 이상 | 작가 오답 설계 부담 폭증 |
| 케이스별 자유 선택지 수 | 난이도 불일치, UI 일관성 깨짐 |

## 5. Compliance
본 ADR을 따르는 모든 케이스 작성은 다음을 준수한다.
- A 단계 가설은 항상 정답 1 + 오답 2의 3지선다로 구성한다.
- 두 오답은 서로 다른 방향으로 그럴듯해야 한다.
- 가설 선택지 UI는 3지선다 가정 하에 설계된다.

# 오답 처리 시스템 — 재시도 규칙 및 상태 보존 원칙

> ⚠️ 미확정(Proposed). 지호 최종 확인 필요.

## 1. Context
ADR-12(2.4)에서 "오답 선택 시 명시적 표시나 페널티 없이 재시도 가능"이라고 방향만 잡았고, 재시도 횟수 처리·오답 시 리셋/보존 범위는 미확정(OQ-2)이었다. "무제한 재시도+이후 어떤 제약도 없음" 방향을 확정했고, 이걸 판정 규칙 문서(ADR-12) 안에 묻어두면 참조가 번거롭고 다른 판정형 시스템에도 재사용해야 할 독립 규칙이라 별도 문서로 분리한다.

## 2. Decision

### 2.1. 재시도 횟수 — 무제한, 카운트 자체를 두지 않음
재시도는 무제한. 시도 횟수는 저장 스키마에 기록하지 않는다. **근거(Golden Idol)**: 보드를 몇 번 열어도 이전 시도 기록이 남지 않고, 힌트도 실패 이력과 무관하게 독립 제공.

### 2.2. 오답 시 리셋 범위 — 배치만 리셋, 진행은 불변
오답 선택 시 초기화되는 것은 **재구성 보드 위 조각 배치뿐**. 다음은 영구 보존: 이미 참이 된 1~3단계 플래그, 이미 확인된 진술 슬롯·회상 내용, 이미 개방된 사령세계 구역.
**근거(Outer Wilds)**: 루프 리셋되어도 지식·단서·열린 문은 영구히 남음. "리셋"과 "손실"을 분리.

### 2.3. 힌트 시스템(도입 시) — 실패 이력 비참조
힌트 도입 시 실패 횟수·재시도 이력을 참조해 동적 난이도 조절하지 않는다.

## 3. Status
Proposed. 2026-07-20 논의에서 도출. ADR-12에서 분리. 지호 최종 확인 필요.

## 4. Consequences

#### 4.1. 긍정적 결과
오답에 대한 심리적 부담 제거, "찍어보고 확인" 방식도 자유롭게 허용. 저장 스키마 단순화(재시도 카운트·실패 이력·동적 힌트 상태 불필요). 3단계까지 진행이 오답과 완전 분리.

#### 4.2. 부정적 결과 / 제약
페널티 부재로 4단계 자체 긴장감·성취감 약화 가능 — 가설 설계(오답 그럴듯함)로 보완 필요. 무제한 재시도 UI가 매끄러워야 지루하지 않음.

#### 4.3. 대안 검토 (기각)
| 대안 | 기각 사유 |
|---|---|
| 재시도 횟수 제한(예: 3회) 후 페널티 | "무제한+무제약" 방향과 충돌 |
| 오답 시 진술·구역개방 초기화 | Outer Wilds식 원칙 위반 |
| 실패 횟수 기반 동적 힌트 | 실패 이력을 상태로 남기게 되어 2.1 위반 |
| 오답 시 "틀렸습니다" 명시 표시 | ADR-12에서 이미 기각된 침묵형 원칙과 재충돌 |

## 5. Compliance
본 ADR을 따르는 모든 재구성 보드·판정형 시스템은 다음을 준수한다.
- 재시도 횟수를 저장 스키마의 어떤 키로도 기록하지 않는다.
- 오답 시 리셋 대상은 해당 시도의 보드 배치로 한정한다. 플래그·진술·구역 개방 상태는 절대 초기화하지 않는다.
- 힌트 기능은 실패 이력을 입력값으로 참조하지 않는다.
- 오답에 대해 명시적 실패 텍스트·아이콘·사운드 등 판정성 피드백을 주지 않는다.

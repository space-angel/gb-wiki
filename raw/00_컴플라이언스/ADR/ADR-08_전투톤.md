# 전투 톤 — 가벼움 + 회피만 (패링·가드 제외)

## 1. Context
사령세계 구조가 메트로배니아로 잠긴 후(ADR-007), 그 위에서 작동할 전투 톤 결정 필요.
- 무거운 전투(소울라이크): 세키로·다크소울류, 구현 난이도 높음, 4인 인디에 부담
- 가벼운 전투(액션RPG): 하데스·하이퍼라이트 드리프터류, 빠른 템포, 메트로배니아 쾌감과 정합

## 2. Decision
1. **전투 톤 = 가벼움 + 회피 위주** — 하데스류 빠른 템포, 한 대가 치명적이지 않음
2. **방어 시스템 = 회피만** — 패링·가드 제외. 회피는 무적판정+캔슬가능
3. **잡몹 처리 방식** — 단순노동형("회피로 무적판정 만들고 계속 때리기"), 깊이있는 전투는 보스 한정

## 3. Status
Accepted. 2026-06-01 회의 D15·D16에서 4명 합의. 노션 전투 시스템 문서에 반영됨.

## 4. Consequences

#### 4.1. 긍정적 결과
구현 부담 감소(4인 인디 캐파에 맞춤). 메트로배니아 코어 쾌감과 정합. ADR-009(보스 패턴 가시성)와 정합 — 가벼운 액션톤에서 "읽는" 플레이가 더 명확.

#### 4.2. 부정적 결과 / 제약
소울라이크 팬층 기대 미충족(의도된 방향, 게임 주정서는 "이해"이지 "도전"이 아님). 방어 옵션이 회피 하나뿐이라 보스 패턴 다양성 제한 — 보스 디자인은 회피 타이밍 변주에 집중.

#### 4.3. 대안 검토 (기각)
| 대안 | 기각 사유 |
|---|---|
| 무거운 전투(소울라이크) | 구현난이도↑, 템포 깨짐 |
| 회피+패링 | 패링 프레임 처리 복잡 |
| 회피+가드 | 가드 방향처리+스태미너 추가 필요 |
| 방어 없음 | 단순 DPS 경쟁, 패턴학습 의미 약함 |

## 5. Compliance
본 ADR을 따르는 모든 전투 설계는 다음을 준수한다.
- 패링·가드 메카닉을 추가하지 않는다.
- 회피는 무적 판정을 가지며 다른 액션을 캔슬할 수 있다.
- 보스 패턴은 회피 타이밍 변주로 설계한다.

# 사령세계 구조 — 메트로배니아 ARPG (보스방 + 탐색 영역 분리)

## 1. Context
5/25 회의 전까지 4명이 사령세계 구조에 대해 서로 다른 멘탈 모델을 가지고 있었다.
- 이재화: 진입 시점 보스 곧장 등장 (쯔꾸르 스타일)
- 안지호: 계층형 구조, 잡몹→보스 단계적 진행
- 송호윤: 메트로배니아, 수평적 맵, 어디든 재진입
- 문정인: 보스방은 별개 공간, 이스터에그 형식 가능성 제안

쟁점은 "메트로배니아의 비선형 탐색"과 "이재화의 피지컬 플레이 존중(보스 직접 도전 가능)"의 양립.

## 2. Decision
사령세계 구조를 **메트로배니아 ARPG**로 잠금한다. 단 보스방과 탐색 영역을 명확히 분리한다.

### 2.1. 장르 = 메트로배니아 ARPG
수평적 맵 구조 + 해금 기반 진행. 다크소울류 선형 진행이 아니다.

### 2.2. 공간 구조
| 공간 | 구조 | 진입 방식 |
|---|---|---|
| 보스방 | 독립 공간 | 메인 유품 발견 시 해금, 어디서든 재도전 가능 |
| 탐색 영역 | 메트로배니아 | 보조 유품 발견 시 단계적 해금 |

### 2.3. 첫 진입 = 보스전 직행
처음 사령세계 진입 시 보스전을 마주한다(세키로/다크소울 첫 보스류). 깨도/못깨도 OK. 실패 시 현실세계로 강제 귀환한다 (ADR-010).

## 3. Status
Accepted. 2026-05-25 회의 D3·D4에서 4명 만장일치. 노션 핵심 컨셉 문서에 반영됨.

## 4. Consequences

#### 4.1. 긍정적 결과
4명의 멘탈 모델이 정렬됨. ADR-002 4종 플래그 + 메트로배니아 구조 = "보조 유품을 모을수록 탐색 영역이 넓어지고 이해도가 상승" 흐름 형성. 피지컬 플레이(소멸-피지컬 루트) 보존.

#### 4.2. 부정적 결과 / 제약
맵 디자인 난이도 높음(메트로배니아는 극악 난이도). 이재화 초기안(쯔꾸르 단일맵)과 달라 케이스 작성 표준 재조정 필요. 사령세계-현실세계는 "느슨한 대응"(1:1 좌표 매핑 아님) — ADR-010에서 정의.

#### 4.3. 대안 검토 (기각)
| 대안 | 기각 사유 |
|---|---|
| 쯔꾸르 스타일 단일 맵 | 재방문 쾌감 상실, 이해도 정합 약함 |
| 계층형 진행 | 비선형 탐색 불가, 피지컬 플레이 차단 |
| 보스방을 일반 맵 안에 배치 | 재도전 메카닉 구현 복잡 |

## 5. Compliance
본 ADR을 따르는 모든 후속 설계는 다음을 준수한다.
- 사령세계는 메트로배니아 구조를 유지한다. 선형 진행 챕터를 추가하지 않는다.
- 보스방은 항상 탐색 영역과 분리된 독립 공간으로 설계한다.
- 보스 도전은 첫 진입부터 가능하다. 이해도 플래그에 종속시키지 않는다.

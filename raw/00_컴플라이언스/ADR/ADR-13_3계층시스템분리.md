# 3계층 시스템 분리 — 인벤토리 / 플래그 / 컷씬

> ⚠️ 미확정(Proposed). 지호 최종 확인 필요.

## 1. Context
메인유품 자유 획득(재화 물품 후보 문서), 사령세계 구역 개방(추리 무관, ADR-11), 이해도 O/A/V/R 순차 진행(ADR-2)이 개별적으로는 다 옳은데 동시에 만족시키려면 충돌했다. 아이템을 초반에 자유롭게 다 주울 수 있게 하면 순서의존이 깨지고, 순서를 지키려 획득을 제한하면 자유 획득 원칙과 부딪힘.

근본 원인: "아이템을 가지고 있다"와 "이야기가 진행됐다"를 하나의 상태로 취급한 것. 아이템 소지 여부로 플래그를 직접 판정하면 순서를 건너뛸 수 있음.

## 2. Decision
이해도 판정을 아이템 인벤토리와 물리적으로 분리된 **3개의 독립 계층**으로 구성한다.

### 2.1. 계층 정의
| 계층 | 담당 | 하지 않는 일 |
|---|---|---|
| 인벤토리 | 무엇을, 몇 개 보유 중인지 기록 | 무엇을 주웠는지는 판단하지 않음(개수만 셈) |
| 플래그 | O/A/V/R 네 조건의 참/거짓만 판정 | 대사·컷씬을 직접 재생하지 않음 |
| 컷씬 | 플래그가 방금 참이 됐다는 신호를 받아 연출만 실행 | 조건을 스스로 판단하지 않음, 인벤토리를 직접 조회하지 않음 |

### 2.2. 참조 방향 제약
인벤토리는 플래그 상태를 직접 변경하지 않는다. "카운트가 임계값을 넘었다"는 이벤트만 발행한다. 컷씬은 인벤토리를 직접 조회하지 않고, 오직 플래그의 참 신호만 구독한다. **O 이후(A/V/R)는 인벤토리 이벤트를 아예 구독하지 않는다.**

### 2.3. 아이템 이름별 역할 확정
| 아이템 | 계층상 역할 | 비고 |
|---|---|---|
| 졸업사진 액자(메인A) | 열쇠. 1구역+보스방 개방 | 인벤토리엔 보유 여부만 |
| 취업 준비 파일철(메인B) | 열쇠. 2구역 개방 | 획득 위치 사령1구역 재배치(ADR-11 정합) |
| 고양이 이동장(메인C) | 열쇠. 3구역 개방 | 획득 위치 현실 숨은장소(암호 해금) 재배치 |
| 인턴 출입증 | 보조. O카운트+1, 판매가능 | 메인B와 페어링 |
| 낡은 러닝화 | 보조. O카운트+1, 판매가능 | 메인C와 페어링 |
| (미정 4개) | 보조. O카운트+1, 판매가능 | 메인A 페어링 2개+메인B/C 각 1개 신규 설계 필요 |

보조유품·메인유품의 "페어링"은 배치 레이어일 뿐, 시스템적 해금 의존 관계를 만들지 않는다.

### 2.4. 단계별 트리거 요약 (ADR-12와 연동)
| 단계 | 인벤토리가 보는 것 | 플래그 판정 | 컷씬이 여는 것 |
|---|---|---|---|
| O | 보조유품 보유 개수(판매분 제외) | N개 이상→TRUE | 핵심유품 제시 상호작용 활성화 |
| A | (참조 안 함) | 유품 제시 완료→TRUE | 사령세계 회상 공간 진입 가능 |
| V | (참조 안 함) | 회상 확인 완료→TRUE | 재구성보드 전체 단서 공개 |
| R | (참조 안 함) | 4슬롯 충족+가설 정답 선택→TRUE | 엔딩 분기 컷씬(ADR-9) |

## 3. Status
Proposed. 2026-07-20 논의에서 도출. 지호 최종 확인 필요.

## 4. Consequences

#### 4.1. 긍정적 결과
자유 획득(ADR-11)과 순서의존(ADR-2)이 다른 계층에서 처리되어 데드락 해소. 보조유품 총량/페어링 방식이 바뀌어도 컷씬·대사 시스템 영향 없음. O 이후 인벤토리 미참조로 순서 위반 시나리오 구조적 차단.

#### 4.2. 부정적 결과 / 제약
계층 간 참조 방향을 개발 초기부터 엄격히 지켜야 함(우회 구현 시 본 ADR 무력화). 보조유품 페어링(서사)과 시스템 의존(게이트)의 구분을 반복 커뮤니케이션해야 함.

#### 4.3. 대안 검토 (기각)
| 대안 | 기각 사유 |
|---|---|
| 아이템 소지 여부로 플래그 직접 판정 | 순서의존 위반 가능 |
| 인벤토리·플래그·컷씬 단일 모듈 통합 | 유지보수 비용 급증 |
| 컷씬이 인벤토리 직접 조회 | 계층 경계 무너짐 |

## 5. Compliance
본 ADR을 따르는 모든 이해도 관련 구현은 다음을 준수한다.
- 인벤토리 모듈은 카운트 기록과 임계값 이벤트 발행만 한다.
- 플래그 모듈은 조건 판정만 하며, 대사·컷씬을 직접 재생하지 않는다.
- 컷씬 모듈은 플래그의 참 신호만 구독하며, 인벤토리를 직접 참조하지 않는다.
- O 이후(A/V/R) 판정 로직은 인벤토리 이벤트를 구독하지 않는다.
- 보조유품의 서사적 페어링은 배치 위치로만 구현하며, 해금 조건에 포함하지 않는다.

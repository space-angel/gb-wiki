# 사령세계 공간 개방 규칙 — 메인 유품 게이트 + 획득/추리 분리

> ⚠️ 미확정(Proposed). 지호(게임 디자인) 최종 확인 필요.

## 1. Context
ADR-7에서 사령세계를 메트로배니아 구조로 잠갔지만, 세 가지가 미결로 남아 후속 설계를 막고 있었다.

첫째, 메인 유품과 사령 구역의 대응 관계가 정의되지 않음(ADR-3 OQ-1에서 미룬 문제).
둘째, 구역 개방과 추리 진행의 관계 — "추리를 맞혀야 구역이 열린다"면 ADR-5의 소멸 엔딩과 충돌(이해 없이 사령세계 진입 자체가 안 됨).
셋째, 소멸-판매 루트 데드락 — 판매용 유품이 추리로 열리는 구역 안에 있으면 "이해하지 않으려는 플레이어"가 판매 재료를 못 얻는 순환 발생.

## 2. Decision
사령세계 공간 개방을 **두 개의 독립된 축**으로 분리한다. 공간을 여는 축(메인 유품)과 이해를 쌓는 축(추리)은 서로 종속되지 않는다.

### 2.1. 축 1 — 공간 개방 (메인 유품 게이트)
메인 유품 1개가 사령 구역 1개를 연다(1:1). 구역 개방은 추리 성공과 무관.
| 열쇠 | 획득 위치 | 여는 것 |
|---|---|---|
| 메인 A | 현실세계 | 사령 1구역 + 보스방 |
| 메인 B | 사령 1구역 | 1구역 내 오브젝트 상호작용 → 2구역 |
| 메인 C | 현실세계 숨겨진 장소 | 3구역 (도달 자체가 열쇠) |

### 2.2. 왕복 구조와 방향 규칙
공간 개방은 **양방향 왕복**(사령→현실 힌트 흐름 존재). 단 **이해(추리)의 흐름은 현실→사령 단방향**을 유지한다. 사령 단서가 현실 추리단계(2·3단계 가설)를 여는 트리거는 금지.

### 2.3. 축 2 — 이해 축적 (추리)
| 선택 | 결과 |
|---|---|
| 추리를 이어감 | 2·3단계 가설+4단계 반전 → 성불/제령 |
| 추리를 하지 않음 | 보조 유품 판매로 생존템 → 소멸 |

### 2.4. 보조 유품 배치
보조 유품은 현실세계·사령세계 양쪽에서 획득. 판매 가능, 어느 루트든 획득 가능.

### 2.5. 소멸의 최소 조건
메인 A만 획득하면 보스방 열림. 추리 없이 돌진하면 소멸 엔딩 도달(ADR-2 "보스 도전은 O_reached부터 항상 가능" 유지).

### 2.6. 배치 제약 (순환 방지)
N구역을 여는 메인 유품은 N구역보다 앞(현실세계~N-1구역)에만 배치. 뒤에 두면 순환 발생하므로 금지.

## 4. Consequences

#### 4.1. 긍정적 결과
공간 개방과 이해 분리로 데드락 원천 제거. 소멸 엔딩이 구조적으로 성립(메인A만으로 보스방 열림). 메트로배니아 왕복 쾌감 유지. 레벨 디자인 착수 가능.

#### 4.2. 부정적 결과 / 제약
메인 C의 "현실 숨겨진 장소+암호 해금" 구현 추가 필요. 메인 유품 배치가 §2.6 제약에 묶임. 보조 유품 양쪽 세계 배치로 설계량 증가.

#### 4.3. 대안 검토 (기각)
| 대안 | 기각 사유 |
|---|---|
| 추리로 구역 개방 | ADR-5 소멸 엔딩과 충돌 |
| 판매 유품 현실세계만 배치 | "사령에서도 판매 유품 획득" 요구 불일치 |
| 곁길 구역(전투게이트)에 판매유품 | 레벨 복잡도 증가 |
| 메인 유품 여러개=한 구역 | 게이트 조건 복잡화 |

## 5. Compliance
본 ADR을 따르는 모든 사령세계 레벨 설계는 다음을 준수한다.
- 사령 구역은 메인 유품으로 연다. 추리 정답을 구역 개방 조건으로 삼지 않는다.
- 보스방은 메인 A 획득 시점부터 상시 개방한다.
- 판매용 보조 유품은 이해 여부와 무관하게 도달 가능한 위치에 둔다.
- N구역을 여는 메인 유품은 N구역보다 앞에 배치한다.
- 사령 단서가 현실의 추리 단계를 여는 트리거를 만들지 않는다.

# 이해도 판정 규칙 — 4단계 플래그 트리거 및 재구성 보드 조합 조건

> ⚠️ 미확정(Proposed). 48시간 룰 적용 중. 지호 최종 확인 필요.

## 1. Context
ADR-2에서 이해도를 4개 이산 플래그의 순차 파이프라인으로 잠갔지만, 각 단계의 판정 트리거가 여러 문서에 흩어져 충돌했다.
1. 4단계(R) 판정 구조가 두 가지(단순 조합형 vs 슬롯형)로 별개처럼 보임
2. 오답 피드백 방식 상충 (Obra Dinn식 침묵형 vs 3지선다 오답 실재)
3. 2단계(A) 트리거가 문서마다 다름 ("유품 제시" vs "유품 조사→NPC 해금")
4. 최종 증인(어머니) 증언의 등록 시점 불명확 (3단계 vs 4단계)

## 2. Decision
이해도 판정을 **아이템 인벤토리와 완전히 분리된 플래그 파이프라인**으로 확정, 4단계 모두 재구성 보드 4슬롯 위에서 통합한다.

### 2.1. 3계층 아키텍처 (ADR-13 재확인)
인벤토리는 보유 개수만 기록, 플래그는 조건 판정만, 컷씬은 참 신호에만 연출. **1단계 이후(2~4단계)는 인벤토리를 전혀 참조하지 않는다.**

### 2.2. 단계별 판정 조건
| 단계 | 트리거 | 판정 조건 | 관련 슬롯 |
|---|---|---|---|
| 1단계 | 보조 유품 수집 | 보조 유품 N개 이상 확보(판매분 제외) | 보조 유품 슬롯 |
| 2단계 | 핵심 유품 제시(조사+제시 통합) | 대상 NPC에게 제시 완료 | 진술 슬롯 |
| 3단계 | 회상 공간 진입·기억 확인 | 대응 회상 공간에서 기억 확인 완료 | 추리 슬롯(선택지 개방) |
| 4단계 | 보드 4슬롯 조합+가설 선택 | 4슬롯 전부 충족 상태에서 3지선다 중 정답 선택 | 전체 슬롯 확인 |

### 2.3. 4단계 최종 판정 통합
"단서 3개 조합"은 별도 로직이 아니라 재구성 보드의 핵심 유품 슬롯을 채우는 절차. 4단계 최종 판정은 4슬롯 충족 상태에서 3지선다 정답 선택 단일 행위.

### 2.4. 오답 처리
3지선다 유지, 오답 시 명시적 표시/즉각 페널티 없음. 보드 닫히고 재시도 가능. 1~3단계 플래그는 오답으로 초기화되지 않음.

### 2.5. 최종 증인(어머니) 증언의 위치
어머니 증언은 진술 슬롯 게이트가 아니라 **4단계 정답 선택 이후 재생되는 리워드 컷씬**으로 확정.

### 2.6. 보조 유품 배치 및 페어링
보조 유품은 현실세계·사령 1구역에 집중 배치(1단계 초반 완료). 핵심 유품과 서사적으로 페어링하되 시스템적 해금 의존은 만들지 않음.

### 2.7. 보스방 개방 조건 (ADR-11 정합)
보스방은 1단계 완료가 아니라 **메인 유품 A 획득 즉시** 상시 도전 가능(ADR-11 §2.5).

## 3. Status
Proposed. 2026-07-20 논의에서 도출. 48시간 룰 적용 중.

## 4. Consequences

#### 4.1. 긍정적 결과
4단계 판정 로직 통합, 이중 판정 구조 해소. 침묵형+3지선다 양립 확정. 2단계 트리거 통합으로 구현 상호작용 단순화. 어머니 증언 리워드 컷씬화로 "최종 증인" 표현 성립.

#### 4.2. 부정적 결과 / 제약
2단계 조사+제시 통합 UI 신규 설계 필요. 어머니 증언 리워드 컷씬 연출 분량 증가. 보조 유품 페어링을 배치일 뿐 시스템 의존 아니라고 재화와 커뮤니케이션 필요.

#### 4.3. 대안 검토 (기각)
| 대안 | 기각 사유 |
|---|---|
| 4단계를 "단서 3개 조합"만으로 판정 | 이중 판정 구조 발생 |
| 오답 즉시 "오답" 표시 | Obra Dinn식 침묵 설계와 충돌 |
| 조사·제시 별개 단계 | 파이프라인이 5~6단계로 늘어나 ADR-2 위반 |
| 어머니 증언 3단계 배치 | "최종 증인=4단계" premise 충돌 |
| 어머니 증언 4단계 게이트 조건 | 판정표 전체 수정 필요 |
| 보스방 O_reached 이후 개방 | ADR-11 §2.5와 충돌 |

## 5. Compliance
본 ADR을 따르는 모든 이해도 판정 로직·UI 설계는 다음을 준수한다.
- 2단계 이후 판정은 인벤토리를 참조하지 않는다.
- 4단계 판정은 4슬롯이 모두 충족된 상태에서만 3지선다를 제공한다.
- 오답 선택 시 명시적 실패 피드백이나 페널티를 주지 않는다.
- 어머니 증언은 진술 슬롯에 등록하지 않으며, 4단계 정답 선택 이후에만 재생한다.
- 보스방은 메인 A 획득 시점부터 상시 개방하며, 1단계 완료 여부를 조건에 넣지 않는다.

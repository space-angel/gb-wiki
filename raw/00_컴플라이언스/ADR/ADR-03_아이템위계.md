# 아이템 위계 — 핵심/보조 2등급 + 챕터당 핵심 3 / 보조 10~12

## 1. Context
이해도 시스템이 작동하려면 아이템에 위계가 있어야 한다. 어떤 아이템은 R 트리거에 직결되고, 어떤 아이템은 O→A 진행 재료로만 쓰이며, 어떤 아이템은 판매 가능해야 소멸-아이템 루트가 성립한다.

세 가지 결정이 필요했다.
- 아이템 등급을 몇 단계로 둘 것인가 — 스토리 자료 초안은 S/A/B 3등급, 시스템 측면에서는 2등급으로 충분할 수 있음
- 챕터당 각 등급별 수량 표준 — 지호의 초안은 "핵심 2~3개"였고 흔들리면 케이스 작성 표준이 안 잡힘
- O_reached 판정에 어떤 아이템들이 포함되는가 — 케이스마다 작가가 별도 설계하면 표준이 흔들림

## 2. Decision

### 2.1. 위계 = 2등급 (핵심 / 보조)
**핵심 아이템** — 고인의 본질에 닿는 물건. 사건의 진실과 직결.
| 속성 | 값 |
|---|---|
| 판매 가능 여부 | 불가 |
| 보드 연결 필수 여부 | 필수 |
| 발견 시 효과 | 사령세계 해당 영역 잠금 해제 |
| 조합 시 효과 | 표층→심층 상태 전환 트리거 (R_reached) |
| 챕터당 수량 | **3개** |

**보조 아이템** — 주변 정황을 구성하는 물건.
| 속성 | 값 |
|---|---|
| 판매 가능 여부 | 가능 (관리인 NPC에게) |
| 보드 연결 | 선택 |
| 발견 시 효과 | 없음 |
| 연결 시 효과 | O→A→V 플래그 진행 재료 |
| 판매 시 효과 | 생존성 아이템 획득 (소멸-아이템 루트) |
| 챕터당 수량 | ~~10~12개~~ → **6개** (ADR-15가 개정, 2026-08-17) |

### 2.2. 시각 구분 = 슬롯 방식
핵심/보조의 시각 구분은 **재구성 보드의 슬롯 위치**로 표현한다. 아이템 자체에 등급 표시는 두지 않는다.

### 2.3. O_reached 판정 = 핵심 전부 + 보조 N개
1. 챕터 내 **핵심 아이템 3개 전부** 발견 (보스방 전용 핵심 포함)
2. 챕터 내 **보조 아이템 N개 이상** 발견 (N은 케이스별 작가 설계값, 김태현 케이스 기준 6~8 권장)

## 3. Status
Accepted. 2026-06-15 회의 D1·D3·D4에서 합의. 노션 ADR-003 문서로 잠금됨

> ⚠️ **부분 개정됨**: 보조 아이템 수량(10~12개)은 2026-08-17 **ADR-15**가 6개로 개정했다. 나머지
> 조항(핵심 3개, 2등급 체계, 판매 가능 여부, 슬롯 시각화)은 그대로 Accepted 상태다.

## 4. Consequences

#### 4.1. 긍정적 결과
케이스 작성 표준의 뼈대가 잡힌다. 판매 가능 여부라는 단일 기준으로 위계가 정해진다. 보조 아이템 판매가 소멸-아이템 루트의 메카닉이 된다. 슬롯 방식이 아트 작업량을 줄인다.

#### 4.2. 부정적 결과 / 제약
스토리 자료의 3등급 위계를 핵심/보조 2등급으로 재배치해야 한다. 김태현 케이스의 경우 S급 2개+A급 일부를 핵심 3개로, 나머지를 보조 10~12개로 재매핑해야 한다.

#### 4.3. 대안 검토 (기각)
| 대안 | 기각 사유 |
|---|---|
| 3등급 (S/A/B) 유지 | 시스템상 핵심/보조만 구분되면 충분 |
| 챕터당 핵심 2개 | 표층/심층 반전 구조 지탱에 부족 (재화 의견) |
| 보스방 전용 핵심을 O에서 제외 | 케이스마다 별도 설계 필요, 표준 흔들림 |
| 아이템 자체 등급 표시 | 아트 작업량 폭증 |

## 6. Open Questions
> **OQ-1. 핵심 아이템 3개와 "메인 유품" 개념의 관계**
> ADR-007에서 "메인 유품 → 보스방 해금 / 보조 유품 → 영역 해금"이 언급된다. 본 ADR의 "핵심 아이템 3개"와 ADR-007의 "메인 유품"의 관계가 명시적으로 정리되지 않았다.
>
> | 가능성 | 내용 |
> |---|---|
> | A | 핵심 3개 모두가 "메인 유품" |
> | B | 핵심 3개 중 1개가 "메인 유품"(보스방 해금), 나머지 2개는 일반 핵심 |
> | C | "메인 유품"·"핵심"·"보조" 3등급 분류 |
>
> 본 ADR은 어느 가능성도 채택하지 않는다. 후속 결정(ADR-11)에서 잠금한다.

## 5. Compliance
본 ADR을 따르는 모든 케이스 작성은 다음을 준수한다.
- 핵심 아이템은 챕터당 3개를 두고, 모두 판매 불가로 설정한다.
- 보조 아이템은 챕터당 ~~10~12개~~ **6개(ADR-15)**를 두고, 모두 관리인 판매 가능으로 설정한다.
- O_reached는 핵심 3개 전부 발견 + 보조 N개 이상 발견의 AND 조건으로 평가한다.

> ⚠️ 알려진 위반: 재화의 서사 문서가 핵심 유품 5개(전역 액자·취업 파일철·사원증·러닝화·고양이 이동장)로 서술. 3개로 재분류 필요 (세계관 어긋남 문서 §A 참조)

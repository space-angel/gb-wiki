## 지금 막혀 있는 것

🔴 **검토필요 4건**이 회의 안건이에요. 그중 최우선:

> **사령세계 획득 구조 — 순차 체인 vs 동시 노출**
> 메인 유품을 챕터 초반에 전부 노출할지, 구역을 열어가며 하나씩 얻게 할지가 안 정해졌어요. 거의 같은 시기에 스토리와 시스템이 서로 확인 없이 각자 결정했어요.
> **레벨디자인 전제가 통째로 갈리는 지점**이라 맵 설계가 못 나가고, 맵이 없으니 이해도 N값도 못 정하는 연쇄가 걸려 있어요.

그 외 **❌ 확정 결정을 어기는 문서 14건**이 있는데, 이건 **회의 없이 문서만 고치면** 돼요. 둘의 차이는 [문서 규칙](2_가이드/문서_규칙.md)에 있어요.

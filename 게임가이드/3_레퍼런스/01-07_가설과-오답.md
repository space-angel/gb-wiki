# 가설 선택지와 오답 처리

## 1. 가설 선택지 — 3지선다 고정 `확정`

A_reached 달성 조건인 "가설 제출"의 선택지는 **정답 1 + 매력적 오답 2 = 3지선다 고정**이다.

**오답 설계 기준**: 두 오답은 **서로 다른 방향으로** 그럴듯해야 한다.
- 방향 ① 표층 감정 해석
- 방향 ② 일반화된 사회적 해석

### 절대 규칙
1. A 단계 가설은 **항상 정답 1 + 오답 2**
2. 두 오답은 서로 다른 방향으로 그럴듯해야 한다
3. 가설 선택지 UI는 3지선다 가정 하에 설계된다

### 왜 3인가
찍기 확률 33%로 추리 게임의 의미가 유지된다. 2지선다(50%)는 의미가 약하고, 4지선다 이상은 작가의 오답 설계 부담이 폭증한다.

### 비용
- 작가는 케이스마다 정답 외 **매력적인 오답 2개**를 설계해야 한다
- **변경 비용이 큰 잠금이다.** 선택지 수를 바꾸면 시스템 전반을 재설계해야 한다

### 기각된 대안
| 대안 | 기각 사유 |
|---|---|
| 2지선다 | 찍기 확률 50%, 추리 의미 약함 |
| 4지선다 이상 | 작가 오답 설계 부담 폭증 |
| 케이스별 자유 선택지 수 | 난이도 불일치, UI 일관성 깨짐 |

## 2. 오답 처리 `잠정` (ADR-14 Proposed)

방향은 한 문장이다 — **"무제한 재시도 + 이후 어떤 제약도 없음."**

| 항목 | 규칙 | 근거 레퍼런스 |
|---|---|---|
| **재시도 횟수** | **무제한.** 시도 횟수를 저장 스키마에 기록하지 않음 | The Case of the Golden Idol |
| **리셋 범위** | **보드 위 조각 배치만.** 플래그·진술·구역 개방은 영구 보존 | Outer Wilds |
| **힌트 (도입 시)** | 실패 횟수·재시도 이력을 참조한 동적 난이도 조절 없음 | Golden Idol |
| **피드백** | 명시적 실패 텍스트·아이콘·사운드 등 **판정성 피드백 금지** | Obra Dinn 침묵형 |

### 영구 보존되는 것
- 이미 참이 된 1~3단계 플래그
- 이미 확인된 진술 슬롯·회상 내용
- 이미 개방된 사령세계 구역

> **Outer Wilds 원리**: 루프가 리셋되어도 지식·단서·열린 문은 영구히 남는다. **"리셋"과 "손실"을 분리**한다.

### 준수 사항
1. 재시도 횟수를 **저장 스키마의 어떤 키로도 기록하지 않는다**
2. 오답 시 리셋 대상은 **해당 시도의 보드 배치로 한정**한다
3. 힌트 기능은 실패 이력을 입력값으로 참조하지 않는다
4. 오답에 대해 **판정성 피드백을 주지 않는다**

### 효과와 리스크
**효과**: 오답에 대한 심리적 부담 제거("찍어보고 확인"도 자유롭게 허용) · 저장 스키마 단순화 · 3단계까지의 진행이 오답과 완전 분리

**리스크**: 페널티 부재로 4단계의 긴장감·성취감이 약화될 수 있다 → **가설 설계(오답의 그럴듯함)로 보완**해야 한다

### 기각된 대안
| 대안 | 기각 사유 |
|---|---|
| 재시도 3회 후 페널티 | "무제한+무제약" 방향과 충돌 |
| 오답 시 진술·구역개방 초기화 | Outer Wilds식 원칙 위반 |
| 실패 횟수 기반 동적 힌트 | 실패 이력을 상태로 남기게 됨 |
| "틀렸습니다" 명시 표시 | 침묵형 원칙과 재충돌 |

### 미정
**"제출됐으나 틀렸다"를 플레이어가 버그로 오해하지 않게 하는 최소 피드백 라인.**
완전 무반응이 원칙엔 가장 충실하지만 UX상 버그로 오인될 위험이 있다. (참고: Obra Dinn은 3건 동시 정답 시에만 확정, 오답엔 무반응)

그 외 미정: 힌트 시스템 도입 여부와 형태 / 재진입 UI(보드 다시 여는 연출) 스펙

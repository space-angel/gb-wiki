# 사령세계 공간 개방 규칙

`잠정` (ADR-11 Proposed). 2026-07-03 설계 논의에서 도출, 지호 최종 확인 대기.

## 핵심 아이디어 — 두 축의 분리

**공간을 여는 축(메인 유품)** 과 **이해를 쌓는 축(추리)** 은 서로 종속되지 않는다.

### 축 1 — 공간 개방 (메인 유품 게이트)

메인 유품 **1개가 사령 구역 1개**를 연다(1:1). **구역 개방은 추리 성공과 무관하다.**

### 축 2 — 이해 축적 (추리)

| 선택 | 결과 |
|---|---|
| 추리를 이어감 | 2·3단계 가설 + 4단계 반전 → 성불 / 제령 |
| 추리를 하지 않음 | 보조 유품 판매로 생존템 → 소멸 |

## 방향 규칙

- 공간 개방은 **양방향 왕복** (사령→현실 힌트 흐름 존재)
- 단, **이해(추리)의 흐름은 현실→사령 단방향**을 유지
- **금지**: 사령 단서가 현실의 추리 단계(2·3단계 가설)를 여는 트리거가 되는 것

## 소멸의 최소 조건

**메인 A만 획득하면 보스방이 열린다.** 추리 없이 돌진하면 소멸 엔딩에 도달한다. (`02-01`의 "보스 도전은 첫 진입부터 가능" 유지)

## 배치 제약 — 순환 방지

**N구역을 여는 메인 유품은 N구역보다 앞(현실세계 ~ N-1구역)에만 배치한다.** 뒤에 두면 순환이 발생하므로 금지.

## 준수 사항 (확정 시 적용)

1. 사령 구역은 **메인 유품**으로 연다. **추리 정답을 구역 개방 조건으로 삼지 않는다**
2. 보스방은 **메인 A 획득 시점부터 상시 개방**한다
3. 판매용 보조 유품은 **이해 여부와 무관하게 도달 가능한 위치**에 둔다
4. N구역을 여는 메인 유품은 N구역보다 **앞**에 배치한다
5. 사령 단서가 현실의 추리 단계를 여는 트리거를 만들지 않는다

## 이 규칙이 푼 문제 3가지

1. **메인 유품 ↔ 사령 구역 대응 관계** 미정의 (ADR-3 OQ-1에서 미룬 문제)
2. **데드락**: "추리를 맞혀야 구역이 열린다"면 이해 없이는 사령세계 진입 자체가 안 되어 **소멸 엔딩이 성립 불가**
3. **소멸-판매 루트 데드락**: 판매용 유품이 추리로 열리는 구역 안에 있으면 "이해하지 않으려는 플레이어"가 판매 재료를 못 얻는 순환

---

## 🔴 검토필요 — 유품 획득 위치가 갈린다

**1:1 게이트 원칙 자체는 양쪽이 공유한다.** 갈리는 건 **유품을 어디서 얻는가**다.

| 안 | 구조 | 출처 |
|---|---|---|
| **순차 체인** | 메인 A로 1구역 열고 → **메인 B는 그 1구역 안에서** 획득 → 2구역. 메인 C는 현실 숨겨진 장소 | ADR-11 §2.1 (07-20, Proposed) |
| **동시 노출** | 메인 3개를 챕터 초반 **원룸에서 전부 발견**. 하나를 골라 시작, 각자 독립적으로 구역 개방 | 스토리 (07-23 ~ 08-04) |

**이게 이 프로젝트에서 가장 큰 블로커다.** 레벨디자인 전제가 통째로 갈린다 — 사령 1구역 안에 다음 열쇠를 배치할지 말지가 맵 설계의 출발점이다.

→ 상세 `06-03`, 챕터1 적용은 `04-05`

## 기각된 대안

| 대안 | 기각 사유 |
|---|---|
| 추리로 구역 개방 | 소멸 엔딩과 충돌 |
| 판매 유품 현실세계만 배치 | "사령에서도 판매 유품 획득" 요구 불일치 |
| 곁길 구역(전투게이트)에 판매유품 | 레벨 복잡도 증가 |
| 메인 유품 여러 개 = 한 구역 | 게이트 조건 복잡화 |

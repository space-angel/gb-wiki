> **한 줄**: 재구성 보드는 **메인유품 / 보조유품 / 진술 / 추리 4슬롯 고정**이고, 진행은 **4 STEP**이며, 검증은 **all-or-nothing**(부분 정답 피드백 없음)이다.

# 재구성 보드 — 4슬롯 구조

이해도 시스템의 핵심 UX. `01-02`의 파이프라인이 작동하는 무대이자, `01-05`의 아이템이 배치되는 공간이며, `01-07`의 가설 제출이 일어나는 인터페이스다.

## 슬롯 4종

| 슬롯 | 역할 | 입력 | 효과 |
|---|---|---|---|
| **메인 유품** | 사건 진행 핵심 | 현실세계 탐색 | 사령세계 영역 해금 |
| **보조 유품** | 삶/상태 이해 | 현실세계 탐색 | 메인 의미 확장 / 가설 변화 |
| **진술** | 인물 관점 | NPC 대화 | 단계별 심층 진술 해금 |
| **추리** | 가설 생성 | 위 3종 조합 | 해석 → 가설 |

**핵심 아이템 → 메인 유품 슬롯**, **보조 아이템 → 보조 유품 슬롯**에 배치한다. (`01-05`)

## 진행 4 STEP

```
STEP 1. 사실 확인 — 메인+보조 유품              → 사령세계 접근 + 기본 사건 구조 확보
STEP 2. 관계 파악 — 진술+보조 유품              → NPC 심층 대화 + 신규 정보 해금
STEP 3. 사건 해석 — 유품+진술+추리              → 표면 사건에서 심층 원인 접근
STEP 4. 진실 도달 — 메인 유품+최종 진술+추리    → 보스의 진짜 형태 확인 + 해소 루트 개방
```

> ⚠ **진행 STEP과 O/A/V/R 플래그는 1:1 대응이 아니다.** ADR-5 본문이 이를 혼란 요소로 명시했다. 케이스 작성 시 둘을 혼용하지 말 것. 단계별 판정 조건은 `01-04`.

## 검증 방식 — all-or-nothing `잠정`

- 4슬롯 **동시 배치 + 가설 제출 시 일괄 검증**
- **부분 정답 피드백 없음** (찍기 방지)
- 오답 시 **맞은 슬롯도 확정되지 않음**
- 통과 시 R = TRUE

> 상태: 방향은 확정됐으나 ADR 등록 전 (트래커 `R트리거_AND조합방식` 진행중). 블록 작업: 재화-R씬

## 절대 규칙

1. 재구성 보드는 **항상 4슬롯 구조**를 유지한다
2. 진행 STEP은 **4단계**로 표현한다
3. 핵심 아이템은 메인 유품 슬롯에, 보조 아이템은 보조 유품 슬롯에 배치한다

## 기각된 대안

| 대안 | 기각 사유 |
|---|---|
| 2슬롯 (메인/보조만) | 진술·추리 위치 모호 |
| 3슬롯 (메인/보조/진술) | 추리 단계가 보드 외부에서 일어남 |
| STEP 없는 자유 보드 | 진행 가이드 부재로 진입 장벽 |

## 제약

4슬롯 UI는 화면 영역을 많이 차지한다 (PC 전용이라 실질 제약은 적음).

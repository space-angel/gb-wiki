> **한 줄**: `잠정(ADR-12 Proposed)` — 1단계는 보조유품 N개, 2단계는 핵심유품 NPC 제시, 3단계는 회상공간 기억 확인, 4단계는 4슬롯 충족 + 3지선다 정답. **N 값은 아직 미정(현재 6으로 변수 유지)**.

# 이해도 판정 트리거

`01-02`가 정의한 O→A→V→R 각 단계를 **무엇으로 달성하는가**. 구조는 확정이고 트리거는 잠정이다.

## 단계별 판정 조건

| 단계 | 트리거 | 판정 조건 | 관련 슬롯 |
|---|---|---|---|
| **1단계 (O)** | 보조 유품 수집 | 보조 유품 **N개 이상** 확보 (판매분 제외) | 보조 유품 |
| **2단계 (A)** | 핵심 유품 제시 (조사+제시 통합) | 대상 NPC에게 제시 완료 | 진술 |
| **3단계 (V)** | 회상 공간 진입·기억 확인 | 대응 회상 공간에서 기억 확인 완료 | 추리 (선택지 개방) |
| **4단계 (R)** | 보드 4슬롯 조합 + 가설 선택 | 4슬롯 전부 충족 상태에서 3지선다 정답 선택 | 전체 |

## 핵심 규칙

**① 2단계 이후 판정은 인벤토리를 참조하지 않는다.** (`05-01`)

**② 4단계 최종 판정은 단일 행위다.**
"단서 3개 조합"은 별도 로직이 아니라 재구성 보드의 핵심 유품 슬롯을 채우는 절차일 뿐이다. 최종 판정은 **"4슬롯 충족 상태에서 3지선다 정답 선택"** 하나다. (이중 판정 구조 해소)

**③ 어머니 증언은 진술 슬롯 게이트가 아니다.**
**4단계 정답 선택 이후 재생되는 리워드 컷씬**으로 확정.

**④ 보스방은 1단계 완료가 아니라 메인 유품 A 획득 즉시 열린다.** (`02-02`)

## 오답 처리

3지선다 유지, 오답 시 명시적 표시나 즉각 페널티 없음. 보드가 닫히고 재시도 가능. **1~3단계 플래그는 오답으로 초기화되지 않는다.** 상세 → `01-07`

## 보조 유품 배치

보조 유품은 **현실세계·사령 1구역에 집중 배치**(1단계 초반 완료). 핵심 유품과 서사적으로 페어링하되 **시스템적 해금 의존은 만들지 않는다.**

## 미정 — N 값

**1단계 임계 개수 N.** 현재 **6**으로 변수 유지 중.

- 구조(임계 기반 O 판정)는 확정인데 값이 없다
- 아이템 풀: 챕터당 13~15개 (핵심 3 + 보조 10~12)
- 미결 지점: ① N 값 ② 핵심/보조 구분 없이 순수 개수인지, 핵심에 가중치를 둘지 ③ 챕터마다 동일한지
- **제약**: 어떤 수집 순서로도 도달 가능해야 한다 (특정 유품 강제 금지)
- **결정 트리거**: 챕터1 현실세계 맵 초안 + 유품 배치안이 나온 뒤. **맵 없이 정하면 감으로 찍는 것이 된다**

## 기각된 대안

| 대안 | 기각 사유 |
|---|---|
| 4단계를 "단서 3개 조합"만으로 판정 | 이중 판정 구조 발생 |
| 오답 즉시 "오답" 표시 | Obra Dinn식 침묵 설계와 충돌 |
| 조사·제시를 별개 단계로 | 파이프라인이 5~6단계로 늘어나 `01-02` 위반 |
| 어머니 증언 3단계 배치 | "최종 증인 = 4단계" 전제 충돌 |
| 보스방 O_reached 이후 개방 | `02-02`와 충돌 |

## 비용

- 2단계 조사+제시 통합 UI 신규 설계 필요
- 어머니 증언 리워드 컷씬 연출 분량 증가
- "보조 유품 페어링은 배치일 뿐 시스템 의존이 아니다"를 작가와 반복 커뮤니케이션 필요

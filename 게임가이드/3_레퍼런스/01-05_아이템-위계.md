# 아이템 위계 — 핵심/보조 2등급

S/A/B 3등급 체계는 **기각**됐다. 시스템상 필요한 구분은 하나 — **판매 가능 여부**다.

## 2등급 정의

| | **핵심 아이템** | **보조 아이템** |
|---|---|---|
| 성격 | 고인의 본질에 닿는 물건. 사건 진실과 직결 | 주변 정황을 구성하는 물건 |
| **판매** | **불가** | **가능** (관리인 NPC에게) |
| 보드 연결 | 필수 | 선택 |
| 발견 시 효과 | 사령세계 해당 영역 잠금 해제 | 없음 |
| 연결·조합 시 효과 | 표층→심층 전환 트리거 (R_reached) | O→A→V 플래그 진행 재료 |
| 판매 시 효과 | — | 생존성 아이템 획득 (**소멸-아이템 루트**) |
| **챕터당 수량** | **정확히 3개** | **6개** |

챕터당 총 **9개**. 보조 6개는 자유 배치가 아니라 **메인 유품(조사축) 3종에 축당 정확히 2개씩
귀속**된다 (ADR-15, 2026-08-17 개정 — 기존 10~12개에서 축소).

## 시각 구분 = 슬롯 위치로만

핵심/보조의 시각 구분은 **재구성 보드의 슬롯 위치**로 표현한다. **아이템 자체에 등급 표시를 두지 않는다.** (아트 작업량 폭증을 막기 위한 결정)

## O_reached 판정 조건 — AND

1. 챕터 내 **핵심 아이템 3개 전부** 발견 (보스방 전용 핵심 포함)
2. 챕터 내 **보조 아이템 N개 이상** 발견

**핵심 일부만으로 O를 판정할 수 없다.** N 값은 미정이나, 보조 풀이 6개뿐이라 **N ≤ 6**이 전제다
(`01-04`, 트래커 `1단계O_임계값N정의`).

## 절대 규칙

1. 핵심 아이템은 챕터당 **3개**, **전부 판매 불가**
2. 보조 아이템은 챕터당 **6개**(조사축 3개 × 축당 2개), **전부 관리인 판매 가능**
3. O_reached는 **핵심 3개 전부 + 보조 N개 이상의 AND 조건**
4. 아이템 등급을 **3단계 이상으로 나누지 않는다**
5. 아이템 자체에 등급 표시를 두지 않는다

## 소멸 루트와의 연결

**보조 아이템 판매가 소멸 루트의 메카닉이다.** "이해하지 않기로 한 플레이어"에게도 진행 경로를 주는 장치이므로, 판매용 보조 유품은 **이해 여부와 무관하게 도달 가능한 위치**에 두어야 한다. (`02-02`)

## 왜 이렇게 정했나

판매 여부를 위계 기준으로 삼은 이유와 기각한 대안 4가지(3등급 유지·핵심 2개·등급 표시 등)는 심화 문서에 있어요.

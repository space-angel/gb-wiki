# 내 파트 찾기

각 파트가 **꼭 알아야 하는 것**과 **자주 어기는 것**을 뽑았어요.

---

## 📖 스토리 · 시나리오

### 읽을 것
`04-01` 사건 개요 → `04-02` 고인 → `04-04` NPC → `04-05` 조사축 → `04-08` 감정 곡선
그리고 [핵심 원칙](../1_소개/핵심원칙.md) **원칙 2·3은 필수**예요.

### 반드시 지킬 것

| 규칙 | 근거 |
|---|---|
| 핵심 유품은 챕터당 **정확히 3개**. 보조는 10~12개 | `01-05` |
| A 단계 NPC와 V 단계 NPC는 **다른 사람**. 각각 최소 2명 | `04-04` |
| 가설 선택지는 **정답1 + 오답2 = 3지선다 고정**. 두 오답은 서로 다른 방향으로 그럴듯해야 해요 | `01-07` |
| 서사적 중간 단계를 **플래그로 신설하지 않아요.** O·A·V·R 네 개가 전부예요. 필요하면 **연출 비트**로 처리 | `01-02` |
| 누구도 **결론을 직접 말하지 않아요** | `04-08` |

### 자주 어기는 것

> ⚠️ **O-A-V-X-R (5단계)** 로 쓰는 것. 서사적으로 X 단계가 필요하다는 발견은 맞지만, 시스템 플래그와 **같은 표기법을 쓰면** 다섯 번째 플래그처럼 읽혀요. X는 R 진입 직전의 **연출 비트**로 배치하세요.
>
> ⚠️ **핵심 유품을 4~5개로 늘리는 것.** 서사적으로 의미 있는 물건이 5개 나오는 건 자연스러운데, 시스템은 3개예요. 나머지는 보조로 재분류하세요.

### 지금 막혀 있는 것
- **메인 유품 3종 명칭**이 문서마다 달라요 (`06-03` C-2)
- **조사 완료 조건**이 비어 있어요 — 조사축이 끝났다고 판단하는 기준
- 과거·현재 축 **보조유품 각 2개 미정**

## ⚙️ 게임 디자인 · 시스템

### 읽을 것
`01-01` ~ `01-08` 전부. `02-02` 공간 개방. `05-01` 3계층 분리.
**4. 심화 전체**를 읽으면 같은 논의를 반복하지 않을 수 있어요.

### 반드시 지킬 것

| 규칙 | 근거 |
|---|---|
| 이해도는 **4개 boolean**. 가중 합산·단일 수치 금지 | `01-02` |
| 순서 의존성을 깨는 트리거 금지 (O 없이 A 달성 등) | `01-02` |
| **보스 도전을 이해도에 종속시키지 않아요.** 첫 진입부터 가능해요 | `01-02` `02-01` |
| 이해도 출력은 **보스 한정**. 잡몹은 무관 | `01-03` |
| O_reached = **핵심 3개 전부 + 보조 N개 이상** (AND) | `01-05` |

### 자주 어기는 것

> ⚠️ **가중치·퍼센트 임계값 도입.** 밸런싱하다 보면 자연스럽게 나오는 발상인데, 이걸 쓰면 **R 없이 성불이 가능해져요.** [왜 4플래그인가](../4_심화/왜-4플래그인가.md)를 먼저 확인하세요.
>
> ⚠️ **"이해도 임계 도달 시 보스방 개방".** 진행 게이트로 쓰기 편해 보이지만 ADR-2·7 정면 위반이에요.

### 지금 막혀 있는 것
- **1단계 O 임계값 N** — 맵 초안이 나와야 정할 수 있어요 (현재 6으로 가정)
- **컷오프 정의 + R 미달 보스전 결과** — 같은 문제의 양면이라 통합 논의 필요
- ADR-11~14가 **Proposed** 상태로 서로 얽혀 있어요

## 🎨 아트 · UI

### 읽을 것
`02-03` 시점 · `04-03` 현장 구조 · `01-06` 재구성 보드 · `03-01` 전투

### 반드시 지킬 것

| 규칙 | 근거 |
|---|---|
| **현실세계 = 사이드뷰 / 사령세계 = 탑다운뷰** | `02-03` |
| 두 세계 전환 시 **카메라 시점 전환 연출**을 둬요 | `02-03` |
| **이해도 게이지·진행바·단계 표시·달성 알림 전부 금지** | `01-01` |
| 아이템 자체에 **등급 표시를 두지 않아요.** 구분은 보드 슬롯 위치로만 | `01-05` |
| 오답에 **명시적 실패 표시(텍스트·아이콘·사운드) 금지** | `01-07` |
| 재구성 보드는 **4슬롯** 고정 | `01-06` |

### 자주 어기는 것

> ⚠️ **이해도 게이지 UI.** 진행도를 보여주는 건 UX 상식인데, 이 게임은 **의도적으로 안 보여줘요.** 이유는 [왜 이해도를 안 보여주나](../4_심화/왜-이해도를-안보여주나.md)에 있어요.
>
> ⚠️ 현실세계를 **탑다운으로 그리는 것.** 맵 레퍼런스에 탑다운·사이드뷰가 둘 다 섞여 있어서 헷갈리기 쉬워요. 현실은 사이드뷰예요.

### 지금 막혀 있는 것
- **패턴 가시성 시각 표현** — 히트박스 윤곽 / 이펙트 잔상 / 카메라 줌인 중 미정. 픽셀 작업 진입 시 결정
- 맵 레퍼런스에 두 시점이 혼재 (`06-03`)
- 아트 문서 다수가 **빈 페이지** 상태

## 💻 개발 · 구현

### 읽을 것
`05-01` 3계층 분리 **먼저**. 그다음 `01-02` `01-04` `03-01`

### 반드시 지킬 것

| 규칙 | 근거 |
|---|---|
| **인벤토리 / 플래그 / 컷씬 3계층을 분리**하고 참조 방향을 단방향으로 고정 | `05-01` |
| 인벤토리는 **개수 기록 + 임계값 이벤트 발행만**. 플래그를 직접 변경하지 않아요 | `05-01` |
| 컷씬은 **플래그 참 신호만 구독**. 인벤토리를 직접 조회하지 않아요 | `05-01` |
| **O 이후(A/V/R)는 인벤토리 이벤트를 아예 구독하지 않아요** | `05-01` |
| 재시도 횟수·실패 이력을 **저장 스키마의 어떤 키로도 기록하지 않아요** | `01-07` |
| 회피는 **무적 판정 + 캔슬 가능**. 패링·가드 없음 | `03-01` |

### 자주 어기는 것

> ⚠️ **아이템 소지 여부로 플래그를 직접 판정하는 것.** 가장 짧은 구현인데, 이러면 순서를 건너뛸 수 있어요. 우회 구현 한 번이면 3계층 분리가 무력화돼요.
>
> ⚠️ **패링 구현.** 액션 게임 상식이지만 ADR-8이 명시적으로 뺐어요.

### 지금 막혀 있는 것
- ADR-13이 **Proposed** — 계층 구조를 확정 전에 코드로 굳히면 위험해요. Unity 작업 시작 전 확인 필요
- 저장 스키마 `flags` 키 구조 확인 (E0-S3 시점)

# 챕터1 NPC

## 공통 원칙 `확정`

NPC는 사건의 진실을 알려주는 존재가 아니다. NPC는 **현실에서 자신이 경험한 것만 말하는 사람**이다. 진실은 유품 · 환경 · 사령세계를 통해 플레이어가 직접 재구성한다.

1. **NPC는 거짓말하지 않는다. 하지만 틀릴 수 있다.**
   예) "취업 준비도 안 하던데." — 실제로는 엄청 많이 했다
2. **NPC는 추측한다.** 예) "우울증이었겠죠." "힘든 줄은 몰랐어요."
3. **NPC는 피해자를 정의하지 않는다.** "착한 사람" / "나쁜 사람"이라고 말하지 않는다
4. **NPC는 자신의 시점만 안다.**

## A·V 단계 분리 원칙 `확정` (ADR-6)

**A 단계와 V 단계의 핵심 진술자 NPC는 서로 다른 사람이어야 한다.**

| 단계 | 역할 |
|---|---|
| **A 단계 NPC** | "초기 행동의 이유 추론" → 표층 가설 형성 |
| **V 단계 NPC** | "최종 감정 검증" → 심층 해석으로 안내 |

케이스당 **A 단계 2명 이상, V 단계 2명 이상.**

**왜**: 분리하지 않으면 같은 NPC를 반복 탐문해 정보를 캐는 패턴이 가능해지고, "인식 변화량 측정" 원칙(`01-01`)이 깨진다.

**비용**: 케이스당 최소 4명이 고정 비용. A 단계 NPC를 V 단계에서 다시 만나는 자연스러운 흐름은 허용되지 않는다.

> 🔴 **검토필요**: 현재 배정은 A=이유미 1명, V=상담사 1명이고 어머니는 "Transition"으로 어느 쪽에도 속하지 않아 **"각 2명" 요건 미충족**이다. 또한 `04-05`에서는 이유미가 A+V를 겸한다. → `06-03`

## NPC 5명

### 관리인 (허브 NPC)

| 항목 | 내용 |
|---|---|
| 존재 목적 | 현실과 플레이어를 연결하는 허브 / 상점 / 사건 배정 / 현실 절차 |
| 등장 장소 | 프롤로그, 건물 외부, 특수청소 차량, 챕터 종료 후 거점 |
| 담당 공간 | 현실 전체 |
| 기능 | 유품 판매 ○ · 유품 보관 ○ · 장비 구매 ○ |
| 플레이어 선택 | 유품 판매 → 재화 획득 → **소멸 부적 구매** |
| 알고 있는 것 | 경찰 철수, 의뢰 내용, 청소 범위, 유족 인계 물품 |
| 모르는 것 | 사령, 기억, 미완, 플레이어가 보는 것 |
| 만드는 오판 | 없음 |
| **OVAR** | 없음 |
| **절대 말하지 않는 것** | "사령" "기억" "성불" |
| **금지** | 사령 설명, 세계관 설명, 죽음 해석 |

**대사 톤**: *"집주인한테 연락 왔다." / "네 손이 필요할지도 몰라." / "이번 건…" / "네가 직접 한번 보는 게 좋겠다."*

### 집주인

| 항목 | 내용 |
|---|---|
| 존재 목적 | 사건 발생의 시작 |
| 등장 / 담당 공간 | 건물 입구 / 현관, 복도 |
| 연결 오브젝트 | 마지막 문자 · 월세 고지서 · 계좌 입금 내역 |
| 핵심 유품 | 없음 |
| 보조 유품 | 월세 고지서 |
| 해금 | 게임 시작 |
| 알고 있는 것 | 연체 / 문자 / 발견 |
| **만드는 오판** | **"생활고 때문에 죽었다."** |
| 수정되는 진실 | 돈보다 '기대를 저버렸다는 감정'이 더 컸다 |
| **OVAR** | **O** |
| 다음 조사 유도 | 거실, 중문 밖 |

**도덕적 위치 — 단순한 악인으로 만들지 않는다**
- 건물 가치와 자신의 생계를 우선한다
- 동시에 김태현의 연락 두절을 이상하게 여기고 **직접 신고했다**
- 사건 이후에는 더 빨리 확인했어야 했는지 고민한다
- **경제적 계산과 인간적 후회가 동시에 존재한다**

이 양면성이 초반의 불편한 인상과 심층 진술의 반전을 만든다.

### 이유미 (옆집 주민)

| 항목 | 내용 |
|---|---|
| 존재 목적 | '마지막까지 남아 있던 책임'을 보여주는 NPC |
| 등장 / 담당 공간 | 복도 (중문 밖 충분히 조사 후) / **중문 밖** — 이 NPC의 핵심 |
| 연결 오브젝트 | 고양이 이동장 · 사료 · 물그릇 · 화장실 |
| 핵심 유품 | 없음 |
| 보조 유품 | 고양이 용품 일체 |
| **해금 조건** | 사료·물그릇·화장실 중 **2개 이상 조사** |
| 알고 있는 것 | 고양이를 정말 아꼈다 / 마지막까지 챙겼다 / 항상 웃으며 인사했다 |
| **만드는 오판** | **"참 착한 사람이었어요."** |
| 수정되는 진실 | 조용했던 것이 아니라 **힘든 모습을 감췄다** |
| **OVAR** | **A** → '끝까지 책임을 놓지 않았다.' |
| 다음 조사 | 중문 개방 |

### 상담사

| 항목 | 내용 |
|---|---|
| 존재 목적 | '노력하지 않았다'는 오판을 깨는 NPC |
| 등장 / 담당 공간 | 전화 (혹은 취업센터) / 책상 |
| 연결 오브젝트 | 취업 준비 파일 · 상담 기록 · 일정표 · 모의면접 메모 |

| 보조 유품 | 상담 기록 / 일정표 / 면접 메모 |
| **해금 조건** | 취업 준비 파일 조사 |
| 알고 있는 것 | 계속 도전했다 / 꾸준히 상담받았다 |
| **만드는 오판** | **"이제 좋아지고 있는 줄 알았습니다."** |
| 수정되는 진실 | 끝까지 버텼지만 결국 도움을 요청하지 못했다 |
| **OVAR** | **V** → "생각보다 훨씬 많이 버텼다." |
| 다음 조사 | 러닝화 |

### 어머니

| 항목 | 내용 |
|---|---|
| 존재 목적 | '기대의 시작'을 보여주는 NPC |
| 등장 / 담당 공간 | 전화 (챕터 후반) / 침대, 책장 |
| 연결 오브젝트 | 졸업사진 · 가족사진 · 상장 |
| **핵심 유품** | ✔ 졸업사진 (조사 후 **자동으로 유족 인계**) |
| 보조 유품 | 상장 / 가족사진 |
| **해금 조건** | 졸업사진 조사 |
| 알고 있는 것 | 어릴 적 태현 / 성실했던 모습 / 가족 이야기 |
| **만드는 오판** | **"힘들면 엄마한테 말했을 거야."** |
| 수정되는 진실 | 말하지 못한 것이 아니라, **말할 수 없었다** |
| **OVAR** | **Transition** → "남이 기대한 삶이 아니라, 스스로 기대를 짊어진 삶이었다." |
| 다음 조사 | 최종 사령세계 |

> 어머니 증언은 진술 슬롯 게이트가 아니라 **4단계 정답 선택 이후 재생되는 리워드 컷씬**이다. (`01-04`)

## NPC-장소-유품 매핑

| 장소 | 오브젝트 | 유품 | NPC | 플레이어의 첫 오판 |
|---|---|---|---|---|

| 중문 밖 | 사료·물그릇·이동장 | 고양이 용품 | 이유미 | 착하고 평범한 청년이었다 |

| NPC | 플레이어가 처음 믿게 되는 것 | 나중에 수정되는 진실 |
|---|---|---|
| 집주인 | 생활고 때문에 죽었다 | 돈보다 '기대를 저버렸다는 감정'이 더 컸다 |
| 이유미 | 착하고 조용한 사람이었다 | 조용했던 것이 아니라 힘든 모습을 감췄다 |
| 상담사 | 회복되고 있었다 | 끝까지 버텼지만 결국 도움을 요청하지 못했다 |

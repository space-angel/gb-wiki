> 2. **이유미가 A+V를 겸한다.** `04-04`에서는 이유미가 A로만 표기돼 ADR-6(A/V 분리)과 충돌 소지

## 메인 유품의 이중 역할

각 메인 유품은 플레이어에게 **일찍 노출**되며 두 가지 역할을 한다.

| 시점 | 역할 |
|---|---|
| 초반 | **열쇠** — 각각 사령세계 1·2·3을 연다 |
| 후반 | **재해석 대상** — 단순한 단서가 아니라 추리의 대상 |

## 조사축 상세

### 과거 축 — 졸업사진

| 항목 | 내용 |
|---|---|
| 최초 플레이어 인식 | 평범한 가족사진 |
| 조사 목적 | 왜 졸업사진이 핵심 유품인가? |
| 사령세계 감정 | **보답** |
| 획득 보조유품 | `미정` ×2 |
| 현실 탐문 NPC | 어머니 |
| NPC 최초 진술 | "태현이는 걱정을 시키지 않는 아이였어요." |
| NPC 재인식 | "혼자 너무 책임지려 했어요." |
| 무너지는 오판 | 부모가 직접 압박했다 |
| **최종 재해석** | **보답하고 싶던 마음이 스스로에게 의무가 되었다.** |
| 이해도 기여 | R |

### 현재 축 — 핸드폰

| 항목 | 내용 |
|---|---|
| 최초 플레이어 인식 | SNS를 많이 보던 사람 |
| 조사 목적 | 비교는 어디서 시작됐는가? |
| 사령세계 감정 | **비교 / 자기비하** |
| 획득 보조유품 | `미정` ×2 |
| 현실 탐문 NPC | 이유미 |
| NPC 최초 진술 | "원래 밝은 사람이었어요." |
| NPC 재인식 | "자기 자신을 계속 깎아내렸어요." |
| 무너지는 오판 | SNS, 유튜브로 시간을 낭비했다 |
| **최종 재해석** | **비교와 자기비하가 문제였다.** |
| 이해도 기여 | A + V ⚠ |

### 미래 축 — 취준 파일

**세 축 중 진도가 가장 빠른 축.** 보조유품 후보가 유일하게 나와 있어 나머지 두 축 작성의 기준이 될 예정이다.

| 항목 | 내용 |
|---|---|
| 최초 플레이어 인식 | 취업 실패한 백수 |
| 조사 목적 | 얼마나 버티려고 했는가? |
| 사령세계 감정 | **노력 / 좌절** |
| **획득 보조유품** | ① 면접 일정이 빼곡한 다이어리 **(노력)** ② 반복된 드라이클리닝 영수증과 면접 정장 **(좌절)** |
| 현실 탐문 NPC | 상담사 |
| NPC 최초 진술 | "컨설팅 받는거 치곤 방문이 뜸했어요." |
| NPC 재인식 | "끝까지 포기하지 않았어요." |
| 무너지는 오판 | 아무것도 하지 않았다 |
| **최종 재해석** | **실패했지만 계속 살아보려 했던 사람이었다.** |
| 이해도 기여 | V |
| 사령세계 3 연출 방향 | **"끝나지 않는 면접."** (패턴·맵구조 `미정`) |

## 지금 막고 있는 것 (P1, 4건)

### 1. 1단계(O) 임계값 N

O 달성에 필요한 유품 개수. **구조는 확정, 값이 없다.** 현재 **6**으로 변수 유지 중.

| | 내용 |
|---|---|
| 확정 전제 | O = 유품 개수 임계 도달 방식 / 아이템 풀 = 챕터당 13~15개 |
| 미결 지점 | ① N 값 ② 순수 개수인지 핵심에 가중치를 둘지 ③ 챕터마다 동일한지 |
| 제약 | **어떤 수집 순서로도 도달 가능해야 함** (특정 유품 강제 금지) |
| **결정 트리거** | **챕터1 맵 초안 + 유품 배치안 이후.** 맵 없이 정하면 감으로 찍는 것 |

→ `01-04`

### 2. 임계값(충분/적정/없음) 컷오프 정의

플래그 조합 → 종결 매핑안이 **제안 상태로만 존재**하고 팀 합의·ADR 등록이 없다.

| | 내용 |
|---|---|
| 미결 지점 | ① 매핑안 팀 합의·ADR 등록 ② **"없음 = A false"가 상태인지 행동인지** ③ 중간 상태 전 구간 미명시 |
| 결정 트리거 | 아래 3번과 **통합 논의** |
| 블록 작업 | 재화-후일담 |

→ `01-08`

### 3. R 미달 상태 보스전 결과

보스룸 항시 접근이 확정되면서 R 미달 상태로도 들어갈 수 있는데, **들어가서 무슨 일이 일어나는지 아무도 정의하지 않았다.**

| | 내용 |
|---|---|
| 미결 지점 | 미도달 상태 보스전이 **"벽"으로 느껴지지 않게** 하는 연출 — 재탐색 동기 부여 |
| 결정 트리거 | 위 2번과 통합 필수. **보스전 플로우 구현(Unity-전투프로토) 전 잠금** |

→ `01-08`

### 4. 핵심 유품 배치 정책

**A) 현실 한정** vs **B) 체인 허용**(사령 구역 안에 다음 열쇠). 논리적으로 강제되는 건 **"열쇠 의존 그래프에 순환이 없을 것"** 하나뿐이다.

> ADR-11이 사실상 **B안**을 채택했다. ADR-11이 Accepted되면 종결 가능. 단 ADR-11 자체가 스토리 자료와 충돌 중이라 그쪽이 먼저 정리돼야 한다. → `06-03`

## 의도적 연기 (P2, 4건)

**지금 정하면 안 되거나, 정할 근거가 아직 없는 것들이다.** 방치가 아니다.

### 5. 재구성 오답 제출 리액션

> ADR-14가 대부분 답했다 — "명시적 실패 피드백·페널티 없음". ADR-14 확정 시 종결 가능.
>
> **남은 질문 하나**: "제출됐으나 틀렸다"를 **버그로 오해하지 않게 하는 최소 피드백 라인.** 완전 무반응이 원칙엔 충실하지만 UX상 위험. 정인-슬롯UI 시안 전 잠금 권장.

### 6. 패턴 가시성 시각 표현

히트박스 윤곽 / 이펙트 잔상 / 카메라 줌인 중 택1 + 단계별 차등 여부.
**연기 사유**: 기능 방향은 확정, 시각 수단만 남음. 아트 스타일과 픽셀 작업 역량 확인 후가 맞다.
**결정 트리거**: 문정인 픽셀 작업 진입 + 보스 1종 패턴 프로토타입 완성 시 (M2~M3)

### 7. 종합 이해도 U 산출 공식

**연기 사유**: 입력값(챕터 수, 챕터별 종결 구조)이 미정이라 **공식을 만들어도 재작업 확정.**
**결정 트리거**: 전체 챕터 수 확정 + 아래 8번과 함께. 챕터1 데모(2027-06)에는 불필요.

### 8. 최종 엔딩 분기 처리 방식

"경우의 수 6가지"는 특정 챕터 수를 가정한 계산인데 **전체 챕터 수가 미확정**이라 전제 자체가 유동적이다. 위 7번과 같은 문제의 양면.

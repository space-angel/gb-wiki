## ⚠ ADR 원문을 읽을 때 주의

**supersede가 원문에 반영돼 있지 않다.**

| 사례 | 내용 |
|---|---|
| **ADR-1 ← ADR-9** | ADR-1이 정의한 출력 3종 중 "잡몹 약화"를 ADR-9가 삭제했으나 **ADR-1 본문은 그대로다.** 원문만 읽으면 폐기된 규칙을 따르게 된다 (`01-03`) |
| **ADR-3 OQ-1 → ADR-11** | "핵심 3개와 메인 유품의 관계"를 ADR-3이 미뤘고 ADR-11이 1:1 대응으로 답했다 |
| **ADR-12 OQ-2 → ADR-14** | "오답 재시도 횟수"를 ADR-12가 미뤘고 ADR-14가 무제한으로 답했다 |
| **ADR-6 → ???** | "R 단계 NPC 지정 규칙은 ADR-8에서 정의"라고 적혀 있으나 **ADR-8은 전투 톤이다.** 담당 ADR 자체가 없는 공백 |
| **ADR-3 ← ADR-15** | 보조 아이템 수량을 10~12개에서 6개로 개정(2026-08-17). ADR-3의 다른 조항(핵심 3개, 판매 여부 등)은 그대로 유효 |

**이 트리는 위 supersede를 이미 반영했다.** 트리와 ADR 원문이 다르면 트리를 따르되, 트리 버그일 가능성도 함께 알린다.

## Proposed 4건은 서로 얽혀 있다

```
ADR-11 (공간 개방) ──┐
ADR-12 (판정 규칙) ──┼── 서로 참조. 하나만 바뀌면 나머지도 흔들림
ADR-13 (3계층)     ──┘
ADR-14 (오답) ← ADR-12에서 분리
```

한꺼번에 확정하는 것이 자연스럽다. **Proposed는 확정 효력이 없으므로 "ADR에 있으니 맞다"고 판단하면 안 된다.**

## ADR을 언제 보나

| 질문 | 어디 |
|---|---|
| "지금 X는 뭐야?" | **이 트리**의 해당 문서 |
| "왜 그렇게 정했어?" | ADR 원문 §Context, §Decision |
| "다른 방법은 왜 안 됐어?" | ADR 원문 **§대안 검토 (기각)** — 같은 논의를 두 번 하지 않게 막아준다 |
| "언제 누가 정했어?" | 위 표 + ADR 원문 §Status |

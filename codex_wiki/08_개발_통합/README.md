# 개발·통합

기획·대사·공간·아트·사운드를 실제로 실행할 수 있는 게임으로 연결합니다. 현재 사용자 확인 기준으로 플레이 가능한 빌드는 없습니다.

## 현재 자료와 상태

| 항목 | 내용 |
|---|---|
| 과거 기록 | 7월 20일에 프로젝트·입력 기반 완료, 저장 착수 보고 |
| 현재 검증 | 코드·씬·세이브·빌드·에셋 재사용 여부 미검증 |
| 세부 상태 | [구현 현황](구현현황.md)에서 보고와 검증을 구분 |

## 적용할 규칙과 경계

4플래그·시점·전투 등 Accepted 규칙을 참조합니다. 3계층 아키텍처(ADR-13)와 세부 판정(ADR-12)은 Proposed이며 현재 코드 구조로 확정하지 않습니다.

## 미결 사항

C-5~7과 C-11을 봅니다. 프로젝트 실행·입력 확인은 전체 기획 확정을 기다릴 필요가 없고, 특정 진행 기능을 구현할 때 그 기능의 조건을 확인합니다.

## 다음 산출물 — 작업 후보

| 산출물 | 확인할 결과 | 연결되는 영역 |
|---|---|---|
| 프로젝트 실행 확인 | 실행 절차·사용 버전·성공/실패와 원인·시험 빌드 | 전체 영역 |
| 재사용 목록 | 동작 확인한 코드·씬·에셋과 보완할 부분 | 기획·아트 |
| 첫 구간 통합 | 진행표에 따른 행동과 결과가 같은 빌드에서 재현 | 스토리·공간·아트 |
| 상태 데이터 초안 | 조사·보유·진술·플래그·구역·연출 상태의 책임과 저장 범위 | 진행·기획 |

담당·마감·작업량은 아직 배정하지 않았습니다. 기존 외부 산출물이 있으면 확인·보완부터 합니다.

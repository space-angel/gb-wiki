# 구현 현황과 첫 통합

**2026-09-08 사용자 확인: 플레이 가능한 빌드는 없습니다.** 기존 코드·씬·입력·저장·에셋이 얼마나 재사용 가능한지는 이번 위키 작업에서 실행 검증하지 않았습니다.

## 과거 보고와 현재 확인의 분리

| 항목 | 과거 기록 | 현재 확인 상태 |
|---|---|---|
| 프로젝트·Git 기반 | 7월 20일 완료 보고 | 현재 프로젝트 실행 미검증 |
| 입력 | 7월 20일 완료 보고 | 실제 이동·조사 기능까지 동작하는지 미검증 |
| 저장 | 7월 20일 착수 보고 | 저장→종료→복원 미검증 |
| 그레이박스·카메라 | 과거 계획에 작업 언급 | 실제 씬·충돌·카메라 미검증 |
| 대화·인벤토리·추리·전투 | 기획·작업 후보 존재 | 플레이 가능한 통합 결과 미확인 |
| 아트·사운드 적용 | 작업 가이드 존재 | 실제 파일·임포트·빌드 결과 미검증 |

폐기한 로드맵의 완료 표시는 현재 코드 상태의 근거가 아닙니다.

## 먼저 확인할 실행 경로 — 작업 후보

1. 실제 개발 저장소와 사용하는 Unity 버전을 확인.
2. 프로젝트를 열고 실행할 씬·입력·현재 오류를 확인.
3. 현재 가능한 동작과 재사용할 코드·에셋을 기록.
4. 실행 가능한 최소 시험 빌드와 재현 방법을 남김.

위 항목은 전체 게임 기획이 확정되기 전에도 진행할 수 있습니다.

## 구현 전에 조건을 맞출 항목

| 구현 범위 | 필요한 입력 |
|---|---|
| 이동·조사 | 첫 공간 범위·조작·충돌·조사 결과 |
| 대화 | 텍스트·화자·대사 단계·공개 조건 |
| 인벤토리·판매 | 아이템과 정보단서 구분, 보유·처분 상태 |
| 이해도 | O 조건·이후 트리거·축별/챕터별 범위 |
| 저장 | 보존할 상태와 판매·오답·복귀 시 변화 |
| 세계 전환·전투 | 출입·복귀·보스 접근·승패 결과 |

3계층 구조와 ‘O 이후 인벤토리 미참조’는 ADR-13의 **제안**입니다. 구현 모듈을 확정하기 전에 실제 단서별 대화 조건과 함께 검토합니다.

## 인계에서 빌드까지

기획의 행동·조건·결과표를 기준으로, 대사와 에셋을 적용하고 같은 동작을 확인합니다. 변환 파일 형식·경로·개발 도구는 실제 프로젝트에서 샘플을 확인한 뒤 결정합니다. 이전 계획의 JSON 규격을 자동 승계하지 않습니다.

완료 증거는 **실행 방법 / 빌드 또는 씬 / 재현 행동 / 기대 결과 / 남은 제한**입니다. 문서 작성이나 코드 존재만으로 플레이 완료라고 기록하지 않습니다.

# 문서 작성과 갱신 규칙

**문서가 작성됐는지, 규칙이 승인됐는지, 게임에서 동작하는지는 서로 다른 상태입니다.**

## 영역별 문서의 기본 구조

| 항목 | 작성할 내용 |
|---|---|
| 현재 상태 | 사용자 확인·로컬 문서·실행 확인 중 무엇이 근거인지 |
| 확정 규칙 | Accepted ADR의 해당 조항과 개정 이력 |
| 작성 중인 기획 | 현재 원안, 사용할 내용, 미검토 범위 |
| 미결 사항 | 쟁점 목록의 식별자와 해당 작업에 미치는 영향 |
| 다음 산출물 | 다음 사람이 사용할 수 있는 결과와 확인 방법 |
| 관련 영역·출처 | 연결되는 문서와 원본 링크 |

이 틀은 전체 위키의 작성 방식입니다. 기획을 모두 확정하거나 모든 산출물을 먼저 만들라는 선행 조건은 아닙니다.

## 상태 표시

| 상태 | 사용할 때 |
|---|---|
| 확정 규칙 | Accepted ADR로 확인되고 후속 개정까지 반영됨 |
| 제안 | Proposed ADR 또는 이번 개편에서 제안한 방식 |
| 기획 작성 중 | 콘텐츠·동선·대사·화면 등 작업 중인 안 |
| 검토 필요 | 출처 간 차이 또는 규칙과의 정합성 확인이 필요함 |
| 구현 미검증 | 구현 보고·코드는 있으나 현재 실행 결과 미확인 |
| 자료 미확인 | 원본·첨부·동작 증거를 확보하지 못함 |
| 확인 완료 | 무엇을 어떤 파일·빌드에서 확인했는지 증거가 있음 |

원본에 ‘확정’이라고 적혔어도 개인 메모·예시·초안이면 승인된 규칙으로 옮기지 않습니다. 혼합 문서는 문장·표 행별로 표시합니다.

## 한 정보의 기준 위치

- 공통 규칙: [공통 규칙](../01_게임방향/공통규칙.md) → 상세 근거는 ADR 원문.
- 기획 내용: 해당 영역 상세 문서. 다른 영역에서는 링크로 연결.
- 미결·충돌: [쟁점 목록](../09_결정_미결/쟁점목록.md). 영역별 페이지에는 해당 식별자만 요약.
- 담당·마감·사이클: 새 로드맵에서 합의한 뒤 연결. 폐기한 계획을 복원하지 않음.
- 원본 스냅샷·역사: [출처와 개편 이력](출처와개편이력.md)의 이전 커밋·원문 링크. 과거 기록을 임의의 게임 결정으로 덮어쓰지 않음.

## 날짜와 근거

페이지를 정리한 날짜와 원본을 확인한 날짜를 구분합니다. 이번 생성일은 2026-09-08이지만 외부 전체 동기화가 된 것은 아닙니다. 현재 원본 대조 범위는 [위키 홈](../README.md)에 적혀 있습니다.

새 내용을 반영할 때 기록할 것: 원본 링크, 원본 날짜, 반영 범위, 남은 미확인 사항.

## 산출물 인계

| 산출물 | 인계 때 확인할 것 |
|---|---|
| 기획 | 행동·조건·결과가 연결되는지, 남은 미결이 식별되는지 |
| 대사·텍스트 | 화자·대사·공개 조건·연출 메모를 수신자가 구분할 수 있는지 |
| 아트 | 파일·크기·피벗·레이어 등 필요한 제작 규격과 적용 화면 |
| 사운드 | 파일·용도·재생 조건·루프 및 종료 방식 |
| 구현 | 실행 방법·재현할 행동·기대 결과·현재 제약 |
| 결정 | 결정문과 영향받는 기획의 반영 여부 |

완료 기준은 작업 범위에 맞춥니다. 대본 검토와 빌드 통합을 서로 다른 작업으로 추적할 수 있지만, 둘을 모두 ‘게임 완성’으로 집계하지 않습니다.

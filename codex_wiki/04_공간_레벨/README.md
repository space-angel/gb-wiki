# 공간·레벨

장소의 의미를 플레이어 동선·조사 위치·구역 출입 조건으로 구체화하는 영역입니다. 원룸 설명과 사령세계 컨셉은 있으나 현재 실제 도면·씬은 미검증입니다.

## 현재 자료와 상태

| 항목 | 내용 |
|---|---|
| 현실 공간 | 원룸과 중문 전후 대비, 건물 입구·복도·취업지원센터 원안 |
| 사령 공간 | 탐색 영역과 보스방 분리 규칙. 구역별 상세 설계는 로컬 스텁 |
| 구체 내용 | [챕터1 공간](챕터1공간.md)에서 장소별 자산과 빈칸 확인 |

## 적용할 규칙과 경계

ADR-7의 사령세계 구조와 ADR-10의 현실 사이드뷰·사령 탑다운뷰를 적용합니다. 메인 유품의 획득 위치·구역 개방 순서는 Proposed ADR-11과 스토리 원안 사이에서 검토 중입니다.

## 미결 사항

C-1(획득·공간 개방), C-8(축 완료), C-9(사령 공간 상세)을 확인합니다. 실제 공간 파일 확인 전 새 제작으로 확정하지 않습니다.

## 다음 산출물 — 작업 후보

| 산출물 | 확인할 결과 | 연결되는 영역 |
|---|---|---|
| 첫 공간 동선 러프 | 시작·조사·NPC·충돌·출구 위치가 표시된 한 구간 | 아트·개발 |
| 구역 의존도 | 어떤 유품·행동으로 어느 구역을 열며 돌아오는지 | 진행·개발 |
| 사령 공간 시험안 | 감정 컨셉을 이동·조사·회피 행동으로 옮긴 러프 | 전투·아트 |

담당·마감·작업량은 아직 배정하지 않았습니다. 기존 외부 산출물이 있으면 확인·보완부터 합니다.

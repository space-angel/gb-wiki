# 챕터1 공간과 레벨 설계

**상태: 기획 작성 중·실제 도면/씬 미검증.** 시점 규칙과 공간 원안을 구분합니다.

## 장소별 현황

| 장소 | 현재 원안·규칙 | 남은 상세 |
|---|---|---|
| 건물 입구·복도 | 집주인·이유미를 만나는 현실 공간 원안 | 시작 지점·이동 범위·NPC 위치·조사 대상 |
| 원룸 중문 바깥 | 현관·신발장·화장실·간이주방, 고양이 용품과 메모 | 오브젝트 크기·배치·도달 순서·중문 조건 |
| 원룸 중문 안쪽 | 침대·책상, 무너진 생활의 대비 | 유품 목록 정합성·배치·첫 조사 결과 |
| 취업지원센터 | 상담사를 현실에서 직접 만나는 원안 | 출입·장소 이동·카메라·대화 위치·회상 표현 |
| 사령세계 1~3 | 메트로배니아 탐색·보스방 분리 규칙 | 공간 연결·단서·전투·왕복·완료 조건 |
| 미래축 사령세계 | ‘끝나지 않는 면접’ 컨셉 | 실제 걸으며 조사하고 회피하는 공간 |

7~8평 원룸이라는 설정과 중문 전후 대비는 콘텐츠 원안입니다. 정확한 타일 수·월드 크기·충돌 영역은 확인되지 않았습니다.

## 적용할 시점

- 현실: 사이드뷰.
- 사령세계: 탑다운뷰.
- 전환 시 시점 변화가 드러나는 연출 방향.
- 모두 ADR-10의 챕터1 적용 범위입니다.

자료에 여러 시점의 참고 이미지가 있다는 사실을 게임 시점이 미정이라는 뜻으로 읽지 않습니다. 이미지 원본은 이번에 검증하지 않았습니다.

## 공간 개방에서 맞출 것

메인 유품 동시 발견안과 순차 체인안은 배치의 전제가 다릅니다. [C-1](../09_결정_미결/쟁점목록.md#c-1-유품-획득과-공간-개방)에서 결정 전 상태를 유지합니다.

도면에는 문과 출구뿐 아니라 **열리는 조건과 돌아오는 경로**를 적습니다. 열쇠를 그 열쇠로 열 구역 안에 두는 순환, 판매한 유품 때문에 진행할 수 없는 상황을 검토합니다.

## 첫 공간 러프의 인계 기준 — 제안

| 표시할 것 | 사용하는 쪽 |
|---|---|
| 시작·종료·복귀 위치 | 개발·진행 |
| 걸을 수 있는 범위와 막히는 곳 | 개발 |
| 조사 오브젝트와 NPC 위치 | 스토리·진행 |
| 먼저 보이는 정보와 가려진 정보 | 스토리·아트 |
| 임시 크기·벽/배경 구분 | 아트·개발 |
| 해당 구간에서 생략한 기능 | 시험 참여자 |

현재 파일이 있으면 먼저 대조합니다. 임시 도형으로 동선을 시험할 수 있으므로 최종 배경 제작 완료를 기본 이동 시험의 필수 선행으로 두지 않습니다.

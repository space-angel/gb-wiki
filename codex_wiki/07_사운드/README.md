# 사운드

환경음·효과음·음악의 역할과 재생 조건을 정리합니다. 로컬의 BGM 트랙 리스트·SE 사양·사운드 디렉션 3개 스냅샷은 빈 페이지이며, 실제 음원 보유 여부는 확인되지 않았습니다.

## 현재 자료와 상태

| 항목 | 내용 |
|---|---|
| 톤 원안 | 환경음·생활 소음 중심, 음악은 최소화한다는 참고 방향 |
| 제작물 | 사용할 수 있는 음원·프로젝트 파일 미확인 |
| 제작 범위 | 첫 시험 구간이 정해지면 필요한 소리와 임시 대체 범위 결정 |

## 적용할 규칙과 경계

위 톤은 참고 기획입니다. 확정 ADR인 것처럼 적용하지 않습니다. 특히 오답에 실패 사운드를 주지 않는 규칙은 ADR-14의 제안이며 현재 확정 상태와 구분합니다.

## 미결 사항

C-11(원본 확인), C-12(오답 피드백)를 봅니다. 환경음·발소리·상호작용음은 첫 구간에서 검토할 후보이며 제작 완료나 확정 요구사항이 아닙니다.

## 다음 산출물 — 작업 후보

| 산출물 | 확인할 결과 | 연결되는 영역 |
|---|---|---|
| 기존 사운드 자산 확인 | 파일·제작/출처·사용 가능 범위·용도 목록 | 개발 |
| 첫 구간 소리 목록 | 행동/공간·재생 시작/끝·루프 여부·우선 필요성 | 스토리·공간·개발 |
| 적용 확인 | 대사·조사·이동을 방해하지 않는지 시험 결과 | 전체 시험 참여자 |

담당·마감·작업량은 아직 배정하지 않았습니다. 기존 외부 산출물이 있으면 확인·보완부터 합니다.

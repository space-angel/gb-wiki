# 유품·단서·조사축

**상태: 기획 작성 중·일부 규칙 확정.** 실제 이름과 배치·해금은 원안이며, 아이템 수량·등급은 Accepted ADR의 제약을 따릅니다.

## 수량과 실제 내용의 구분

핵심 3개, 보조 6개, 축당 보조 2개는 ADR-3·15에 근거합니다. 실제 메인 유품 명칭은 스토리의 졸업사진·핸드폰·취준 파일과 ADR-13 제안의 목록이 달라 C-2에서 관리합니다.

## 조사축 원안

| 축 | 메인 유품 원안 | 연결 인물 | 보조유품 원안 | 확인하려는 변화 |
|---|---|---|---|---|
| 과거 | 졸업사진 | 어머니 | 2개 미정 | 보답하려는 마음이 의무·부담이 됨 |
| 현재 | 핸드폰 | 이유미 | 2개 미정 | 단순한 시간 낭비에서 비교·자기비하로 |
| 미래 | 취준 파일 | 상담사 | 면접 일정 다이어리 / 정장+영수증 | 아무것도 하지 않았다는 판단에서 반복된 시도를 인식 |

과거·현재 보조유품은 **로컬 자료상 미정**입니다. 미반영 외부 원문에 이미 작성됐는지 확인한 뒤 새 설계 업무로 잡습니다.

## 미래축에 있는 내용

- 취준 파일: 센터의 존재를 알게 하는 최초 근거.
- 센터 이용 흔적: 개별 보조유품으로 세지 않고 정보단서군으로 묶는 원안.
- 다이어리: 지원·면접·탈락·다음 일정의 반복 기록.
- 정장+영수증: 기록이 실제 생활 속 행동으로 이어졌음을 보강하는 흔적.
- 최종 인식 방향: 포기한 사람이 아니라 쉽게 멈추지 못했던 사람.

원문은 영수증만으로 개별 면접 참석을 확정하지 않도록 합니다. 정보단서군이 인벤토리 아이템인지 별도 기록인지는 미정입니다.

## 진행 규칙과 연결할 것

| 필요한 정의 | 연결 쟁점 |
|---|---|
| 발견·조사·획득·선택이 각각 어떤 행동인지 | C-1, C-5 |
| 아이템과 환경·정보단서의 구분 | C-6 |
| 각 축의 정보가 공유 플래그 또는 축별 진행에 어떻게 기여하는지 | C-4 |
| 첫 축 완료와 나머지 축 개방 조건 | C-8 |
| 보조유품을 팔았을 때 단서·진술·진행이 어떻게 되는지 | C-7 |

# 상태와 진행 조건

**상태: 규칙·제안·설계 공백 혼합.** 이 문서는 현재 차이를 보이기 위한 정리이며 실행 사양을 새로 확정하지 않습니다.

## 구분해서 정의할 상태 — 설계 검토 항목

| 상태 | 답할 질문 |
|---|---|
| 조사 기록 | 무엇을 보거나 읽었는가? 같은 것을 다시 조사하면 달라지는가? |
| 보유·처분 | 현재 가진 유품은 무엇이며 판매 전 기록과 어떻게 다른가? |
| 진술 공개 | 어느 NPC의 어느 대화가 열렸고 이미 들었는가? |
| 이해도 | O/A/V/R 중 무엇을 달성했는가? |
| 구역·조사축 진행 | 어느 공간이 열렸고 어느 축이 완료됐는가? |
| 회상·연출 | 무엇을 봤으며 재생·다시 보기 조건은 무엇인가? |

이 구분은 조건을 논의하기 위한 작업표입니다. 새 모듈·저장 필드·플래그를 이미 채택한 것이 아닙니다.

## O 조건이 다른 세 기록

| 근거 | 내용 | 상태 |
|---|---|---|
| ADR-3·아이템 가이드 | 핵심 3개 전부 발견 + 보조 N개 | Accepted 규칙 |
| ADR-12 | 보조 N개 확보, 판매분 제외 | Proposed |
| 7월 20일 회의록 | 메인 A + 보조 N개로 축소했다는 보고 | 후속 ADR 반영·효력 확인 필요 |

ADR-15는 보조 총량을 6개로 줄였고 N의 상한도 6입니다. **N=6은 확정값이 아닙니다.** O 조건을 바꿀지와 N을 얼마로 할지는 다른 질문입니다. [C-5](../09_결정_미결/쟁점목록.md#c-5-o-조건과-n값)

## 이후 단계

O→A→V→R의 순서 의존은 확정입니다. ADR-12는 유품 제시·회상 확인·4슬롯과 정답 선택을 단계별 트리거로 제안합니다. ADR-4·6의 A단계 가설·핵심 진술 역할과 어떻게 대응하는지까지 함께 검토해야 합니다.

3축마다 독립 플래그를 둘지, 챕터 전체의 한 세트를 채울지 아직 정해지지 않았습니다. 축 하나의 재해석을 곧바로 챕터의 R 완료로 간주하지 않습니다.

## 보드와 오답

- 4슬롯과 3지선다 기본 구조는 Accepted입니다.
- 최종 판정 시점·충족 조건은 ADR-12 제안과 연결됩니다.
- ADR-14는 무제한 재시도, 오답 배치만 초기화, 진행 보존, 명시적 실패 피드백 없음 등을 제안합니다.
- 오답 이후 보존 규칙을 판매 이후 규칙으로 확대하지 않습니다.

## 판매·보스·종결

성불·제령·소멸 방향은 존재하지만 모든 중간 상태와 행동의 결과가 정리되지 않았습니다. 다음 사례를 하나의 표로 확인해야 합니다.

| 사례 | 정할 결과 |
|---|---|
| O 이전에 판매 | 관찰 달성 가능성과 다른 진행 경로 |
| A/V 이후에 판매 | 이미 얻은 이해·진술·회상·구역의 유지 또는 재판정 |
| 오답 제출 | 무엇이 닫히고 무엇이 남으며 다시 시도하는 방법 |
| R 미달 보스 진입 | 싸움·패배·승리·복귀·종결 가능 범위 |
| 첫 축만 조사 | 어디까지 완료이며 나머지 축은 언제 열리는지 |

## 첫 구간 진행표 틀

**행동 전 상태 → 플레이어 행동 → 얻는 정보 → 상태 변화 → 새로 가능한 행동 → 예외·되돌아오기** 순으로 씁니다.

일부 조건을 생략한 시험은 생략 범위를 표시합니다. 조건부 대사가 동작하는 것과 추리·재해석 전체를 검증한 것을 구분합니다.

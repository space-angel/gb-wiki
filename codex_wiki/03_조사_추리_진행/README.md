# 조사·추리·진행

플레이어가 무엇을 조사하고, 어떤 증거로 가설을 만들고, 무엇이 달라지는지를 연결합니다. 진행 규칙이 아직 일관된 한 표로 정리되지 않은 상태입니다.

## 현재 자료와 상태

| 항목 | 내용 |
|---|---|
| 콘텐츠 | [조사축](조사축.md): 과거·현재·미래의 유품·단서·재해석 원안 |
| 조건 | [상태와 진행](상태와진행.md): O/A/V/R·보드·판매·종결의 경계 |
| 현재 빈칸 | O 조건, 축별/챕터별 플래그, 첫 축 완료, 판매 이후 상태 |

## 적용할 규칙과 경계

4플래그·2등급 아이템·3지선다·4슬롯은 Accepted ADR에 근거합니다. 구체 판정·획득 순서·오답 처리는 제안 또는 검토 대상입니다.

## 미결 사항

[쟁점 목록](../09_결정_미결/쟁점목록.md) C-1~8과 연결됩니다. 기본 상호작용 시험에 필요한 결정과 전체 게임 구현 전 필요한 결정을 구분합니다.

## 다음 산출물 — 작업 후보

| 산출물 | 확인할 결과 | 연결되는 영역 |
|---|---|---|
| 첫 구간의 진행표 | 행동 전 상태 → 행동 → 획득 정보 → 상태 변화 → 다음 행동 | 스토리·공간·개발 |
| 유품·단서 대장 | 명칭·종류·발견/획득·판매·진술 연결과 원문 | 아트·개발 |
| 분기 확인표 | 조사를 덜 함·판매·오답·조기 보스 진입의 결과 | 전투·개발 |

담당·마감·작업량은 아직 배정하지 않았습니다. 기존 외부 산출물이 있으면 확인·보완부터 합니다.

# 공통 규칙과 제안의 경계

아래 표는 로컬 Accepted ADR에 근거한 규칙 요약입니다. **구체 콘텐츠와 모든 진행 조건까지 확정됐다는 뜻은 아닙니다.** 원문·상태는 [ADR 목록](../09_결정_미결/ADR목록.md)에서 확인합니다.

## 확정 규칙

| 주제 | 기준 | 근거 |
|---|---|---|
| 이해도 의미 | 고인의 삶과 감정에 대한 인식 변화량. 수집량만으로 전체 이해를 대체하지 않음 | ADR-1 |
| 플레이어 능력 | 이해도로 플레이어 데미지·체력·공속 등 스탯을 강화하지 않음 | ADR-1 |
| 노출 | 이해도 수치를 플레이어에게 직접 노출하지 않음 | ADR-1 |
| 내부 표현 | O→A→V→R 네 boolean, 이전 단계가 다음 단계의 전제 | ADR-2 |
| 출력 범위 | 보스 패턴 가시성·종결 선택지. 잡몹은 이해도 영향 제외 | ADR-9가 ADR-1 일부 개정 |
| 아이템 | 핵심 3개 판매 불가, 보조 6개 판매 가능. 조사축마다 보조 2개 | ADR-3, ADR-15 |
| O의 기존 규칙 | 핵심 3개 전부 발견 + 보조 N개. 변경 제안과 충돌 중이며 N은 미정 | ADR-3; C-5 |
| 가설 | 3지선다: 정답 1개 + 서로 다른 방향의 그럴듯한 오답 2개 | ADR-4 |
| 보드 | 메인 유품·보조 유품·진술·추리의 4슬롯 구조 | ADR-5 |
| 핵심 진술자 | A/V 분리, 각 최소 2명. 실제 NPC 배정은 미결 | ADR-6; C-3 |
| 사령세계 | 메트로배니아 구조, 탐색 영역과 분리된 보스방, 첫 진입부터 도전 가능 | ADR-7 |
| 전투 | 가벼운 톤, 방어 수단은 회피, 패링·가드 제외 | ADR-8 |
| 시점 | 챕터1 현실은 사이드뷰, 사령세계는 탑다운뷰 | ADR-10 |

보스 도전 시점에 관한 ADR-2의 O 이후 표현과 ADR-7의 첫 진입 표현은 [C-10](../09_결정_미결/쟁점목록.md#c-10-보스-진입결과와-종결)에서 함께 추적합니다. 특정 유품 획득 순간과의 대응은 ADR-11 제안입니다.

## 확정으로 읽으면 안 되는 내용

| 문서·내용 | 현재 상태 | 왜 확인이 필요한가 |
|---|---|---|
| ADR-11 공간 개방 | Proposed | 순차 획득과 동시 노출 원안이 다름 |
| ADR-12 판정 규칙 | Proposed | O 조건과 A/V/R 행동 매핑이 기존 규칙과 달라짐 |
| ADR-13 구현 계층 | Proposed | 단서별 대화 해금과 참조 제약의 관계 확인 필요 |
| ADR-14 오답 처리 | Proposed | 재시도·배치 초기화·실패 피드백의 제안 |
| 메인 유품 명칭·NPC별 배정·대사 | 기획 작성 중 | 작성자 원안과 시스템 문서가 완전히 맞춰지지 않음 |
| 픽셀 규격·맵·보스 패턴 | 자료 존재 또는 미확인 | 현재 프로젝트 적용·제작 준비 여부는 별도 검증 |

보조 수량을 6개로 바꾼 ADR-15는 **수량 조항만 개정**했습니다. 이를 근거로 O 정의·N값·판매 이후 플래그까지 바꿀 수는 없습니다.

## 첫 실험에서의 사용

실험에서 단서를 적게 쓰거나 상태를 디버그로 주입할 수는 있지만, 이를 정식 O/A/V/R 달성이나 챕터 완료로 기록하지 않습니다. 시험 범위와 생략한 조건을 명시합니다.

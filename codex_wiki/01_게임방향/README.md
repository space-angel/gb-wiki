# 게임 방향

현실의 유품과 진술, 사령세계의 단서를 통해 고인에 대한 첫 판단을 수정하고 사건의 종결에 이르는 게임입니다. 기본 규칙은 ADR에 있고, 구체적인 플레이 흐름은 기획 중입니다.

## 현재 자료와 상태

| 항목 | 내용 |
|---|---|
| 핵심 경험 | 수집량보다 인식 변화, 플레이어 스탯 강화보다 종결 방식의 변화 |
| 세계관 원안 | 기록관·유품·사령·현실과 사령세계에 관한 설정 문서 존재 |
| 범위 | 현재 정리 대상은 챕터1. 이후 챕터와 외부 마감은 새 로드맵에서 확인 |

## 적용할 규칙과 경계

[공통 규칙](공통규칙.md)에서 Accepted와 Proposed를 구분합니다. 세계관·사건·연출 원안은 사용자 설명에 따라 작성 중인 기획으로 취급합니다.

## 미결 사항

첫 실험의 범위는 미정입니다. 상세 기획을 완성 게임의 동작으로 설명하지 않습니다.

## 다음 산출물 — 작업 후보

| 산출물 | 확인할 결과 | 연결되는 영역 |
|---|---|---|
| 첫 실험의 질문 | 어떤 플레이어 행동과 인식 변화를 확인할지 한 문장으로 제시 | 스토리·진행·개발 |
| 첫 실험의 범위 | 포함할 장소·NPC·행동과 끝 지점을 표시 | 전체 영역 |

담당·마감·작업량은 아직 배정하지 않았습니다. 기존 외부 산출물이 있으면 확인·보완부터 합니다.

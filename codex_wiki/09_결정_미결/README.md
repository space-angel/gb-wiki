# 결정·미결

확정된 규칙의 근거와 영역 간 설계 차이를 추적합니다. 정리 문서가 늘어나도 같은 질문을 중복해서 새 작업으로 만들지 않도록 연결합니다.

## 현재 자료와 상태

| 항목 | 내용 |
|---|---|
| 결정 원장 | [ADR 목록](ADR목록.md): Accepted 11건·Proposed 4건 |
| 검토할 질문 | [쟁점 목록](쟁점목록.md): 기존 C-1~4를 유지하고 진단에서 찾은 공백 연결 |
| 우선순위 | 현재 만들 구간에 영향을 주는 항목부터 검토. 전체 항목 일괄 확정은 선행 조건이 아님 |

## 적용할 규칙과 경계

Accepted 규칙과 명백히 다른 옛 요약은 근거에 맞춰 정리합니다. 설계 선택이 필요한 경우에는 양쪽 안과 영향을 남기며 임의로 확정하지 않습니다.

## 미결 사항

담당자·마감은 새 로드맵에서 정합니다. 이 목록에 있다는 이유만으로 즉시 착수할 이슈나 승인된 정책이 되지 않습니다.

## 다음 산출물 — 작업 후보

| 산출물 | 확인할 결과 | 연결되는 영역 |
|---|---|---|
| 결정에 필요한 비교 | 질문·현행 규칙·대안·영향·시험할 방법 | 관련 영역 |
| 결정 반영 | 결정문과 영향을 받는 진행표·콘텐츠·구현 사양에 반영 | 관련 영역 |
| 열린 질문 정리 | 필요한 시점과 해당 산출물 연결, 중복 질문 병합 | 로드맵 |

담당·마감·작업량은 아직 배정하지 않았습니다. 기존 외부 산출물이 있으면 확인·보완부터 합니다.

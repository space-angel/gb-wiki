# 전투 규칙과 보스 시험

**상태: 전투 방향 확정·구체 패턴과 결과 기획 중·구현 미검증.**

## 확정 방향

ADR-8은 가벼운 전투, 회피의 무적 판정과 캔슬, 패링·가드 제외를 규정합니다. 잡몹은 단순한 평타 처리 방향이며 깊이 있는 전투는 보스에 집중합니다.

ADR-9에 따라 이해도는 잡몹을 약화하지 않습니다. 보스에서 패턴을 읽는 방식과 종결에 영향을 주며 플레이어 스탯을 올리지 않습니다.

## 아직 정해지지 않은 것

| 항목 | 필요한 답 |
|---|---|
| 보스 1종의 패턴 | 예고·공격 범위·회피 타이밍·피격·패턴 종료 |
| 처치·해소 방식 | 플레이어의 어떤 행동으로 싸움이 끝나는가 |
| 패턴 가시성 | 이해 상태별 무엇을 얼마나 먼저 보여주는가 |
| 조기 진입 | O/R 등 진행이 부족할 때 가능한 행동과 결과 |
| 패배·철수·재도전 | 복귀 위치·유지 상태·다시 시작하는 방법 |
| 종결 연결 | 전투 결과·진행 상태·유품 처분이 어떤 종결로 이어지는가 |

‘회피만’은 방어 수단에 대한 규칙입니다. ‘공격 없음’ 또는 ‘피하기만 하면 승리’로 확대 해석하지 않습니다.

프롤로그에서 첫 사령에게 반드시 패배한다는 내용은 스토리 진행 원안입니다. 모든 보스의 첫 전투에 적용하는 확정 규칙이 아닙니다.

## 첫 패턴 시험안의 작성 항목

**검증할 행동 / 적의 예고 / 공격 판정 / 플레이어의 대응 / 성공·실패 결과 / 재시작 / 임시 표현**을 한 묶음으로 적습니다.

패턴 수·수치·아트 분량은 지금 새로 확정하지 않습니다. 먼저 한 패턴으로 회피와 예고가 읽히는지 확인하는 작업 후보입니다.

## 연결되는 결정

- C-9: 사령 공간에서 전투가 어디에 놓이는가.
- C-10: 보스 진입과 R 미달 결과, 종결의 중간 상태.
- C-11: 실제 아트·애니메이션 규격과 적용 파일.

# 전투·보스

회피 중심 전투와 이해에 따른 보스 변화, 승패·복귀·종결의 연결을 다룹니다. 톤은 정해졌지만 실행 가능한 전투는 확인되지 않았습니다.

## 현재 자료와 상태

| 항목 | 내용 |
|---|---|
| 방향 | 가벼운 전투, 방어는 회피 중심, 패링·가드 제외 |
| 보스 | 이해도에 따라 패턴을 읽는 방식과 종결이 달라짐 |
| 구체 설계 | [전투 설계](전투설계.md): 규칙·미결·시험 항목 |

## 적용할 규칙과 경계

ADR-8·9가 중심입니다. ‘회피만’은 방어 수단에 대한 규칙이며 공격 없는 게임이나 회피만으로 보스를 처치하는 규칙으로 확대하지 않습니다.

## 미결 사항

C-7(판매·상태)과 C-10(보스 결과·종결)을 확인합니다. 프롤로그의 강제 패배는 스토리 원안이며 일반 보스전 규칙과 분리합니다.

## 다음 산출물 — 작업 후보

| 산출물 | 확인할 결과 | 연결되는 영역 |
|---|---|---|
| 보스 패턴 1종 시험안 | 예고·공격·회피·피격·종료 조건을 재현 가능하게 정의 | 아트·개발 |
| 전투 결과표 | 패배·재도전·철수·R 미달 승리 후 흐름 | 진행·스토리 |
| 가시성 비교안 | 이해 상태별 무엇이 언제 보이는지 비교 | 아트·UI·개발 |

담당·마감·작업량은 아직 배정하지 않았습니다. 기존 외부 산출물이 있으면 확인·보완부터 합니다.

# 아트·UI

캐릭터·배경·오브젝트·화면·연출과 게임 적용 규격을 다룹니다. 참고 문서와 픽셀 규격안은 있지만 현재 재사용 가능한 원본 파일과 적용 화면은 미확인입니다.

## 현재 자료와 상태

| 항목 | 내용 |
|---|---|
| 참고 자료 | 무드·아트 제작 가이드, PPU/해상도 문서 |
| UI | 대화·인벤토리·보드 관련 페이지 다수가 로컬 빈 스냅샷 |
| 실제 자산 | [제작 현황](제작현황.md): 파일을 확인해 채울 항목과 인계 기준 |

## 적용할 규칙과 경계

ADR-10의 시점, ADR-1의 이해도 수치 비노출, ADR-3의 아이템 등급 표기 제한, ADR-5의 보드 4슬롯을 참조합니다. 오답 피드백 금지 규칙은 ADR-14 Proposed이므로 별도 표시합니다.

## 미결 사항

C-11(원본·규격 확인)을 봅니다. 픽셀 수치가 적힌 문서만으로 현재 프로젝트 설정이 동일하다고 간주하지 않습니다.

## 다음 산출물 — 작업 후보

| 산출물 | 확인할 결과 | 연결되는 영역 |
|---|---|---|
| 기존 에셋 목록 | 원본 경로·용도·버전·크기·게임 적용 여부 | 개발·공간 |
| 첫 화면 러프 | 이동·조사 대상·대사 가독성을 확인할 화면 | 기획·개발 |
| 첫 구간 제작 규격 | 실측 크기·레이어·피벗·내보내기와 적용 샘플 | 개발 |

담당·마감·작업량은 아직 배정하지 않았습니다. 기존 외부 산출물이 있으면 확인·보완부터 합니다.

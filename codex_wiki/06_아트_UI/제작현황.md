# 아트·UI 제작 자료와 인계

**상태: 자료 확인 단계.** 실제 에셋이 없다고 단정한 목록이 아닙니다. 원본 이미지·작업 파일과 Unity 적용 상태는 미검증입니다.

## 로컬에서 확인한 자료

| 자료 | 내용 | 현재 해석 |
|---|---|---|
| 아트 폴더 | 7문서 중 빈 스냅샷 5개, 참고 가이드·폴더 목록 | 실제 원본 파일 수·완료율로 사용할 수 없음 |
| UI 폴더 | 10문서 중 빈 스냅샷 8개, 나머지는 하위 목록 | 대화창·인벤토리·보드 시안 별도 확인 필요 |
| 톤·무드 | 저채도·공허함·생활 흔적·절제된 연출 등의 원안 | 참고 기획, 제작 승인 여부 별도 |
| PPU 문서 | 픽셀·타일·해상도 값이 적힌 규격안 | 현재 프로젝트와 맞는지 미확인 |
| 7월 23일 회의 자료 | 에셋 제작 순서와 소요시간 측정 가이드 | 제작 완료 증거가 아닌 작업 안내 |

## 기존 픽셀 규격 문서에 적힌 값

| 항목 | 기록된 값 |
|---|---|
| 타일 | 32×32 |
| PPU | 32 |
| 캐릭터 기본 크기 | 32×48 |
| NPC·오브젝트 기본 크기 | 32×32 |
| 내부 해상도 | 640×360 |
| 출력 해상도 | 1920×1080, 정수 배율 |

위 값은 과거 문서의 기록입니다. 새 제작 규격으로 승인하거나 현재 에디터 설정과 일치한다고 판정하지 않았습니다.

## 실제 자산 확인표 틀

| 항목 | 기록할 내용 |
|---|---|
| 원본·버전 | 실제 작업 파일 경로와 마지막 변경 |
| 사용 위치 | 어느 공간·인물·화면에 쓰는가 |
| 제작 상태 | 러프·작업 중·검토 가능 등 실제 상태 |
| 규격 | 크기·레이어·피벗·애니메이션 등 해당 자산에 필요한 것 |
| 적용 상태 | 미적용·적용 미검증·빌드에서 확인 |
| 다음 조치 | 재사용·수정·새 제작과 이유 |

이 목록을 실제 파일로 채운 뒤 제작량을 산정합니다. 가이드에 있는 예시 에셋 수를 곧바로 확정 물량으로 삼지 않습니다.

## UI에서 지킬 것과 검토할 것

| 내용 | 상태 |
|---|---|
| 이해도 숫자·게이지로 진행을 직접 보여주지 않음 | ADR-1 확정 |
| 아이템 자체에 핵심/보조 등급 표시를 두지 않음, 보드 슬롯으로 구분 | ADR-3 확정 |
| 재구성 보드 4슬롯·가설 3지선다 | ADR-4·5 확정 |
| 오답의 명시적 실패 피드백 없음 | ADR-14 제안 |
| 대화 카드·조사 표시·인벤토리·보드의 실제 레이아웃 | 작성·검토 필요 |

## 첫 적용 샘플 — 작업 후보

첫 구간의 공간 러프와 텍스트를 받아 **오브젝트 구분·글자 가독성·조사 반응·이동 범위**를 같은 화면에서 확인합니다. 최종 타일·캐릭터 애니메이션 전체 제작보다 먼저 규모와 전달 방식을 맞춥니다.

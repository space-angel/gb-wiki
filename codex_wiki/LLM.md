# codex_wiki 에이전트 안내

## 읽는 순서

[위키 홈](README.md) → 해당 영역 README → 필요한 상세 문서 → 연결된 원문 순서로 읽는다. 현재 운영·기획 설명은 이 위키를 진입점으로 삼고, 기존 문서는 고정된 Git 이력 링크에서 출처로 확인한다. 이전 폴더는 현재 브랜치에 없다.

## 현재 전제

- 2026-09-08 사용자 확인: 플레이 가능한 빌드 없음. 기획은 작업 중.
- ADR-1~10 및 15는 로컬 파일상 Accepted, ADR-11~14는 Proposed.
- Accepted 문서 안의 예시·Open Question·잠정 매핑까지 확정으로 취급하지 않는다.
- ADR-9의 출력 범위 개정, ADR-15의 보조유품 수량 개정을 반영한다.
- 빌드 없음과 코드·아트 없음은 다르다. 기존 구현·에셋 재사용 여부는 미검증이다.
- 기존 로드맵들은 폐기됐다. [현황 진단과 개편 기준](00_문서운영/현황진단과_개편기준.md)에서 새 계획을 구성한다.
- 기존 위키와 raw의 과거 날짜·담당·완료 표기를 현재 운영 사실로 승계하지 않는다.

## 갱신 규칙

[작성 규칙](00_문서운영/작성규칙.md)을 따른다. 규칙·작업 상태·검증 상태를 구분하고, 원문 링크와 대조 범위를 남긴다.

- 새 충돌은 쟁점 목록에 근거와 영향을 기록한다. 조용히 한쪽을 확정하지 않는다.
- 문서 이동·편집일을 외부 원본의 최신 확인일로 쓰지 않는다.
- 이전 커밋의 역사적 기록을 현재 사실로 고쳐 쓰지 않는다. 자료의 시점은 [출처와 개편 이력](00_문서운영/출처와개편이력.md)을 확인한다.
- 이 위키의 제안은 이슈 발행·담당 배정·마감 합의가 아니다.
- 새 문서의 링크는 상대 경로를 쓰고 존재 여부를 확인한다.

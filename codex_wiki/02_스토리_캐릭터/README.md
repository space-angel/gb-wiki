# 스토리·캐릭터

김태현 사건, 인물의 관점, 대사와 감정 흐름을 다룹니다. 사건·NPC 시트와 상담사 상세 대본이 있지만 모두 작성 중인 기획 자산입니다.

## 현재 자료와 상태

| 항목 | 내용 |
|---|---|
| 사건 | [챕터1 원안](챕터1.md): 책임·기대·고립·재해석 |
| 인물 | [NPC 기획](NPC.md): 관리인·집주인·이유미·상담사·어머니 |
| 상세 대본 | 상담사 대본과 회상 4개 존재. 최종 투입 범위·조건은 검토 필요 |

## 적용할 규칙과 경계

ADR-6의 A/V 핵심 진술자 분리 규칙을 참조합니다. 인물별 실제 배정은 미해결입니다. 이야기의 감정 단계와 시스템 플래그를 같은 것으로 간주하지 않습니다.

## 미결 사항

[쟁점 목록](../09_결정_미결/쟁점목록.md)의 C-2(유품), C-3(NPC), C-4(플래그 범위), C-6(대화 해금), C-8(축 완료)를 함께 봅니다.

## 다음 산출물 — 작업 후보

| 산출물 | 확인할 결과 | 연결되는 영역 |
|---|---|---|
| 첫 구간의 대사·조사 텍스트 | 사용할 텍스트, 화자, 공개 조건, 원문 출처 | 진행·개발 |
| NPC별 정보 공개표 | 각 단계에서 아는 사실·말하는 사실·새로운 단서를 구분 | 진행·공간 |
| 나머지 축의 콘텐츠 | 기존 외부 산출물을 확인한 뒤 보조유품·진술의 빈칸 보완 | 아트·진행 |

담당·마감·작업량은 아직 배정하지 않았습니다. 기존 외부 산출물이 있으면 확인·보완부터 합니다.

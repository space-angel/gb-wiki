# codex_wiki

게임 프로젝트 ATK_DEF의 **영역별 작업 위키**입니다. 각 영역에서 현재 자료, 확정 규칙, 작업 중인 기획, 미결 사항, 다음에 필요한 산출물을 확인합니다.

**현재 기준(2026-09-08): 플레이 가능한 빌드는 없고, 기획은 작업 중입니다.** 로컬 ADR은 Accepted 11건, Proposed 4건입니다. 기획 문서가 존재한다는 이유로 제작 완료로 표시하지 않습니다.

## 처음 읽는 순서

1. [게임 방향](01_게임방향/README.md)에서 전체 의도를 확인합니다.
2. 자기 작업과 관련된 영역의 README를 엽니다.
3. 해당 영역의 미결 사항을 [쟁점 목록](09_결정_미결/쟁점목록.md)과 대조합니다.
4. 실제 문서를 쓸 때 [작성 규칙](00_문서운영/작성규칙.md)을 사용합니다.

에이전트가 작업할 때는 [LLM 안내](LLM.md)에서 출처·상태 판단과 영역별 읽기 경로를 확인합니다.

영역은 담당자를 고정하는 분류가 아닙니다. 예를 들어 NPC 대사 내용은 스토리, 대사가 열리는 조건은 진행, 화면 표시는 UI, 동작 확인은 개발에서 연결합니다.

## 로드맵과의 관계

로드맵은 [현황 진단과 개편 기준](00_문서운영/현황진단과_개편기준.md)을 바탕으로 [codex_sprint](../codex_sprint/README.md)에 구성했습니다. 이전 스프린트·장면·담당별 계획·Linear 운영 초안은 폐기됐습니다.

이 위키의 **다음 산출물은 영역별 작업 후보**입니다. 실제로 등록한 첫 이슈 7건은 [등록 결과](../codex_sprint/신규이슈_초안.md)에서 확인하고, 현재 담당·진행 상태는 Linear에서 관리합니다.

## 자료를 읽을 때의 기준

| 구분 | 해석 |
|---|---|
| ADR 확정 | Accepted이며 후속 개정까지 반영한 규칙 |
| ADR 제안 | Proposed. 채택된 규칙으로 단정하지 않음 |
| 기획 작성 중 | 기존 대본·시트·도면 설명 등. 팀 합의·제작 준비와 별개 |
| 구현 미검증 | 과거 구현 보고는 있지만 현재 실행을 확인하지 않음 |
| 자료 미확인 | 로컬에 내용·파일이 없거나 외부 원본을 확인하지 못함 |

정리일은 2026-09-08입니다. 위키 작성에는 8월 17일 로컬 대조 자료와 9월 7일 미래축·상담사 부분 반영 자료를 사용했습니다. 게시 준비 중 원격 저장소의 **8월 21일 추가 대조 기록**도 확인했습니다. 미반영 변경분 32건은 로컬 기록 당시의 수치이며, 빈칸을 곧바로 새 제작 업무로 잡지 않습니다. [자료 확인 시점과 개편 이력](00_문서운영/출처와개편이력.md)

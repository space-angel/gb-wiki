# codex_sprint

**2026-09-08 회의용 개편안.** 새 로드맵과 신규 이슈 기준입니다. 사용자와 합의한 컨벤션으로 첫 이슈 7건을 Linear에 등록했습니다. 프로젝트·마일스톤·사이클과 팀 상태 설정은 아직 변경하지 않았습니다.

첫 목표는 **팀원이 직접 실행해서 이동·조사·대화 변화를 확인하는 작은 실행 파일(빌드) 하나**입니다. 그다음에는 조사한 정보로 고인에 대한 해석이 바뀌는 짧은 추리 경험을 검증합니다.

회의에서는 첫 세 문서를 중심으로 봅니다. 컨벤션은 첫 이슈 7건에 적용했고, 남은 팀 설정과 사이클의 작업량을 맞춥니다.

## 이번 개편의 기준

- 팀의 공통 목표는 한 번에 하나. 각자는 그 목표에 필요한 결과물 하나에 먼저 집중합니다.
- 전체 기획 완료를 첫 구현의 선행 조건으로 잡지 않습니다. 해당 실험에 필요한 조건을 정하고, 정식 게임 규칙과 실험용 가정을 구분합니다.
- 현재와 바로 다음 단계만 이슈 수준으로 구체화합니다. 먼 단계는 로드맵의 결과·진입 조건으로 관리합니다.
- 기존 이슈를 복원·이관하는 계획은 사용하지 않습니다. 아래 `NS-01` 같은 번호는 **신규 초안의 로컬 번호**이며 실제 Linear 번호가 아닙니다.
- 새 이슈 체계가 기존 코드·그림·대본의 폐기를 뜻하지는 않습니다. 현재 출발점을 확인하고 필요한 결과를 새 기준으로 정의합니다.

등록 후 이 폴더의 이슈 초안에는 Linear 링크만 연결하고, 진행 상태를 양쪽에 중복 기입하지 않습니다. 합의된 게임 규칙은 위키에 반영하고 이슈에서 연결합니다.

**현재 위치:** 컨벤션 협의와 첫 이슈 등록 완료 → 오늘 회의에서 첫 소재·가용 시간 확인 → 약속할 이슈만 사이클에 배정 → 연결 권한이 준비되면 프로젝트·마일스톤·상태 설정 적용.

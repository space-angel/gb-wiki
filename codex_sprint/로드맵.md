# 새 로드맵 — 실행 확인에서 데모까지

**단계는 결과를 뜻하며 스프린트 번호와 일치하지 않습니다.** 한 단계가 여러 사이클에 걸릴 수 있습니다. 날짜는 실제 가용 시간과 첫 실험 결과를 확인한 뒤 정합니다.

기준: [현황 진단과 개편 기준](../codex_wiki/00_문서운영/현황진단과_개편기준.md), [영역별 위키](../codex_wiki/README.md). 폐기한 일정·장면 번호·기존 이슈 배정을 승계하지 않은 신규 구성입니다.

## 단계별 결과와 진입 조건

| 단계 | 팀이 얻을 결과 | 다음으로 넘어갈 증거 | 중심 역할 / 주요 질문 |
|---|---|---|---|
| **M0 출발점과 첫 실험 정의** | 실행 경로, 작은 실험의 행동표·텍스트·화면 러프 | 현재 실행 가능 여부와 차단 원인이 분명하고, 첫 구간의 입력과 결과를 네 사람이 같은 뜻으로 이해 | 호윤 실행, 지호 규칙, 재화 텍스트, 정인 화면 / C-11과 해당 구간의 C-6 |
| **M1 첫 조사 플레이** | 이동 → 조사 → NPC 반응 변화 → 다시 시작 | 개발자 외 팀원 3명이 같은 빌드를 실행해 위 순서를 재현. 진행 불가 오류 해소 | 호윤 통합, 지호 검토, 재화·정인 수정 / NS-05~07 |
| **M2 짧은 추리·재해석 플레이** | 정보 → 가설 선택 → 다른 진술로 검증 → 해석 변화의 짧은 흐름 | 플레이어가 어떤 증거로 생각이 바뀌었는지 설명하고, 정답·오답·재시도 경로가 재현됨 | 지호 규칙, 재화 증거·진술, 정인 보드/UI, 호윤 통합 / C-3~6·C-12 |
| **M3 세계·전투·처분 연결** | 현실↔사령의 작은 왕복 구간, 전투, 보조유품 처분의 결과 | 출입·복귀, 승패·철수, 판매 전후 상태와 저장/복원이 합의한 표대로 동작 | 지호 진행·전투, 재화 상황·공간, 정인 시각, 호윤 통합 / C-1·2·7·9·10 |
| **M4 챕터1 범위 통합** | 합의한 챕터1 조사축·NPC·공간·보스·종결 연결 | 시작부터 합의한 종결까지 진행 가능. 중간 저장·복원 후에도 막히지 않음 | 전원 / C-4·8·10, 남은 콘텐츠·사운드 |
| **M5 데모 마감과 전달** | 온보딩·가독성·오류 수정·배포 패키지 | 팀 밖의 대상 테스터가 안내에 따라 설치·시작·플레이 가능. 알려진 제한과 결과 기록 | 호윤 빌드, 지호 검수, 재화 안내, 정인 UI·표현 |

M0에서는 각자의 준비를 병행할 수 있습니다. M1 구현도 준비된 입력부터 시작합니다. M2 이후의 본격적인 제작은 앞 단계의 결과를 확인한 뒤 범위를 잠급니다.

## M2에서 확인할 핵심

M1의 조사에 따른 대화 변화는 구현 연결을 확인합니다. M2에서는 **왜 플레이어의 생각이 달라지는지**를 확인해야 합니다.

1. 재화가 처음의 인상, 이를 의심하게 하는 정보, 나중의 해석을 연결합니다.
2. 지호가 그 흐름과 A/V/R·플래그 범위·재시도 규칙의 관계를 명시합니다.
3. 종이 또는 화면 러프로 먼저 플레이해 정보가 충분한지 확인합니다.
4. 호윤과 정인이 합의한 작은 흐름을 구현·표현합니다.

Accepted ADR의 가설 3선택지·재구성 보드 4슬롯·A/V 핵심 진술자 분리 및 각 2명 이상 조건을 검토합니다. 시험을 작게 만든다는 이유로 규칙을 조용히 바꾸지 않습니다. 필요한 규칙 개정은 제안·채택을 명시하고, 축소 실험은 전체 시스템 검증과 구별합니다.

## M3는 한 번에 거대한 통합 이슈로 만들지 않기

실제 착수 때 `왕복 이동 → 작은 전투 → 처분·상태·복원`으로 결과를 나누고, 각각 검증 가능한 단위로 발행합니다. 보스 첫 접근·승패·철수와 O/A/V/R의 관계는 구현 전에 상태표로 정합니다. 회피 중심 전투를 공격 없는 전투로 해석하지 않습니다.

저장 기능이 M2 검증에도 필요해지면 필요한 상태만 앞당겨 작업합니다. 전체 판매·엔딩 규칙을 정하기 전에 최종 저장 구조를 고정하지 않습니다.

## 일정과 범위를 바꾸는 기준

- M0 실행 경로가 막힘: 복구의 구체 작업과 예상량을 확인하고 M1 범위를 줄입니다. 프로젝트를 새로 만드는 것은 확인 결과에 따른 별도 선택입니다.
- M1 이동·조사만 됨: 달성한 결과와 남은 대화 작업을 나눠 기록합니다. 원래 목표 전체를 완료로 처리하지 않습니다.
- M2에서 추리가 전달되지 않음: 정보·진술·가설 연결을 수정합니다. 다음 공간이나 아트를 늘려 해결하려고 하지 않습니다.
- M3에서 처분·보스·종결이 충돌함: 충돌한 상태 전이부터 해결하고 콘텐츠 확대를 보류합니다.
- 외부 마감이 정해짐: M4의 콘텐츠 범위를 역산해 줄입니다. 아직 합의되지 않은 전체 챕터 물량을 데모 약속으로 사용하지 않습니다.

각 단계의 날짜가 생겨도 **Linear의 이슈 완료 비율만으로 단계 통과를 판정하지 않습니다.** 위 표의 실행·플레이 증거를 함께 확인합니다.

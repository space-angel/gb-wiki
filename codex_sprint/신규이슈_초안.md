모두 새로 작성한 작업이며 기존 Linear 이슈를 복원하거나 이관하지 않았습니다. **NS-01~07은 2026-09-08에 GBG-247~253으로 등록**, NS-08~10은 다음 단계 초안으로 남겼습니다. `NS` 번호는 이 문서에서 찾기 위한 번호입니다.

제목은 `[파트] 구체적인 작업`, 본문은 사용자와 논의한 네 항목을 적용했습니다. 첫 실험 소재인 **물그릇·이유미와 조사 후 대화 변화는 아직 제안**입니다. 오늘 회의에서 다른 소재를 고르면 등록한 NS-02~07의 설명도 함께 바꿉니다.

## NS-01 · [개발] 현재 프로젝트의 실행 상태와 빌드 방법 확인

Linear: [GBG-247](https://linear.app/wozz/issue/GBG-247) · 담당: 송호윤 · 상태: 할 일

### 왜 필요한지

지금 어디까지 실행되는지 알아야 첫 조사 구간의 작업량을 정할 수 있어요. 다른 친구들도 켜볼 수 있는 실행 파일을 어떻게 만들지 먼저 확인하려고 해요.

### 할 일

- 실제 개발 저장소와 사용하는 Unity 버전, 시작할 장면을 확인해주세요.
- 프로젝트를 실행하고 현재 되는 동작과 막히는 오류를 적어주세요.
- 공유할 대상 운영체제를 정하고 시험 실행 파일을 만들어보세요. 실패하면 오류가 나는 순서와 다음에 해결할 일을 남겨주세요.

### 완료 기준

- [ ] 프로젝트 위치·버전·여는 순서를 보고 같은 상태를 다시 확인할 수 있어요.
- [ ] 실행된 화면과 시험 파일이 있거나, 실행/빌드를 막는 오류와 재현 순서가 있어요.
- [ ] 지호가 현재 가능한 범위와 먼저 해결할 일을 확인했어요. 오류가 남았다면 NS-05 착수 전에 해결해야 한다고 표시했어요.

### 참고·인계

- 참고: [현재 구현 현황](../codex_wiki/08_개발_통합/구현현황.md). 과거 완료 보고와 현재 실행 상태를 구분해주세요.
- 전달: 저장소의 실행 안내와 시험 파일 위치를 지호에게 공유해주세요. 실행 파일을 못 만들었다면 오류 화면·로그 위치를 연결해주세요.
- 막히면: 프로젝트 접근은 현재 저장소 관리자에게, 목표 축소는 지호와 상의해주세요. 확인 없이 프로젝트 전체를 새로 만드는 범위까지 늘리지 않아요.

<a id="ns-02"></a>
## NS-02 · [기획] 첫 조사 구간의 행동과 반응 정리

Linear: [GBG-248](https://linear.app/wozz/issue/GBG-248) · 담당: 안지호 · 상태: 할 일

### 왜 필요한지

재화는 대사를, 정인은 화면을, 호윤은 동작을 만들어요. 같은 상황을 생각하면서 작업할 수 있게 플레이 순서를 한 장으로 맞추려고 해요.

### 할 일

- 회의에서 고른 물건·NPC를 기준으로 `플레이어 행동 / 필요한 조건 / 보이는 반응`을 적어주세요.
- 처음 말 걸기 → 물건 조사 → 다시 말 걸기 → 다시 시작의 순서를 정해주세요. 같은 물건을 여러 번 조사하거나 대화를 닫았을 때도 적어주세요.
- 이번 시험에서만 쓸 조건을 표시해주세요. 물건을 조사했다고 게임 전체의 이해도 단계까지 바뀐다고 정하지는 않아요.

### 완료 기준

- [ ] 조사 전·후 대사 조건, 조사문과 대화창 닫기, 반복 조사, 다시 시작 결과가 표에 있어요.
- [ ] 호윤이 각 줄을 어떤 동작으로 확인할지 설명할 수 있고, 재화·정인이 자기 작업과 다른 부분을 확인했어요.
- [ ] 정하지 못한 질문에는 이번 작업을 막는지와 상의할 사람이 적혀 있어요.

### 참고·인계

- 참고: [첫 실험 범위](오늘회의.md), [정보와 대화 조건 C-6](../codex_wiki/09_결정_미결/쟁점목록.md). C-6 전체를 이번에 해결할 필요는 없어요.
- 전달: 행동표를 해당 위키 작업 문서에 두고 재화·정인·호윤에게 연결해주세요. NS-03·04와 같은 물건·NPC 이름을 써주세요.
- 막히면: 대사의 의미는 재화, 구현 가능 여부는 호윤과 상의해주세요. 규칙 의견이 갈리면 회의에서 정한 결정 담당에게 질문을 모아요.

<a id="ns-03"></a>
## NS-03 · [스토리] 첫 조사문과 이유미의 조사 전·후 대사 작성

Linear: [GBG-249](https://linear.app/wozz/issue/GBG-249) · 담당: 이재화 · 상태: 할 일

### 왜 필요한지

물건을 살펴보고 이유미에게 다시 말을 걸었을 때 무엇이 달라졌는지 느껴보고 싶어요. 이번 작은 구간에 바로 넣을 문장을 준비하는 작업이에요.

### 할 일

- 선택한 물건을 조사했을 때 보여줄 짧은 글을 적어주세요.
- 조사하기 전과 조사한 뒤의 이유미 대사를 나눠 적어주세요. 각 대화는 변화가 드러나는 짧은 한 묶음이면 돼요.
- `대사 구분 이름 / 말하는 사람 / 언제 나오는지 / 실제 문장`을 한 표에 적어주세요. 문장 안에서 더 정해야 할 설정은 표시해주세요.

### 완료 기준

- [ ] 조사문 한 묶음과 조사 전·후 대사가 실제 문장으로 준비됐어요.
- [ ] 지호가 “왜 반응이 달라지는지” 이해했고, 첫 행동표의 조건과 맞아요.
- [ ] 호윤이 어느 상황에 어떤 문장을 넣을지 추가로 추측하지 않아도 돼요.

### 참고·인계

- 참고: [이유미 등 NPC 정리](../codex_wiki/02_스토리_캐릭터/NPC.md). 이번 소재는 회의 제안이며 정식 챕터 전체 대사를 확정하는 작업은 아니에요.
- 먼저 필요한 것: 회의에서 고른 소재. NS-02 작성 완료를 기다리지 않고 시작하되, 조건이 바뀌면 지호와 맞춰주세요.
- 전달: 실제 문장 표를 위키의 해당 작업 문서에 두고 호윤에게 링크를 전달해주세요. 파일 형식이 필요하면 샘플 한 줄로 먼저 맞춰요.
- 막히면: 언제 어떤 정보까지 말할지는 지호와 상의해주세요. 이번에 NPC 전체 대본을 마무리할 필요는 없어요.

<a id="ns-04"></a>
## NS-04 · [아트] 첫 조사 공간과 대화창 배치 그리기

Linear: [GBG-250](https://linear.app/wozz/issue/GBG-250) · 담당: 문정인 · 상태: 할 일

### 왜 필요한지

어디로 걸어가고 무엇을 조사하면 되는지 화면에서 알아볼 수 있어야 해요. 첫 실행 화면에 필요한 위치와 크기를 함께 맞추려고 해요.

### 할 일

- 작은 공간 한 곳에 플레이어가 걸을 곳, 막힌 곳, 물건과 NPC 위치를 표시해주세요. 재화와 동선을 확인해주세요.
- 조사할 수 있다는 표시와 짧은 대화창을 화면에 놓아주세요.
- 파일의 가로·세로 크기와 따로 움직여야 하는 부분을 적어주세요. 간단한 도형과 글씨로 그려도 괜찮아요.

### 완료 기준

- [ ] 한 화면에서 이동·조사·대화 위치를 알아볼 수 있어요.
- [ ] 호윤이 파일을 열어 필요한 위치와 크기를 확인했어요.
- [ ] 첫 시험에 쓸 임시 그림과 나중에 다듬을 부분을 구분했어요. 아직 게임에 넣지 않았다면 그렇게 표시했어요.

### 참고·인계

- 참고: [챕터1 공간](../codex_wiki/04_공간_레벨/챕터1공간.md), [아트·UI 현황](../codex_wiki/06_아트_UI/제작현황.md). 예전 크기 기준은 현재 화면에서 확인 후 적용해요.
- 전달: 편집 가능한 원본과 미리보기 이미지를 팀이 접근할 수 있는 작업 위치에 두고 호윤에게 알려주세요.
- 막히면: 동선은 재화·지호, 게임에서 보이는 크기는 호윤과 상의해주세요. 이번에는 건물 전체 도면이나 완성 타일을 만들지 않아도 돼요.

<a id="ns-05"></a>
## NS-05 · [개발] 첫 공간의 이동과 물건 조사 연결

Linear: [GBG-251](https://linear.app/wozz/issue/GBG-251) · 담당: 송호윤 · 상태: 백로그

### 왜 필요한지

팀이 직접 움직여보고 물건을 살펴볼 수 있는 첫 실행 파일을 만들려고 해요. 다음 대화 작업도 이 장면에 이어 붙일 수 있어요.

### 할 일

- 작은 공간에서 이동하고 벽에 막히게 해주세요. 화면 안에서 이동과 조사 대상을 확인할 수 있게 해주세요.
- 물건 가까이에서 정한 키를 누르면 조사문이 나오고 닫히게 해주세요.
- 조사한 사실을 이번 실행 동안 기억하게 해주세요. 그림은 임시 도형으로 시작해도 괜찮아요.

### 완료 기준

- [ ] 지호가 실행 안내만 보고 걷기·벽 충돌·물건 조사·조사문 닫기를 확인했어요.
- [ ] 같은 물건을 반복 조사해도 문장이 겹치거나 진행이 막히지 않아요.
- [ ] 실행 파일·버전·조작 방법과 현재 제한이 함께 있어요.

### 참고·인계

- 먼저 필요한 것: NS-01에서 실제 실행 가능 상태 확인, NS-02 행동표, NS-03의 조사문. 실행 오류가 있으면 해결 작업을 먼저 정해주세요.
- 화면 참고: NS-04 러프가 준비되면 적용해요. 완성 그림은 이번 착수 조건이 아니에요.
- 전달: 시험 파일을 공유하고 지호에게 확인을 요청해주세요. 다음 NS-06이 사용할 조사 여부도 짧게 설명해주세요.

<a id="ns-06"></a>
## NS-06 · [개발] 조사 여부에 따른 이유미 대사 연결

Linear: [GBG-252](https://linear.app/wozz/issue/GBG-252) · 담당: 송호윤 · 상태: 백로그

### 왜 필요한지

물건을 조사한 뒤 NPC에게 돌아갔을 때 다른 말을 듣는 흐름을 완성하려고 해요. 친구들이 처음부터 다시 해보면서 두 반응을 비교할 수 있어야 해요.

### 할 일

- 조사 전과 조사 후에 NS-03의 서로 다른 대사가 나오게 해주세요.
- 대사를 넘기고 닫을 수 있게 하고, 대화 중 입력이 이동·조사와 충돌하지 않는지 확인해주세요.
- 처음 상태로 돌아가는 방법을 마련하고 실행 안내에 적어주세요. 이번에는 종료 후에도 진행을 보관하는 저장 기능이 필요하지 않아요.

### 완료 기준

- [ ] 처음 말 걸기 → 물건 조사 → 다시 말 걸기에서 약속한 두 반응이 나와요.
- [ ] 대화를 반복하거나 중간에 닫아도 다시 진행할 수 있어요.
- [ ] 다시 시작하면 조사 전 상태로 돌아가고, 같은 순서를 한 번 더 해볼 수 있어요.
- [ ] 지호가 위 순서를 확인했고, 재화·정인이 실제 문장과 화면에서 수정할 부분을 확인했어요.

### 참고·인계

- 먼저 필요한 것: NS-05, NS-03 전후 대사, NS-04 러프 또는 정인·지호가 확인한 임시 화면 배치.
- 참고: NS-02의 조건을 사용해요. 이번 조사 여부를 정식 이해도 판정과 섞지 않아요.
- 전달: NS-07에서 전원이 사용할 같은 실행 파일·버전·조작 안내를 공유해주세요. 언제 대사가 바뀌어야 할지 애매하면 지호와 상의해주세요.

## NS-07 · [기획] 첫 조사 구간 함께 플레이하고 수정점 정리

Linear: [GBG-253](https://linear.app/wozz/issue/GBG-253) · 담당: 안지호 · 상태: 백로그 · 참여: 전원

### 왜 필요한지

만든 사람이 설명해야만 진행되는 부분이 있는지 확인하려고 해요. 이번 결과를 보고 다음 추리 구간으로 갈지, 먼저 무엇을 고칠지 정해요.

### 할 일

- 호윤이 공유한 같은 파일을 지호·재화·정인이 각각 실행해주세요.
- 처음 말 걸기, 조사, 다시 대화, 다시 시작을 해보고 성공 여부와 헷갈린 점을 적어주세요.
- 진행을 막는 오류와 이해하기 어려운 표현을 나눠 적고, 꼭 필요한 수정의 담당을 정해주세요.

### 완료 기준

- [ ] 개발자 외 팀원 3명의 실행 결과와 “무엇이 달라졌다고 느꼈는지” 한 줄씩이 있어요.
- [ ] 통과 / 일부 결과만 달성 / 수정 후 다시 확인 중 하나를 근거와 함께 정했어요.
- [ ] 수정이 필요하면 재현 순서·기대 결과·담당이 있어요. 통과하지 않은 목표를 완료로 기록하지 않았어요.

### 참고·인계

- 먼저 필요한 것: NS-06 실행 파일과 안내. 확인 기준은 [첫 스프린트](첫스프린트.md)를 사용해주세요.
- 전달: 결과 요약을 같은 이슈에 남기고, 다음 목표를 [로드맵](로드맵.md)의 M1 보완 또는 M2로 연결해주세요.
- 이 검토 이슈는 판단과 수정 목록까지 정리하면 완료할 수 있어요. M1 단계 통과는 필요한 수정까지 확인한 뒤 별도로 판단해요.

<a id="ns-08"></a>
## NS-08 · [기획] 짧은 추리 구간의 정답·오답·진행 조건 정리

담당 제안: 안지호 · M2

### 왜 필요한지

다음에는 단서를 보고 생각을 바꾸는 경험을 확인하려고 해요. 무엇을 알아야 선택할 수 있고, 잘못 골랐을 때 어떻게 다시 해보는지 먼저 맞춰요.

### 할 일

- 선택한 짧은 사건의 정보·선택지·다음 진술·해석 변화를 순서로 적어주세요.
- 관찰·연결·검증·재해석 중 어디까지 경험할지, 누구의 말이 어떤 생각을 돕는지 정해주세요. 보드에서 맞히거나 틀렸을 때, 다시 시도할 때의 반응도 적어주세요. 기존 확정 규칙과 다른 제안은 구분해주세요.

### 완료 기준

- [ ] 정답과 오답으로 각각 따라가도 다음 행동을 알 수 있어요.
- [ ] 재화와 호윤이 진술·조건을 같은 뜻으로 이해하고, 바뀐 결정은 위키에 반영됐어요.
- [ ] 확정한 공통 규칙의 선택지·보드·NPC 역할 기준과 맞는지 확인했어요. 이번 작은 시험만으로 확인할 수 없는 부분도 적었어요.

### 참고·인계

- 먼저 필요한 것: M1 결과와 다음 구간 선택. NS-09와 내용·조건을 함께 맞춰요.
- 참고: [쟁점 C-3~6·C-12](../codex_wiki/09_결정_미결/쟁점목록.md), [공통 규칙](../codex_wiki/01_게임방향/공통규칙.md).
- 전달: 다음 추리 진행표를 재화·정인·호윤에게 연결해주세요. 전체 챕터 공식을 한 번에 정하는 범위로 늘리지 않아요.

<a id="ns-09"></a>
## NS-09 · [스토리] 첫 추리 구간의 증거와 해석 변화 구성

담당 제안: 이재화 · M2

### 왜 필요한지

단서를 모으는 일이 고인을 다르게 이해하는 경험으로 이어지는지 보고 싶어요. 처음의 인상과 나중의 해석이 어떤 정보로 연결되는지 작게 만들어봐요.

### 할 일

- 처음의 인상, 이를 의심하게 하는 증거·진술, 바뀐 해석을 짧게 연결해주세요.
- 화면이나 종이에 내용을 놓고 지호·정인과 순서대로 읽어보세요. 설명을 더해야 이해되는 부분을 적어주세요.

### 완료 기준

- [ ] 읽어본 사람이 어떤 증거 때문에 생각이 바뀌었는지 말할 수 있어요. 전달되지 않았다면 보완할 부분이 분명해요.
- [ ] 진술과 선택지의 정보가 NS-08 규칙과 맞고, 정식 NPC 역할 조건과의 관계를 확인했어요.

### 참고·인계

- 먼저 필요한 것: M2 구간 선택. NS-08과 병행 작성하되 정해진 규칙과 맞춘 뒤 제작에 전달해요.
- 참고: [조사축](../codex_wiki/03_조사_추리_진행/조사축.md), [NPC](../codex_wiki/02_스토리_캐릭터/NPC.md).
- 전달: 실제 사용할 문장과 읽기 시험 결과를 지호·정인·호윤에게 공유해주세요.

<a id="ns-10"></a>
## NS-10 · [개발] 첫 추리 구간의 선택과 재시도 연결

담당 제안: 송호윤 · M2 · 구현 범위를 나눌 후보

### 왜 필요한지

종이로 확인한 추리 흐름을 직접 조작해 보려고 해요. 선택을 틀리거나 다시 들어왔을 때도 생각을 이어갈 수 있는지 확인해요.

### 할 일

- NS-08·09가 준비되면 정인과 필요한 화면을 먼저 정해주세요.
- 가설 선택, 진술 확인, 보드 제출·재시도를 실제로 눌러볼 수 있는 크기로 나눠주세요. 화면 제작은 정인이 맡는 별도 신규 작업으로 정의해요.
- 분할한 작업마다 확인 가능한 실행 결과를 정하고, 해당 범위만 구현해주세요.

### 완료 기준

- [ ] 등록 전: 구현·아트/UI 작업이 담당자별로 나뉘고 각 완료 동작과 예상량이 있어요.
- [ ] 구현 후: 합의한 선택·정답·오답·재진입 순서를 다른 팀원이 재현했어요.
- [ ] 플레이어가 어떤 증거로 해석이 바뀌었는지 설명한 결과가 있어요.

### 참고·인계

- 먼저 필요한 것: NS-08·09 검토, M1 실행 결과, 화면 제작 작업과 인계 합의.
- 참고: [M2 통과 기준](로드맵.md). 현재 초안은 분할 전 범위를 보여주며, 그대로 사이클에 넣지 않아요.
- 전달: 분할 시 이 후보의 필요한 조건을 각 신규 이슈로 옮기고 실행 결과를 지호에게 공유해주세요.
